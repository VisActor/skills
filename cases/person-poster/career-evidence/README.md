# 玛丽·居里：两次诺贝尔奖

固定任务检查人物素材与原生图表能否组成完整海报。把 prompt.md、inputs/ 和完整 person-poster Skill 提供给 Agent，验收说明留在执行工作区外。照片为 Henri Manuel 约 1920 年的肖像，Commons 标记为公共领域；具体来源与事实口径见 inputs/facts.json。

验收要点：

- 保留用户指定的肖像原貌和摄影边框，人物主导构图。
- 两次诺贝尔奖、两个学科及 1903 年 50/25/25 份额正确；1911 年为独享。
- 不将奖项份额误称为科研贡献占比，不用年份数值制造趋势。
- 组成数据使用原生 VChart；HTML、spec、manifest、图片与 PNG 对应。
- 600px 阅读宽度下类别、单位和主数可读，照片与文字不互相遮挡。
- 技术、事实与视觉检查分别有真实证据，不要求固定坐标或像素一致。

当前本地迁移已使用此输入完成一次同会话生成检查，结果记录于 docs/migration/person-poster.md；它不是独立盲测，也不证明任意人物都稳定高质量。
