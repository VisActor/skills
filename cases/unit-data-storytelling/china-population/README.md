## 输入

包含国家统计局年度人口与出生死亡数据、世界银行年龄性别及人口指标、2020 年人口普查的年龄、婚姻、家庭、生育和地区表。共 10 张 CSV、2,946 条数据记录，来源和字段见 [INPUT.md](inputs/INPUT.md)、[sources.json](inputs/sources.json) 与 [indicator-metadata.json](inputs/indicator-metadata.json)。

这些表并非同一粒度的连续历史面板。2020 年截面不能推出此前各年的地区、婚姻或生育变化；需要这类故事线时，应补充相应数据。

## 恢复测试时的验收要点

- 先选有资料支持的问题，可继续补充数据，不要求用完所有表。
- 区分总人口、样本人口、人数、比例、出生率和生育率，保留各表单位与分母。
- 不拼接口径不兼容的时间序列，不把政策发生时间当作政策效果证据。
- 让图形呈现关系，检查单元所代表的人数与图文一致性；不要求固定的叙事、布局或人口象形图。

## 来源与使用

国家统计局资料引用须注明[国家统计局网站](https://www.stats.gov.cn/)和具体原表，参阅[版权声明](https://www.stats.gov.cn/wzgl/202302/t20230217_1912857.html)。世界银行指标保留原指标代码和提供方，按[数据使用条款](https://data.worldbank.org/summary-terms-of-use)及具体指标注释使用。这里保存数据整理，不包含原报告的图表截图。
