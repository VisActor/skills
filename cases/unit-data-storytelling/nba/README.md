# NBA：身高、位置与上场机会

使用 [prompt.md](prompt.md) 和 [inputs/](inputs/) 中的固定快照测试 `unit-data-storytelling`。本文件供完成后验收，不交给创作 Agent；文件哈希见 [fixtures.json](fixtures.json)。允许补充有来源的新数据，不要求复刻展示案例。

## 输入

1960–61 至 2025–26 赛季：4,484 名球员、24,025 条球员赛季记录、1,708 条荣誉记录。字段、缺失项、处理方法与来源在 [INPUT.md](inputs/INPUT.md)、[data-context.json](inputs/data-context.json) 和 [sources.json](inputs/sources.json)。

身高统一采用球员资料表；位置来自赛季记录，多位置计入各位置。年代按赛季起始年分组，使用全部可用赛季。2020 年代尚未完整，不裁短其他年代去匹配它。

## 验收要点

- 明确一个单元代表球员、球员赛季还是固定数量；年代内按人去重，多位置分组不能再相加为联盟独立人数。
- 区分人数分布、分钟加权分布和荣誉球员分布。赛季总分钟不能解释为球员在每个位置实际打了多少分钟。
- 保留身高和位置缺失的处理说明；跨年代的样本量、赛季数与明星名单口径一致。
- 结论在画面中可比较，叙事与图形相互支持；观察到的关联不自动构成选材或战术变化的因果证据。
- 在真实浏览器中查看开篇、关键比较、动画中途与探索；不以章节数量、指定构图或像素一致作为验收条件。

## 来源与使用

主要资料来自 [Sumitro Datta 的 NBA Stats](https://www.kaggle.com/datasets/sumitrodatta/nba-aba-baa-stats)，固定版本与原始哈希见 `sources.json`；数据集标注 CC0。荣誉补充来源也列在输入中。该数据许可不涵盖 NBA 标志、球员照片或另行取得的素材。
