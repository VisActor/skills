# 叙事编排：让证据接起追问

好的叙事让读者愿意进入，借助证据逐步看清一个问题，并获得比开篇更完整的理解。本页负责追问、顺序与阅读组织；[单元设计](unit-visualization.md)负责让关系成为可见证据，两者共同进入[设计稿](#把叙事与画面写进同一份设计稿)。

## 什么算好的叙事

以下是设计与评议共用的标准，不是六个必备章节。认识可以是理解一个群体、看清变化、学会比较或修正直觉；清楚的描述同样有价值，不要求反转或戏剧冲突。

| 标准 | 编排时作出的决定 | 在作品中怎样判断 |
| --- | --- | --- |
| 有值得获得的认识 | 从读者关注选定主问题，区分题材、统计事实及其意义 | 读完能说清对这个问题多理解了什么，依据能回到材料 |
| 各段确实推进理解 | 选择主线证据，安排必要背景、解释与回看，其余放入详情或舍去 | 删除或合并一段，会失去哪项理解或必要的阅读节奏；只是又多看一个字段，贡献还不够明确 |
| 顺序有解释上的理由 | 先建立后续所需的对象、参照和比较条件；并列角度各有职责 | 下一段接住前段的问题、补充或修正认识；并列证据最终能合起来回答主问题 |
| 信息在需要时出现 | 开篇建立识别与期待，首次读图交代单位，关键比较留出阅读空间 | 读者不用先解码整套分析才能进入；需要某项背景时已经得到，图文落定后有机会看清 |
| 证据在画面中成立 | 正文的重点对应可见的差异、结构、过程或身份线索 | 保留必要图例、暂不读结论文字，仍能指出主要关系；精确读数和解释文字继续提供细节 |
| 收尾兑现开篇期待 | 综合已建立的证据，回答或修正最初的问题，说明影响判断的边界 | 结尾所得有前文依据；后续探索延续已学会的比较方式和有用追问 |

沿完整解释和整篇阅读判断。背景、停顿与总结可以不增加新数据；并列段落也可能互换顺序。事实可核对、比较条件一致、描述与原因分清，是基础。

## 从用户关注点选择值得讲的发现

先明确读者带着什么经验进入、希望弄清什么。沿用用户已有的问题或创意；只有主题时，从材料中寻找可回答的问题，核对[材料与粒度](unit-visualization.md#整理材料与确定粒度)。

主题可以是“作品与阅读量”；问题可以是“作品更多的类别，是否也获得更多注意力”。对候选发现判断三件事：与用户关注有什么关系；读者会多理解什么；总体、分母、时期、分类与来源是否支持这个理解。

某类记录增加可能来自覆盖扩大；均值相近的群体，分布与尾部可能不同。核对条件可以形成或推翻主线。补材料用于回答必要问题；变化与关联不自动支持原因解释。

题目宽泛时，比较候选主线带来的认识、关键证据与材料缺口；选择值得讲且能讲清的一条，不按列名生成目录或凑固定数量的方案。

选定后，用一句话写清主问题，以及读者最后应形成的认识；再区分主线证据、理解它所必需的背景和可按需查看的细节。设计中的结论随证据修订。

## 把发现编成连续的追问

每段先确定读者已经知道什么、还要看清什么，再连起所需证据。已看到总量增加，接下来可以拆开新增来源，也可以核对覆盖范围；追问不同，画面的参照与变化也不同。

把关键画面按阅读顺序连排，借助[表达与衔接](unit-visualization.md#从叙事追问推导表达与衔接)选择怎样从已有证据中展开下一项比较。后续对象先建立身份，待检验的判断先给出可回看的依据；原图仍能解释时让正文继续，需要新证据时再改变组织与视角。

前后构图可以相互调整：下一步要细看群体，前一步就需让它在总体中可辨；要比较增量，就先建立各组原值。后续来源难以辨认时，回改范围、排列或追问顺序，再决定动画。可比的独立样本也能延续共同尺度，无需假装同一批个体。

新角度用于补背景、解释特征或检验判断；并列分析需共同回答主问题，不因多一个指标就中断正在展开的比较。独立材料可补充原因或生活影响，不必编造数据转换。先连起观察，再划分状态与[舞台边界](#先划解释段落再决定舞台)。

为重要连接写清：

> 读者已看见＿＿；接下来要判断＿＿；依据＿＿之间的关系，对已有画面进行＿＿，并保留＿＿作为参照。

相邻画面接得顺，还需合起来完成本段判断。把具体对象、关系与操作写入设计稿：从已有画面的哪一部分开始，怎样组织变化，哪些参照持续可见，何时形成新的比较。用[追问与数据关系](unit-visualization.md#从叙事追问推导表达与衔接)定位构图取舍，再按[运动操作](unit-visualization.md#设计旧结构怎样打开新结构怎样形成)安排过程；操作名链接对应实现片段。示例解决选定关系的接线，故事顺序仍由本段追问决定。

### 同一份数据，故事线可以不同

假设同一观察窗口中有十件作品：A 类六件、共获九十次阅读；B 类四件、共获一百五十次，其中一件获得一百二十次。这是说明推导的虚构数据。

若关心“作品更多的类别，是否也获得更多阅读”，可以连起这段认识：先知道 A 类作品较多，再发现 B 类作品较少、阅读却更多，随后检验这个类别总量是否由少数作品撑起。最后读者需要区分类别总量与单件表现。数量比较建立两类身份，贡献比较接住它们，类内展开再检验刚形成的判断。具体画面如何共同设计，见[连续构图推演](unit-visualization.md#数量与贡献)。

若关心“注意力是否集中”，可以从那件获得一半阅读量的作品进入，保留它的身份并展开其余作品，形成个体与总体的比较；再看其余贡献怎样分布。类别只在帮助解释集中时出现，此时先介绍所有类别数量会延迟回答核心问题。

两条线组合了不同的追问与画面操作，不要求按表格顺序选择。阅读量支持贡献与集中程度，不自动说明作品质量或流行原因。

## 开篇与第一项证据一起设计

开篇用简洁标题、短引入和主体画面建立主题感与继续阅读的理由，集中呈现一个容易进入的重点。较长背景、成组指标和读图说明随第一项证据逐步展开。有引入价值的数字可以保留，但对象、单位和关系应一眼能懂，无需先学图例、坐标或操作。简洁取决于理解负担，不只取决于元素数量。

**读者为什么进入。** 从主问题选择值得遇见的人、物、情境、反差或疑问，也可用主题形象或文字构图建立体验。入口越具体，后文越需要回应这个对象或经历；先确定吸引读者的内容，再选形式，不必每次制造悬念。

**主体要保留什么特征。** 身份、外观或场景细节若承担吸引力，先按[素材指导](material-direction.md#先确定素材承担什么)查看代表素材，再选原图、插画、轮廓或符号。简化可能突出共同特征，也可能丢掉独特性；格式与绘制工具随后选择。

**标题与主体怎样共同构图。** 用实际图文确定视觉中心：视角或局部显出主体特征，留白、色彩与字形组织视线，见[视觉样式](visual-style.md)。主题可辨只是起点，题材特征还应成为吸引力。文字也可担当主视觉，形象与运动不必同时编码数量；点阵母形见[素材准备](material-direction.md#主题母形的准备)。

**第一项证据怎样接住期待。** 展开或检验刚认识的对象、经历与追问，也可先建立所需基准。换时期、指标或范围时，交代为何先看这里；同一种符号或动画本身不足以承接。开篇可同台进入数据，也可自然滚到下一段，标题、引导与图形共同交接，并为第一项证据留出阅读机会。

例如，沿用上文十件作品的虚构数据，若从那件获得一半阅读量的作品进入，可以让其封面与标题「十件作品，一件分走一半阅读」共同构图。封面让读者认出具体作品，大小暂不编码阅读量；第一项证据保留它的身份，展开全部作品的阅读贡献，让“一半”成为可见比较。先展开类别数量则需另有解释理由，因为它暂未回应注意力集中的问题。这里示范选择与承接的依据，不规定封面式开篇。

试读开篇时，看重点是否清楚、解释与指标能否后置、第一项证据是否接住期待。形象负责识别时，暂去掉名称，看实际尺寸下是否仍可辨；文字负责引入时，看措辞、字形与排布能否共同成立。

## 阅读组织与停留

### 先划解释段落，再决定舞台

先把核心数据解释连成持续演进的全出血主舞台，从已有画面推导下一步，再划分阅读状态。章节组织追问，舞台承载这段共同观察；章节标题、换时期、换指标或换图形本身不决定换场。

1. **在舞台内展开追问。** 根据[追问与表达的对应](unit-visualization.md#从叙事追问推导表达与衔接)选择操作，让读者看见选择、展开、对齐、重组或时间更新怎样产生下一项证据。布局和尺度可以改变，必要时同台并置多个视图；延续的是有用的身份与参照，不是所有对象的原位置。
2. **给解释留下停留。** 当前画面已能支持下一段说明时，保持证据，让正文继续展开；需要新比较时再响应。静态可读的状态同样属于连续叙事，不为保持运动而制造变化。
3. **在阅读任务确需改变时结束舞台。** 当前共同观察已经完成，接下来如需细读档案、人物经历或独立材料，可以进入正常图文。新数据问题若需要独立空间，先判断重排、缩放或并置是否可继续解释；仍会混淆对象与基准时再换场，并写明新空间带来的具体收益。

连续性依靠仍有解释职责的对象、历史与比较基准。可以保留关键时期、历史轮廓或缩略全景，不必把完整旧图叠成永久背景；独立样本也可以靠共同尺度连续比较。固定容器内淡出旧图、换入另一张成图，仍需说明它怎样承接已有理解。

### 用空间与停留支持这一段解释

正文提出问题、解释背景与意义；图形显出差异、组成或过程；动画交代已有证据怎样形成下一项比较。数值标签提供精度，不要求图形脱离文字说明一切。正文说增量，画面就应能找到增加的部分，而不只是前后总量。成品保留影响判断的证据边界，设计理由和动画实现留在设计稿。

正文可自然经过或原位交接；一幅图可支撑多段解释，一段文字也可引出多个变化。追问引导图形回应，结论在证据可读时进入，各过程可以重叠；具体时机见[各层交接](implementation.md#文字图例轴和单元一起交接)。

按比较方向、密度和正文分配[舞台空间](unit-visualization.md#舞台空间与辅助信息)，再选侧栏、浮动文字或上下组织；布局是否变化取决于比较需要。

有时间字段时，选择有解释意义的时期、变化和转折：可以沿过程推进，也可以从结果回看基底，再比较群体。保留支撑发展判断的历史，普通时期可以经过，重要节点需要读清；完整覆盖不等于逐年停留。

正常向下阅读时也应有机会看清关键比较，不能要求读者恰好在动画终点停手；触发位置与停留空间见[阅读区间](implementation.md#给完整证据留下阅读区间)。

## 收尾与简洁探索

结尾用前面的证据回应主问题，也可修正最初的提问或解释为什么只能回答到这里。可以回到全景、并置重要判断或停在代表记录；选择由最终认识决定，不再添加一组与主线无关的指标。

有值得继续追问的问题时再安排探索：先确定一个问题、一项主要操作和一种可见结果，例如换时期比较分布，或选择记录看它在同类中的位置。结果可以是差异、例外或具体依据，不必总是惊人的发现。

沿用已经教会的视觉语言。涉及变化就保留比较基准；查记录就提供可辨认入口；额外维度有帮助再加控件。状态管理见[实现参考](implementation.md#主线与探索)。

## 把叙事与画面写进同一份设计稿

保留一份可修订的 `story-design.md`，可沿用用户分镜。关键段连排追问、画面与承接，其余先记作用与依据；实现后可引用实际画面和计算位置。只维护当前决定，不复制网页全文或另做设计稿网页。

| 内容 | 留下能指导实现的决定 |
| --- | --- |
| 整体构想 | 主问题与最终所得；贯穿解释的对象和参照，主要构图与操作怎样接成一条可观察的线索 |
| 追问与数据关系 | 读者已经知道什么，下一步要比较哪些对象、属性或组成关系，为什么接在这里 |
| 证据依据 | 引用支持本段的数据、来源与计算位置；记清会影响画法或解释的单位、总体、分母和边界 |
| 画面与操作 | 连排关键段的起点、变化过程与可停留的结果；指出参与的对象、群组或参照，按[衔接设计](#把发现编成连续的追问)说明新比较怎样形成。标明单位、尺度与必要素材，实现后引用实际图文 |
| 正文与阅读 | 正文何时引导操作，证据与结果何时可读，哪里需要停留；必要换场怎样接住已有认识 |
| 视觉样式 | 字体与数字角色、主要层级、颜色含义及间距；用真实图文验证，具体依据见[样式指导](visual-style.md) |

构想可用草图，试作条件见[创作流程](../SKILL.md#从当前任务进入)。具体到能还原画面：“保持身份”需要指出可辨认的对象或参照，“共同坐标”需要容纳比较双方与可辨差异。小任务可合并条目，计算和来源引用已有记录；只更新影响实现的决定。
