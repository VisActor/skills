# 通用视觉样式：让文字、数据与素材形成整体

本页负责字体、层级、配色与间距，随[关键构图](unit-visualization.md#舞台空间与辅助信息)一起确定。中文、英文及混排共用角色原则，具体排版按语言调整。

## 先确定全篇的视觉方向

根据主题、对象和材料选择少量能贯彻的视觉特征：标题的字形与分量、背景与数据的对比、素材的处理、画面的疏密。例如，以档案为线索可以让材料边缘和注释关系参与构图；以运动为线索可以强调方向与聚散。它们是推导方式，不是题材与风格的一一对应。

先把开篇和最密集的数据画面并看：两者需要有共同的视觉语言，也允许开篇更有表现力、读图区域更克制。主题感可以来自字体、构图、素材或运动，不必靠添加纹理、卡片和装饰框。

将字体角色、颜色含义和主要间距记入现有 `story-design.md`。实现用少量语义变量统一这些决定；具体值由作品确定，不另建一套必须套用的主题系统。

## 字体选择与可用资源

由 agent 按主题和阅读任务，在系统可用字体、项目已有字体及用户提供字体中选择。默认不搜索、下载或安装新字体。使用已有字体文件时随作品正确引用；使用系统字体时设置合理回退，并检查实际显示的字形，不要求不同系统使用完全相同的字体。

- **标题**建立主题气质，可以沿用正文或选另一种适合展示的字形。用实际语言与长标题检查分量和断行，不因参考作品采用某种字体就固定同类题材的选字。
- **正文与图内说明**支持持续阅读和快速识别，选当前语言覆盖完整、所需字重清楚的字体；标题与正文不必处处使用相同的视觉强度。
- **数字**按[用途](#数字与单位的排版)判断字形、精度与对齐需求。先检查正文所用字体的数字，确有表现或读数需要再增加数据字体。

通常以一套正文/标签字体和可选的标题字体直接排版，在当前画面的常规检查中核对字形、回退与整体协调。出现明确的字形适配问题，或字体承担的主题表达未成立时，再用相同内容和画面任务局部比较已有替代字体，按实际字面调整尺寸与字重。已有选择满足需要就继续，无需独立样张或比较报告。

### 按作品语言排版

- **中文**：结合字体字面、每行汉字数量与段落长度调整行距。标题按语义断行，检查标点落点与末行孤字；正文保持自然字距，短题字确有需要再疏排。
- **英文**：结合单词长度、行宽、大小写与字形调整字距和行距。长标题用真实单词检查断行；字标或短眉题的全大写、宽字距另作局部决定。
- **混排**：检查中文、拉丁字母、数字与单位的视觉大小、字重和基线。人名、年份范围和数值单位按语义成组；不要为了套入已有框而拆开必要的读数。

用真实内容确定文字区域，再与图形一起调整空间。英文作品可启发层级、留白和注意力安排，具体字号、行宽和断行仍按目标语言调整；中文也不是把同一组英文参数统一放大即可。

## 字号、行距与信息层级

下面是本 skill 的桌面排版经验起点，单位为**最终显示的 CSS 像素**，并非下列参考文档给出的统一标准。按实际字体、语言、阅读距离、内容长度与画面职责调整；角色关系比固定数值更重要。

| 角色 | 参考起点 | 决定如何调整 |
| --- | --- | --- |
| 开篇标题 | 标题承担主视觉时可试 48–88px；素材为主时可更克制 | 形象与标题谁是主角；断行是否完整，是否挤压入口提示与留白 |
| 本段主标题 | 28–44px，行高 1.2–1.45 | 由章节标题或图题承担，放在读者应先看之处，给主要证据留足空间 |
| 连续正文 | 中文可试 18–20px、行高 1.65–1.9；英文可试 16–20px、行高 1.5–1.75 | 联合调整字体、栏宽与段落长度；中文侧栏可先试每行约 20–30 个汉字，英文按实际单词与行长试读 |
| 图内名称、刻度与必要图例 | 14–16px | 读者是否需要靠近或放大才能辨认；标签密集时先调整组织、数量或空间 |
| 来源及次要注释 | 12–14px | 必须能读；理解单位、分母等必需的信息按必要说明处理 |
| 重点数值 | 36–64px 起，按构图扩展 | 强调的是哪项发现；与单位、基准和对应图形是否靠近且协调 |

章节标题已提出问题时，图旁用较轻的字补对象、时期或单位。两处意思相同就共用一个标题。图形或关键数字最值得先看时，用位置和留白突出它，正文接着解释。正文排不下时，先调整栏宽、重复说明或舞台空间，保留易读字号。

SVG 的 `font-size` 会随 `viewBox` 缩放，Canvas 的 CSS 尺寸与绘制像素也可能不同。检查实际显示结果，不把源码写着 16 当成用户看见了 16px。密度较高时先让关键读法清楚，再决定哪些细节进入悬停或展开。

## 数字与单位的排版

| 数字的职责 | 选择与检查重点 |
| --- | --- |
| 正文中的年份、数量与比例 | 默认与正文协调；检查数字是否过轻、过重或突变为另一种气质 |
| 刻度、标签与比较读数 | 先保证小尺寸辨认和统一分量；数据读数通常适合齐线数字，不直接继承展示标题的装饰字形 |
| 动态读数、纵向对齐的数值 | 字体支持时使用等宽数字，并为完整变化范围预留空间；位数或单位变化时也不推挤邻近内容 |
| 承担主视觉的重点数值 | 可以选更有表现力的字形；与单位、基准和图形共同构图，静态大数字无需一律等宽 |

`lining-nums` 选择齐线数字，`tabular-nums` 选择等宽数字，实际效果取决于字体是否提供对应字形。等宽数字不等于整套字体使用 `monospace`，也不自动保证字体适合当前作品。把真实的整数、小数、负值、百分比或年份范围放到实际尺寸下，检查轮廓、粗细、小数点、负号、单位与基线；样例由当前数据选择。

同一比较使用一致的小数精度、分隔习惯与单位；精度来自数据与解释需要，不由原始字段的小数位数决定。单位、时期和比较基准放在对应数值附近，单位可稍小但仍需容易辨认。文字读数、SVG 标签与 Canvas 读数按同一组角色协调。

下面只演示字体角色与数字特性的分工，默认沿用可用的系统字体；按实际画面需要覆盖相应变量，不据此固定字体组合或字号。

```css
:root {
  --font-body: system-ui, sans-serif;
  --font-title: var(--font-body);
  --font-data: var(--font-body);
}
.story-copy, .chart-label, .data-unit { font-family: var(--font-body); }
.story-title { font-family: var(--font-title); }
.data-value { font-family: var(--font-data); font-variant-numeric: lining-nums; }
.data-value.is-changing, .data-value.is-aligned {
  font-variant-numeric: lining-nums tabular-nums;
}
```

Canvas 的字体需显式设置，数字字形特性也要核对所用绘制接口的实际支持，不能假定它继承 DOM 的 CSS。已有字体异步加载时，就绪后重测文字、更新布局并重绘；SVG/HTML 也要检查最终字形下的换行与遮挡。

## 色彩、背景与强调

先区分页面底色、主要文字、辅助说明和数据颜色。颜色承担类别、量值或状态时，含义与可比性由[编码指导](unit-visualization.md#分配形状通道与视觉层级)决定，装饰不能改变它们。

正文、必要标签和历史参照即使不是强调色也应可读；次要说明可以更克制。

背景留给数据和正文足够的对比。纹理、渐变或大图可以建立氛围，检查经过文字和单元的区域，必要时局部简化。深色画面中细字、细线与小色点需要单独查看；浅色画面也不能用过淡的刻度表达必要读数。

## 留白、对齐与辅助元素

空间组织由[舞台构图](unit-visualization.md#舞台空间与辅助信息)决定。样式在该构图内建立秩序：相关的数值、标签和对象靠近，共用有意义的边缘或基线；不同解释组之间留出可感知的间隔。

用段落间距、行长与留白分开层次，不把每段文字都装进卡片。浮动说明要检查整个运动过程的占位，来源、按钮、导航和图例也需要自己的空间。边框、底色与阴影用于划清对象或交互范围；同一项强调不必重复描边、光圈和阴影。

同类元素全篇一致，主题形象、核心数据与资料细读可以有不同的表现强度。只在返回、比较或探索确实需要时安排导航与控件；避免界面元素抢走主要阅读空间。

## 参考依据与使用边界

按遇到的问题查阅，不要求创作前遍历外部资料：

- [W3C《中文排版需求》](https://www.w3.org/TR/clreq/)：中文字体、行长与行距、标点断行和混排的参考；目前为持续修订的草案，包含书籍排版场景，不直接作为网页尺寸标准。
- [Carbon Typography：Style strategies](https://www.carbondesignsystem.com/building-blocks/foundations/typography/style-strategies)：参考按阅读与操作任务安排文字层级的思路；其字体、字号和字重组合服务 IBM 自身系统，不直接规定本作品的中文或英文字体。
- [MDN：font-variant-numeric](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-numeric)：核对齐线、等宽等数字字形特性；实现能力不等于视觉品质。

[已有作品参考](unit-visualization.md#参考作品怎样使用)也可用于观察样式：Hamilton 开篇让点阵形象与标题共同建立主题，Love Story 用克制的标题、人物素材和留白引入。这里提炼的是画面的注意力安排，不是作者发布的通用规范；实际语言、内容和素材决定本作品的选字、尺寸与空间。
