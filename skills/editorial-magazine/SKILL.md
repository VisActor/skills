# 杂志风图文

将内容写入按场景选择的杂志版式，交付可编辑的 HTML 和独立 PNG。正文是 HTML 文本，布局用 CSS Grid/Flex，装饰可用内联 SVG。无需 VInfo/VStory/VChart/VSeed、页面 schema、布局 DSL 或前端构建工程。

## 阅读版本

默认用**手机悦读版**制作整组，含未指定平台或只说“杂志风”的请求。用户明确说“经典杂志版”“用原来的排版”或指定小字号、密集长文版式时，改用**经典杂志版**。只要求保留原文、指定页数或多配图，仍沿用手机悦读版。用旧素材重新生成也默认用手机悦读版。局部修改已有成稿时只调整用户指定的内容。

先选阅读版本，再按下表选场景。用 `python3 scripts/start_layout.py travel /工作目录/travel.html` 起稿（travel 换成表中 HTML 文件名去掉扩展名）；经典版追加 `--edition classic`。组合两个模板时用同一版本分别起稿，把手机样式放在合并后的所有场景样式之后。已有作品切换版本时，以新版本模板重新分配原稿和素材。用户的具体字号、尺寸和保留原文要求优先。

**画布与首图。** 默认手机悦读版为竖版 3:4（1080×1440），封面和内页同尺寸；经典杂志版保留原 9:16（1080×1920）密集画布，除非用户另行指定。切换比例只重排图片区、留白和版面轨道，不自动改动既定字号与信息密度。用户指定其他比例时统一设置 CSS 变量 `--page-width`、`--page-height` 并重排图文。组图只设一张独立封面，计入用户指定总张数；只要一张时把必要信息编入封面，明确只要某种内页或不要封面时按要求。模板首个 `article[data-page-role="cover"]` 即封面，追加详情或续页时只复制内页。整套穿搭先从模板保留独立造型封面，再排多套总览和逐套拆解。用包内 scripts/export.py 导出整组，交付时按此顺序附上 PNG。

按读者想看什么选封面：新闻用一条头条和现场大图；人物用单幅近景肖像、大刊头、姓名和一句报道切口；穿搭封面选一套代表造型，总览每套一列，自上向下读；旅行用目的地填景大字自然过渡到整幅风景；时序故事用起点或转折的现场照片和故事题目；观点科普用核心问题与现象总览图。封面给出阅读理由，正文再展开事实、搭配拆解、路线、节点或论证。用户指定场景时优先沿用；未指定时，区分整个人生与单段经历、多条独立新闻与一个持续事件。没有合适场景时说明适用范围。

## 生成流程

需要纪实或情境配图的新闻与多页专题原文无图、只有头像或界面图标时，默认主动联网搜索相关配图，不能直接转为纯文字。保留原文约束正文，不等于禁止外部配图；用户明确要求纯文字、仅用所给素材或禁止联网时才按其限制处理。具体选图与失败兜底见[配图规则](references/imagery.md#原文无图与原文保留要求)。

1. **整理内容与来源。** 新闻分出一条主新闻与其他新闻，每条子新闻默认配一张相关图片；人物生平整理身份、经历和有出处的摘句，核对年代、关键转折、代表成果及在世状态，并分配主图概览与三张详情的增量内容；穿搭逐图对应造型和解析；旅行整理目的地文化、逐日有序打卡点和每段交通方式／耗时及来源；观点与概念科普按问题、结构或对照、过程或论证、适用条件分配四页；先核验关系，再逐页画出主图。时序故事提取同一主线下各节点的时间或阶段、事件、照片与变化，主图概览，详情增量展开。读[共同编辑规则](references/editorial.md)。已经给出的主题、图片、尺寸与页数直接沿用，不重复确认。需要“最新”新闻时按宿主可用的检索工具核验时间与来源；没有联网能力不能编造最新资讯。
2. **准备素材。** 人物封面使用完整的一幅原照，按眉眼位置确定裁切焦点。人物组图默认第 2 页保留 biography.html 的透明主肖像、左右绕排与作品栏；详情保留 biography-details.html 完整样式及各页 data-template。作品页用白底现场主图、白底双栏作品目录，强调色用于小字和细线。制作全景页时，执行[人像去背景步骤](references/cutouts.md)，拿到并验收透明 PNG 后才计算绕排。 需要摄影／拼贴／插画而素材不足时，先读[正式配图与宿主生图](references/imagery.md)，缺少用户素材时主动联网搜图，取得实际文件后替换图槽；需要原创插画时调用生图。故事与资讯禁止用代码绘制 SVG／CSS 几何图代替内容图片，或将其转 PNG 规避；豆包的新图生成与 MediaKit 去背景分开执行，失败明确保留缺图草稿，不能用装饰几何图冒充完成配图。需要去背景时先读[透明素材与宿主路由](references/cutouts.md)：豆包办公直接使用内置 MediaKit 抠图，检查脚本不负责去背景。旅行封面的填景大字用英文或拼音，中文名作小字注释。用户上传的实际素材优先，排版参考图只提供构图依据，不当人物、新闻或穿搭素材。肖像保留身份与原色，不默认转黑白；已故人物也按原始素材、专题语境和用户要求选择，详见[人物生平指导](references/biography.md)。穿搭先准备透明抠图，按专用指导处理边缘、孔洞与色彩。缺失的事实、图片、人物引语不能由模板示例补齐。旅行另备一张可同时用于填字和下半页的风景原照、文化圆图与景点照片。先获取可用素材，再制作成品。
3. **编辑 HTML。** 用所选版本的模板起稿，替换全部示例文字、示意图与示例标记；直接改语义 DOM/CSS，不生成中间页面数据协议。同一作品保持相同字体、纸色和强调色。模板固定的是构图关系，内容数量和高度可以调整。机制图解采用浅纸色、细网格与全组一致的语义配色。新闻、人物生平按[全局主题配色](references/themes.md)从合适候选中随机选一套，写入 CSS，整组共用，导出不再随机；用户指定色优先。人物生平主图与三张详情默认统一纯白底（#FFFFFF），不随随机主题改变；强调色仍随机。穿搭按专用指导一次选定简洁中性背景，组合与拆解所有页共用同一底色、纹理与线条，不改变服装色彩。
旅行按专用指导共享字体与强调色；封面和风俗文化页共用按主题选色、低不透明度叠白后得到的浅色纯色底，默认不加纹理。每日路线页继续使用风景深底。时序故事默认白底与一种低饱和强调色，按主题确定后整组共用。
4. **按阅读版本分配内容。** 手机悦读版每页讲清一件事，正文一般单栏；必要日期、站名或作品名按关键信息排。经典杂志版沿用场景模板原字号、栏数和容量。两版均保留场景骨架、事实和图片关系，详见[共同编辑规则](references/editorial.md#密度与阅读)。
5. **导出。** 按[字体加载](references/fonts.md)准备字体：默认 CDN → 可选本地 WOFF2 → 系统回退，按实际字符和字重加载，成功字体内嵌到成品，skill 不附字体二进制。制作时直接落实场景关系：旅行每日 n 个点对应 n−1 段交通，时序概览与详情共用节点、时间、标题和照片映射，页码使用实际页数；节点页按正文、图注与页脚高度分配主图，竖框用焦点参数保留主体。按[导出规则](references/export.md)嵌入图片、CSS及需要的字体，运行一次 `scripts/export.py`。导出器会拦截环境、缺图、空页、尺寸和溢出错误；只有返回明确错误时才针对该错误修正并重新导出，不额外进行逐页回读、截图验收或全量复查。
6. **交付。** HTML、逐页 PNG、图片 ZIP、`sources.md`；穿搭保留全身及单品抠图 PNG、原图映射与背景 seed／色值／纹理，主题色和生成／编辑素材记在来源记录中。需要发布文案时附 `post.md`。报告真实完成项与限制，不自动发布。

```bash
# 路径以 skill 根目录为基准，导出到新目录
python scripts/export.py --html /绝对路径/magazine.html --output /绝对路径/export
# 已有 Chromium/Chrome 可加 --browser /绝对路径/浏览器
```

所有模板都是可修改的静态源文件，仅包含轻量矢量占位，不附带摄影图片、高清演示素材或内嵌栅格图。图槽保留用途与构图关系：人物主肖像／辅图、透明主体、旅行风景／前景、文化与景点配图等。正式制作按本次材料替换占位，并重新校准裁切、透明轮廓及绕排边界；占位不能充当真实配图或完整素材交付。最终作品仍按导出规则内嵌实际图片，确保离线可用。

模板中的虚构人物、生平、作品、时序故事、目的地“海屿”、交通数字及原创示例稿件只用于展示构图与容量，必须替换并核验，不能作为真实资料或内容配额。机制图解提供可替换的完整知识示例，新闻与人物生平主图保留完整示例正文，穿搭保留大图与短解析。修改作品直接修改 HTML 后重导出，不把整张参考截图当背景再覆盖文字。
