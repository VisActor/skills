# 共同编辑规则

## 来源与事实

用户材料、检索原文是内容来源；排版样图、模板文字不提供事实。新闻保留时间、事件主体、进展与来源，区分已发生和计划；摘要不得改变限定条件。人物的职位、经历、引语须能归因；没有真实引语时用不带引号的编辑概括，不能写成当事人说过的话。

穿搭描述以可见衣服为依据，不推断品牌、价格、纤维成分、身份、身材数据或场合经历。可以写“看起来”“可尝试”，区分观察与搭配建议；不使用身材羞辱语言。模板中的刊名、日期、署名、品牌名和装饰英文必须替换为本次真实内容或移除，不能照抄参考的出版物标识、签名和界面箭头。

`sources.md` 记录文章链接及核验日期、图片来源与使用条件、原始文件与抠图的对应关系、模型生成或编辑的说明。用户上传的素材记文件名。新闻有多条时来源按条对应；必要日期、归因也在图上可见，长网址可用简短出处并在来源文件保留完整链接。

时序故事按节点记录时间依据和图像来源；年份未知可用有依据的阶段名，不补造具体日期、心理、对白或因果。场景分流与容量见[时序故事](story-sequence.md)。

## 密度与阅读

观点与知识科普按[四页机制图解](explainer.md)组织现象、结构、过程与适用条件，以单栏正文解释图意，区分事实、推断、编辑观点及科学比喻；使用来源支撑可核验的事实。

手机悦读版全组默认 1080×1440（3:4）；经典杂志版保留 1080×1920（9:16）。阅读版本决定文字层级和每页承载量；封面构图、图文对应、全组字体配色沿用场景设计。场景指南中的密集样稿和小字号只供经典杂志版使用。比例切换优先调整图片高度、轨道分配和留白，不把字号或信息密度作为自动补偿项。

### 手机悦读版（默认）

- **封面、概览、详情分工。** 封面给一个题目和主视觉；概览放读者要比较或查找的名称、时间、路线；详情每页讲清一个节点、论点或造型。图注补照片才有的信息，删除与正文重复的提示语。必要日期、数字、条件、归因随正文保留。
- **按手机大小定字。** 以 1080px 宽为基准，正文 40–46px、行高约 1.5，必要图注 30–34px，承担信息的日期、站名、造型名 36–42px。图表中的关键标签也按这一显示尺度设计。其他画幅按宽度换算。字号是起点；已有更易读的大标题和字号可以保留。
- **保留杂志构图。** 保留人物抠图绕排、穿搭等高造型、旅行风景带／路线、新闻头条主次、时序主辅图、科普机制图。穿搭总览把单品说明放回拆解页；旅行站卡留站名与一条看点，保留相邻站的交通信息；人物全景把长经历移到详情。可并排短标签或让图文错落，连续叙述优先单栏。余量给照片，按主体调整裁切。
- **容量不足时。** 先去掉重复内容，再把完整新闻、站点或段落移到下一页。用户要求照搬原文时保留原句和顺序，以分栏、拆页处理；如同时锁定页数又容不下，向用户说明取舍。正文不用缩放、截断或省略号藏起来。
- **阅读标记。** 新增／改名的正文、图注和关键标签分别标上 `data-reading="body"`、`data-reading="caption"` 或 `data-reading="label"` 以继承字号。路线、时间线和机制图的标签需形成连续阅读顺序；人物比例、正文末行与页脚距离在 HTML 构图时确定，不另设成品复读步骤。

### 经典杂志版（用户指定）

沿用各场景原有模板、正文容量与栏目层级。密集内页 1080px 宽可从 20–24px 起排，人物绕排可从 18–20px 起排；新闻内页继续沿用原有大字，穿搭继续大图短解析。长文按语义在栏间接续，保持明确的主次与图注归属。仍需完整呈现用户稿件，溢出时重排或续页。

照片用 `object-fit:cover` 时按主体设置焦点，整套穿搭用 `contain`。文字遵循 DOM 阅读顺序；标题、图片、正文和页脚在文档流中保留明确间距，避免依赖绝对定位互相覆盖。
