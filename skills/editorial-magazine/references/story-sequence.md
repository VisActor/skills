# 时序故事：概览与节点展开

适合用几个关键时间节点讲清一段经历、事件或项目的变化过程。采用 `assets/story-sequence.html`：一张故事开场封面，用现场照片引出事件；随后一张照片概览主图，再逐节点使用图片主导的杂志故事页。节点之间应有共同主线与时间承接，只有日期、没有可展开事件的清单不自动扩写成故事。

## 场景边界

按读者要理解什么选择，不仅依据“时间”“人物”“回顾”等关键词：

| 请求重心 | 场景 |
| --- | --- |
| 一段经历怎样发生、推进、转折：成长片段、项目诞生、活动筹备、旅途回忆、家庭记录 | 时序故事 |
| 这个人是谁、经历哪些人生阶段、代表成果与影响 | 人物生平 |
| 最近发生了哪些事、有什么新进展，特别是多条独立事件汇总 | 新闻资讯 |
| 接下来去哪、如何安排路线、点间交通时间 | 旅行攻略 |
| 一个观点为什么成立、一个概念如何运作，按论点而非事件推进 | 观点解读／概念科普 |

例如“某人的生平与成就”仍用人物生平；“他完成第一部作品的三段经历”用时序故事。“三天旅行回忆”可以用时序故事；“三天旅行路线”仍用旅行攻略。仅有年份列表的公司大事记先做概览，不凭空添加动机、对话或细节；材料能展开时才增加节点故事页。爱情是可能的题材之一，不是默认主题；项目、组织、活动也可以作为叙事主体。用户明确指定版式时优先遵从。

## 内容组织

先从材料提取各节点的时间或阶段、事件、可用照片、细节与后续变化，保留来源。主图为每个节点提供一张代表照片、时间和简短概述；正文页增加具体行动、背景、选择、转折或结果，不重复主图摘要充篇幅。

- 精确日期未知时用有依据的月份、年份或阶段名，例如“筹备期”；不为版面整齐补造日期。不要把阶段次序写成经过核实的日历日期。
- 默认按时间顺序，一个节点对应一张展开页；故事较长可用同节点续页，数个过短片段可合为一个有意义的阶段。模板的三个节点只是容量样例，页数是封面、概览加实际节点页数，不固定四页。
- 关键节点过多时先选有变化和细节的节点；必须全保留时拆分概览与续页，同步编号和总页码。不压小主图文字塞进所有节点。
- 正文保留连续段落，讲事件如何发展，不变成全页照片加一句口号。材料不足时缩短叙述或减少页数，不填充虚构心理、对白和因果。只要求摘取原文时沿用摘录，不扩写。
- 引语块可选。有真实引语就核验出处；无引语时用不带引号的事件小结、补充照片或留白，不编造当事人说过的话。

## 模板与版式

模板包含概览与 A/B/C 三种节点页。三种页型按照片方向和故事长度选择，可以重复使用，无需按固定顺序全部用一次；页内的 `data-story-node` 与概览 `data-story-node` 对应，同节点续页复用该编号。`data-image-key` 标识图片用途，概览可以复用该节点主照片。

| 页型 | 图片与正文关系 | 适用材料 |
| --- | --- | --- |
| 概览 | 大标题＋左侧略倾斜白边照片＋右侧时间/节点名；细线和圆点串联 | 整段经历的入口；默认3–5个节点起排 |
| A 场景展开 | 上方标题与日期，中间通栏大照片，下方连续正文与一张细节图 | 一张横向场景照，事件过程较完整 |
| B 双图叙事 | 大幅竖向照片＋窄幅辅助照片/可选小结，下方两栏连续正文 | 一张适合竖裁的主图和一张相关细节图 |
| C 照片开篇 | 上方通栏大图，中段日期与标题，下方细节图与叙事 | 场景本身有吸引力，希望先看图再读故事 |

主图保留用户选定的照片卡片和时间概览关系；节点详情无需重复绘制时间线。默认采用中性圆点，不套爱心、婚礼用语、相框或特定人物关系。图片主次由大小和裁切承担，不加入无关装饰图形。

经典杂志版在1080×1920竖版起排：内页正文24px左右、1.6–1.7行高、常规400字重；标题约60–66px，图注16–18px。主体照片与辅助照片占主要阅读面积，约占内容区60%作为起点，按素材和完整正文调整；不能为了比例裁断人物、丢掉关键段落或以同图反复填槽。长稿优先同节点续页，不能把字号越缩越小。分栏文字顶部对齐，不因全局 `p+p` 间距产生错位。

节点页沿用模板中的整页纵向布局与 `data-story-layout`、`data-story-node` 属性。标题、正文、图注和页脚按实际高度排入文档流，再把剩余高度交给 A 的场景主图、B 的双图区或 C 的开篇照片。B 页小结按字数占位，右侧照片吃满其余高度。换成长照片后重新定位画面中的人脸与动作。若长文挤得主图难以辨认，把完整段落移到续页。若短文结束后离页脚很远，先检查照片区是否还在使用固定像素高度。

手机悦读版的 B 页把连续正文改为单栏，两张照片仍保留一主一辅；详情页通常写两段，每段完成一个叙事动作。概览保留所有节点的时间与名称，具体经过进入各节点页。

## 概览的时间与间距

在 1080px 宽的概览页，把日期和时刻放入同一节点的 `.eyebrow`，默认 38px 半粗；只有年份或阶段时沿用相同位置。日期较长时可在日期与时刻之间换行，时刻与时区尽量同排。节点按 DOM 顺序排列，让时间线在手机显示尺度下可直接顺读。

每个节点直接放在 `.moments` 下，保留一个 `.moment`。模板先留出标题、可选结语和页脚，再按实际节点数等分时间线高度，照片随行高收放，圆点居中。3～5 个节点优先在一页实排；节点更多或完整文字放不下时，在节点边界拆成两张概览，保留顺序并重算页码。

## 让竖图保留主体

先看原片里要讲的对象和动作，再为封面、概览缩略图及详情各自取景。同一张照片进入不同宽高比的图框时分别设置焦点。人物关注脸、手和动作涉及的物件，设备关注外形与关键部件，多人互动要留住参与者。

模板默认居中。逐图在 `img` 上设置 `style="--focus-x: 25%; --focus-y: 45%"` 可调整左右、上下的取景位置，数值按原图和图框确定。若移动焦点仍会切掉关键部分，用 `style="--photo-fit: contain"` 保留全图，或换用比例更合适的照片。

## 统一风格与配图

整组默认白底 `--paper:#FFFFFF`，深色正文、轻量细线和一种低饱和强调色；模板的鼠尾草绿是起点，可按主题选择其他协调颜色。已选作品续页复用原配色，不每页重新抽色。字体、字重、页边距、页眉、图注和页脚统一，照片保留原色。通用标题可以用“故事档案”“这段经历”等，也可直接使用作品名，不默认 OUR LOVE 或浪漫英文口号。

按[正式配图](imagery.md)准备素材：用户图优先，缺图主动检索相关场景或物件；需要原创情境时实际调用生图并标注。真实人物和真实项目不能用生成图冒充现场记录。不同节点需要与各自事件对应的画面；生成同一主体时在素材制作阶段保持身份、服饰与环境连续，差异明显时不冒充同一人的纪实影像。概览复用详情主图合理，详情的辅助图应提供有意义的细节。

所有内容图保留 `data-image-policy="raster"`。运行时仅含 SVG 图槽占位，正式导出前必须换成实际图片并内嵌；原样模板会被导出器拒绝。不得删除检查标记或用代码几何图替代配图。示例文字、日期、图注、刊名和页码同步替换，明确虚构的模板稿不能当作事实来源。

概览与详情共用同一份节点顺序、时间、标题和主照片映射，续页明确承接节点。按[导出规则](export.md)生成自包含 HTML、逐页 PNG 和图片 ZIP；`sources.md` 按节点记录来源。
