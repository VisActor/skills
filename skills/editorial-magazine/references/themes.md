# 每次新作品随机一套全局配色

机制图解沿用浅纸色、墨色与固定语义配色，见[机制图解](explainer.md)。新闻与人物生平默认按内容选候选色系，再随机抽取一套协调配色。用户指定颜色、品牌规范或要求沿用已有作品时优先遵循，不再次随机。随机的是整套作品，所有页共用；不是分别随机每页、每段或每张图片。

```bash
# 人物生平：选择强调色，按下文固定白底；机制图解使用模板自带的语义配色
python scripts/choose_theme.py --style editorial --family general
# 已知主题可改 technology / nature / culture / lifestyle
# 重现同一套：保存输出中的 style、family、seed 和实际色值
python scripts/choose_theme.py --style editorial --family general --seed 123
```

编辑拼贴候选包括暗红、森林绿、藏蓝、灰紫、赭棕、深青。综合题材用 general，内容明确时用相应候选组。允许用户指定这些候选以外的颜色；另行检查正文和反白文字的对比度。不要直接在RGB空间随意抽三个互不协调的色值。

除人物生平默认将 paper 覆盖为 #FFFFFF 外，把输出的 accent / paper / ink / onAccent 分别写入 HTML 的 `--accent` / `--paper` / `--ink` / `--on-accent`，标题底、封面、重点块、分隔线、图注与页脚均由这些变量派生。`--rule-soft` 及人物生平的 `--rule` 从强调色派生；不要残留写死的红色线条。主题在生成素材和排版前确定，并在 sources.md 保存选择结果；HTML 中不运行随机脚本。重新导出、继续修改、增加续页时复用，只有新作品或用户要求换色时重新抽取。随机可能抽中上次颜色，不承诺每次一定不同。

## 拼贴与真实图片

新生成的装饰拼贴，把选定强调色和纸色写入图像提示词；整组素材统一双色调。已有的示例拼贴有固定红色，不能仅改背景便声称它也完成了主题换色。可先在 HTML 中设置 `--collage-filter:grayscale(1)` 将装饰图以中性色呈现；需要新的双色调图时，用宿主图像工具编辑或重新生成并记录来源。模板预览中的 CSS 灰度只改变呈现，原始 PNG 保留。

只对明确作为装饰的 `.collage` 图片应用这一滤镜。用户穿搭照片、纪实照片或承载颜色含义的科学图不得因为全局换色而改变真实配色；它们可保持原色，并选择相容的页面主题。穿搭色板继续从衣物中提取，不套随机主题。

脚本验证纯色上正文、强调色文字及反白文字的对比度，图片叠字、透明区域和整页视觉仍需实际渲染检查。


## 穿搭组图

穿搭采用独立的浅中性背景候选，执行 `python scripts/choose_theme.py --style outfits`。返回的纹理与底色在组合页和每张拆解页保持完全一致；family 不影响这组中性候选。具体 CSS 映射与衣物保真要求见[穿搭组图](outfits.md)。不要把编辑拼贴的深色主题铺到穿搭背景上，实际衣物色板仍取自照片。


## 人物生平

默认使用 editorial / general 的六套候选，生成时随机一次；参考图的粉红不构成固定要求。生平默认纯白背景（--paper:#FFFFFF），随机候选只应用强调色、正文色和反白字色；保存主题记录时同步覆盖 paper 并按实际背景核验对比度。用户明确指定背景时优先采用。姓名和标题条使用强调色，--rule 由 --accent 混合透明色得到；不要只换标题而留下旧颜色边线。肖像默认保留原始颜色；不因主题换色、杂志风格或人物已故而自动去色。原始黑白素材可原样使用，其他黑白处理须有明确编辑意图或用户要求。肖像和绕排轮廓保持不变，续页共享主题。具体版式见[人物生平](biography.md)。
