# 旅行攻略：封面、文化介绍与每日路线

用于目的地旅行图文、城市慢游、周末游和多日行程组图。默认一张风景填字封面、一张目的地文化介绍，再按行程天数各做一张路线页，即 2＋天数；用户指定的页数、页型和素材优先。复制 [旅行组图模板](../assets/travel.html)，替换示例后直接编辑 HTML/CSS/SVG。

## 内容与整组风格

- 先整理目的地、天数、旅行方式与各天有序打卡点。影响路线的出发地、日期或交通方式缺失时，只问会改变行程的必要信息；不从参考海报推定真实出行需求。
- 当地文化涵盖饮食、手艺、建筑、生活方式、节庆或礼仪，根据真实资料取舍；不把美食参考的八个模块当成必须凑满的配额。介绍页不是另一个景点清单。
- 大型内嵌图片直接放入 img/src、SVG image 或 background-image；避免把数MB的data URI放进CSS自定义属性触发浏览器长度限制。主题色与尺寸仍可使用变量。

同一作品固定字体、字重、页眉／页码、强调色与照片色彩倾向。按[字体加载](fonts.md)优先加载实际使用的 Noto 字体；主图说明、风俗文化正文、路线景点介绍及补充说明默认使用300字重，栏目标题和重要交通时间保留400–500以建立层级。填景大字仍用足够粗的字重，不随正文一起减轻。封面和风俗文化介绍页默认共用按旅行主题选取的浅色纯色底；路线页按用户参考使用全幅风景照片和暗色蒙层。统一风格不等于每页都铺同一背景。
- 封面与风俗文化介绍页的底色按目的地照片、季节和内容选取，例如滨海浅蓝／青、山林浅绿、古城浅沙色；这些只是选色方向，不按地名机械匹配。选一次并两页共用，不逐页换色。默认纯色，不加背景照片、蒙版、纸纹或噪点；用户明确指定时再调整。
- “颜色透明度低”只用于把选定底色淡化到白底上：可从主题色6%–10%的不透明度起调，按照片和文字对比度调整。先与白色合成最终不透明色值，再写入 `--paper`，例如深青 `#225B58` 以6%叠白得到 `#F2F5F5`。最终画布不透明；不要给整页、正文、照片或父容器设置 opacity。两页的页脚底色、编号遮罩等也复用 `--paper`，避免出现突兀白块。记录原始颜色、混合比例及最终色值。
- 主题强调色可从目的地照片取色，或从协调候选中随机一次；记录色值并整组复用。真实风景、饮食与民俗照片保留原色，不随主题整体去色或套双色滤镜。
- 用户照片优先。参考截图只用于学习构图，不直接当旅行内容。风景填字、前景、文化模块和路线照片分别记录来源；AI素材必须标明，不冒充真实目的地的纪实影像。实际营业信息和交通耗时需核验，无法核实就说明待确认，不用样稿数字补齐。

## 01 风景填字封面

选一张上方有天空、下方有可辨地貌的目的地实景。用同一张照片、同一个裁切窗口同时形成填景大字与下半页全幅照片。上部只从英文名或拼音笔画中透出风景，字底逐渐露出完整画面。让地平线和地貌跨过字边时连续，根据主体高度调整蒙版的渐变区。默认无需抠图。中文地名和短导语放在下方暗部，必要时局部压暗以保证可读。

## 02 上下文化模块＋中央风景

- 中央横向风景带作为视觉轴线，内放目的地名称与一段整体介绍；上、下分布圆形图片＋标题＋连续说明。大编号可与圆图叠接，但不能遮住图片关键主体。
- 参考是上下各四组；模板示范上下各三组，以给中文正文留足宽度。按材料与画布选择 4–8 组，不要求固定数目。减少模块时增大图文，不留空卡占位。
- 每个子模块都要有对应图片。圆图截取真实内容主体，配文解释当地风土人情及其背景，不能只写“必吃／必看”。文化事实、传统来源不从照片主观编造。
- 经典杂志版介绍页承载中等信息密度，可从20–24px正文和1.5–1.65行高实排。文字需要分段或减模块时处理内容，不能裁切、溢出隐藏或省略号截文。
- 模板六格矢量占位用 CSS 背景位置分区，仅示意图槽。实际制作通常替换成六张独立图片；替换时同步去掉联页的300%×200%背景尺寸，避免错位裁图。

3:4 手机文化页沿用模板的纵向网格。上下两排按圆图、标题和实际正文取高，中央风景带承接剩余高度；底排在页脚前收束。圆图保持 1:1，横幅使用 cover 并按主体调焦。

手机悦读版的文化页为每个模块保留一个名称和一句 20–40 字的观察，上下合计通常 4–6 个模块；完整历史背景、饮食说明或游览建议进入当天路线页或独立详情页。路线站卡只写站名和一条看点，相邻站的交通方式与时间继续完整显示。

## 03 每天一张风景背景路线页

这是**行程示意图**，不要求真实地图底图或按比例道路。背景使用目的地风景，前景是可编辑的 SVG 路径、编号点、景点照片卡和点间交通时间。

- 页头写 Day、当天主题和点位数量；编号按实际游览顺序。照片卡写景点名与简短介绍，靠近对应编号，用细虚线连接卡片与节点。
- 路径可以随机选择弯折形状、方向或左右交替，保留视觉节奏；随机的是排版几何，**不随机行程顺序、点名、交通方式或时间**。样稿路径静态保存，重复导出不抖动。留出边缘、卡片及时间标签的空间，避开无意义交叉和回绕。
- 一天 n 个点必须有 n−1 段相邻交通信息；每段标明 `01→02`、交通方式和耗时，如“步行 · 15分钟”。最重要的耗时用高对比标签放在对应线路附近，不能只在底部集中罗列，也不能把两个区间的时间合并成模糊总时长。只有一个点时无点间交通段，不造一段补数。
- HTML `.stop[data-stop]`、`.node[data-node]` 与 SVG `.route-line[data-from][data-to]`、`.leg[data-from][data-to]` 对应；这是 DOM 关联标记，不是新的页面 schema。复制路线页后改标题、点位、照片、段数、端点和时间标签，删掉多余元素。
- 3:4 手机每日路线使用页头与底注之间的整块空间。沿用模板的百分比定位：SVG 用 0–1000 的纵坐标和 preserveAspectRatio="none"，站卡、编号和交通标签用同一组百分比。多站的首末节点默认在路线区的 12.5% 和 87.5%，其余按站数分布；单站居中。照片保留横幅比例，只随卡宽缩放。
- 真实攻略先确认交通方式与起终点，再查地图服务、公共交通官方资料或用户提供的数据。估计值标“约”或范围，记录查询日期与来源；时间受时段、候车、转乘影响时说明。图面线段长短不用于计算耗时，停留时长与交通时间分开。
- 标明“路线示意，非导航地图”。随机曲线并不表达真实距离或方位；不要在未核对的位置上放经纬度、比例尺或指北针。
- 背景加足够暗的蒙层，照片卡保持原色与白边。节点、时间标签统一强调色；区间方向清晰，连接线不要穿过说明文字。点太多时先减少非必要长介绍，或在用户允许下做当天续页，不把照片与耗时缩到不可读。

## 版式关系与交付

制作 HTML 时直接保持这些关系：

1. 封面英文／拼音大字内确有风景，中文名为下方小字注释；字内与字外的景物在过渡处对齐，目的地仍可识别。模板矢量占位已替换，未用图标或大块顶部空白替代前景构图。
2. 文化页上下每个模块都有圆图与介绍，中央风景带与上下内容无叠压。
3. 每天编号连续、卡片与节点一一对应；每一相邻点都有一条路线和一个可见时间标签，首尾端点准确连接节点；交通时间来源或演示性质明确。
4. 共用字体、主题变量和页码；封面与风俗介绍页使用同一浅色纯色底，正文与照片保持完全不透明。路线深底与封面／介绍浅底是有意的页型差异；交通耗时使用手机字号规范中的关键标签尺寸。

交付 HTML、逐页 PNG、图片ZIP、sources.md；保存实景原图、图片映射、耗时来源及实际配色。模板内“海屿”是虚构目的地，图片仅为矢量占位，景点和时间为演示，不可沿用到真实攻略中。用户只要求新增模板时可以做明确标注的虚构样稿；用户给了真实目的地时转为资料核验与真实素材工作流。
