# 地图中的分析与决策

与[通用分析方法](guide.md)配合使用，负责二维与三维地图共有的空间证据。地图表现位置、邻近、覆盖和区域差异；图表、记录与空间选择共同支持同一问题。

## 空间比较的依据

- **身份与精度：** 区分事件坐标、实体位置、行政代表点和地域汇总。位置来源、坐标系、边界版本与粒度明确；只有国家代表点时不推断城市位置。
- **分母与覆盖：** 数量、密度、比例和暴露分别定义。面积、人口、业务存量或观测能力可能影响分布；缺少适当分母时只报告观测样本，不据点多推断风险高或点少推断安全。未定位记录继续计入适用统计与证据。
- **可比范围：** 区域边界、时间覆盖、采样和口径一致后再比较。总体差异必要时按相关特征分层，检查地域内部异质性，避免从国家均值推断个体情况。
- **聚合尺度：** 聚类、网格和行政分区的结果可能随缩放、边界或粒度改变。渲染聚类只改善可读性；称为热点或空间异常时应明确邻接／距离、尺度、比较基准及覆盖限制，并检查结论是否依赖划分方式。
- **真实关系：** 下钻依赖明确父子关系，流向和连线依赖事实关系。相机移动与地理邻近本身不能证明业务原因。

## 从地图继续追问

先定位值得关注的范围，再比较其基准、分布或结构；必要时检验覆盖、分组和尺度对判断的影响，最后定位相关记录。少量地域采用共同尺度或分面帮助比较，三维柱形的遮挡与透视不能替代精确数值图表。

以下是按现有示例数据可设计的路径，不表示模板已实现这些分析，也不要求新业务照搬。

| 场景与问题                           | 比较与检验                                                                                 | 证据及下一步                                                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| 地震目录：近期变化集中在哪里？       | 用同一截止点下的完整等长窗口，比较区域事件数、震级与深度结构；检查报告网络、覆盖与目录修订 | 地图与时间／分组证据定位变化来源，核对原事件；支持进一步观察或目录核查，不能由事件数量推断地震预测或灾害损失     |
| 地震目录：哪些记录值得优先复核？     | 联合查看审核状态、震级、时间与位置；保留已定义的业务优先规则，不凭空生成评分               | 从队列定位稳定事件 ID，检查完整记录与修订信息；人口、资产与资源未知时不推演救援配置                              |
| AQI 快照：国家均值是否掩盖内部差异？ | 比较均值、分位、超阈值占比与样本量，检查少数极端记录和样本门槛对排名的影响                 | 定位需要核对的城市样本与质量差异；可提出补充采样的方向，缺少日期、采样设计与人口时不评价趋势、总体暴露或治理成效 |

## 地图与分析范围

定位、缩放、筛选和层级下钻分别定义。只有确认业务范围才修改统计条件；悬停只预览，拖动只导航。分析继承已确认范围，局部探索按[范围与返回](guide.md#范围联动与返回)处理，关闭不销毁宿主地图或重置视野。

地图标记、图元与列表通过同一实体 ID 或地域键核对。无法绘制的位置仍可在明细访问；抽样、Top N 和地图裁剪不截断总体证据。重点记录可分别提供分析与定位入口，避免事件冒泡混淆两种操作。

## 空间分析验收

用一个关键发现走通“空间范围 → 比较或反证 → 记录 → 下一步”；核对坐标语义、分母、样本覆盖和共同尺度。若区域划分、样本门槛或时间窗口改变主要判断，明确说明；定位与分析选择各自清除、返回后范围正确。地图、统计和表格一致只能证明联动正确，分析质量仍按[通用验收](guide.md#验收)判断。
