# 单 HTML 资源加载

业务数据、轻量国家几何与页面代码保留在 HTML，固定版本运行时与大型纹理可由 CDN 加载；联网单文件不等同于离线交付。切换资源供应商不能上传用户数据，凭据不写入 HTML。

## 依赖与回退

复用 `DashboardResources` 的版本和候选源配置。按实际资源请求决定镜像／国际链路优先，不根据语言、时区或浏览器地区判断网络；每个资源独立验证结果、超时与失败原因。

- VChart／VTable UMD 通过实际 script 导出验证，已有正确实例优先复用。
- Three.js 与 OrbitControls 使用相同版本和同一精确模块实例，显式解析其依赖；不得按域名前缀盲改未知 import。
- VBI／VQuery／VSeed ESM 依赖完整模块图，不能把某服务的重写 URL 直接替换成普通镜像；必要时保留兼容 ESM 回退，避免重复加载图表运行时。

初始化总期限与重试由加载层管理，候选请求的期限和换源归资源加载器；最终失败才显示错误。恢复或迟到资源不能复活已取消的初始化。

## 地理纹理

地表、高程、云图和历史夜光的来源、年代及语义见[地图与数据](map-and-data.md)。图像先设 anonymous CORS 再设 src，验证解码、Canvas 采样与 WebGL 使用，替换托管源时保留高程编码和授权。

地表、高程或云图失败时明确三维降级，数据分析继续可用；可选夜光失败只关闭该增强。临时纹理、请求与 renderer 在初始化退出和正常销毁时统一释放。

修改加载器时实际验证首选失败、全部失败、模块导出、纹理 CORS 和中途退出。按目标打开方式检查独立 HTML，明确联网或离线要求；HEAD 成功、URL 可拼接或历史测试不能证明当前浏览器可用。
