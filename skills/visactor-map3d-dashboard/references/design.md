# 空间构图与外观契约

[完整模板](../templates/template.html)维护默认外观、组件和动效，主页面见[预览](../templates/desktop.png)。只修改外观时读取本篇；分析问题与内容按[分析方法](metric-analysis/guide.md)决定。

## 空间与阅读

默认桌面采用 `|O|`：全视口地图铺底，两侧玻璃容器覆盖其上，标题与工具位于中央安全区。地球可缩放到侧栏背后；标签、选中摘要和定位避让按实际占位计算。卡片数量与空间按证据需要调整，不裁切关键行或缩小到不可读来维持首屏。

窄屏保留独立地球区并纵向排列卡片，页面允许滚动，宽表内部滚动。图表有足够空间读取轴、数值、样本量与完整名称；精确比较可与二维图表配合，地球透视不承担全部读数。

## 表面与控件

外壳负责一次背景散射、方向性轮廓光和柔和外阴影；内卡用独立填充和接触阴影区分层次，不重复模糊。设置与分析外壳共用玻璃表面，分析内卡承载稳定阅读面，主页与弹窗控件共用样式和状态。四主题、深浅材质与玻璃强度由[token](design-tokens.md)统一管理。

标题只显示业务文本，国家范围与图标工具集中；同一操作不重复摆放，图标可悬停或键盘聚焦读取说明。搜索、分段、loading 与焦点反馈沿用现有控件，业务更新原位过渡。具体尺寸、圆角与时长读取 HTML。

## 地图编码与背景

真实高程、自然地貌、历史云图和夜光的来源及限制见[地图与数据](map-and-data.md)。背景、蜂窝和光效只表达材质或选择状态，国家柱、点与图例才承载业务编码，连续数值色阶与来源分类色分别使用。

保持共同尺度与真实位置，选中时保留邻域比较背景。国家边界在云层、海岸和不同地表上可读；密集区域可调整标记占位或标签，不按视角改变数值高度。背景切换保留业务图层与选择。

## 入场与更新

沿用[运动 token](design-tokens.md#运动-token)：地图先显示，地球放大后数据柱生长，外容器依次入场，内部 Card 随容器，标题与控件随后出现。后续区域提前隐藏并禁用交互，筛选与主题不重播首次入场。

动效遵守实际状态：画布空白保持可用自转，命中地球或标记才悬停暂停；确认国家停止相机漂移，选中高亮可继续。手动暂停、拖动、弹窗、后台及减少动态效果遵守统一控制。关闭与焦点返回不等待动画，更新保留阅读位置和已有实例。
