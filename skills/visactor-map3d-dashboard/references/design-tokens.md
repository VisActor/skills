# 主题与 Token 维护入口

只在维护外观、图形编码或动效时读取。直接维护[模板](../templates/template.html)内的材质、控件与场景 token，交付保持单 HTML。整体阅读效果按[外观契约](design.md)核对。

## 所有权

| 职责                     | 现有入口                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------- |
| 字体、尺寸、运动         | `--font-*`、`--control-*`、`--rail-*`、`--stage-*`、`--motion-*`                        |
| 深浅光学与表面层次       | `[data-mode=dark/light]` 下的 `--material-*`、`--glass-*`                               |
| 四主题底色、正文和强调色 | `[data-theme=dark/graphite/ice/silver]` 下的 `--ink`、`--strong`、`--muted`、`--accent` |
| 地球背景与光照           | `--map-water`、地貌／云／夜光／大气及边界 token                                         |
| 业务编码                 | `--map-column-low/high` 连续色阶、来源等级语义色及对应图例                              |

Three.js、VChart、VTable 和控件消费同一 CSS token，业务数据不另维护色板。组件布局、深浅光学和主题色分工保持明确；外壳、内卡与阅读面使用各自的表面角色。

有效主题偏好优先，存储不可用回到默认；玻璃强度由设置逻辑统一管理。主题、强度和恢复外观不改变业务范围或相机，不触发业务查询。深浅主题下文字、数据层和背景分别可辨；减少透明、高对比及无 backdrop-filter 时沿用既有降级。

## 控件维护

玻璃材质维护 `dashboard-material`，分段与请求反馈维护 `dashboard-interaction-runtime`，选择器与玻璃强度维护 `map-glass-controls`。2D／3D 沿用同套实现；修改共用行为时同步核对另一地图模板，各自保留地图专属功能。

设置、分析弹窗与国家菜单的外壳共用 `--glass-background` 和 `--material-filter`；分析遮罩只调暗背景。内卡、搜索与选中项使用填充和阴影，避免重复模糊。选择器通过 `MapGlassControls` 接入宿主，业务查询、国家范围和相机继续由场景模块管理。

## 运动 Token

`entrance` 从 token 推导阶段边界，地球、数据柱、容器和后续控件的起点随前序结束计算，不在文档另存时间表。首次画布缩放不改变相机和地理数据，柱子生长不提前消耗加载期时间；暂停时钟与单 RAF 保持一致。

分析、菜单与数值更新沿用各自模块的 motion 参数；只改变呈现，不重放查询或改写数值。减少动态时直接最终态，销毁取消动画与等待任务。涉及三维性能时补读[维护边界](template-adaptation.md#图形性能与释放)。
