# 三维地图验收

按当前变更验证，默认外观对照[模板](../templates/template.html)，示例数值对照[数据基线](map-and-data.md#可复算基线)。记录本次查询、操作与截图证据，不沿用历史评分、SHA 或性能结果。

## 分析与决策

按[分析验收](metric-analysis/guide.md#验收)和[空间分析验收](metric-analysis/map.md#空间分析验收)走通关键发现、比较或反证、记录与下一步。至少检查影响主要判断的数据覆盖、样本量或合理口径选择；证据不足时明确限制，不能把 AQI 样本排名当国家人口暴露或原因解释。

不同入口围绕各自问题增加证据，分析深度不能只按图表类型、统计量数量或默认摘要评定。新分析要求与模板已实现能力区分，未实现的检验如实列出。

## 数据与完整证据

- 独立读取源数据复算总体与有效筛选范围，核对稳定 ID、粒度、公式、单位、权重、分母和缺失。示例中的分类／数值差异、子指数语义及分位口径保持正确。
- 图表、发现和完整 VTable 同范围；风险子集保留固有条件，分布、国家与子指数视角不残留旧选择。Top N、最低 n 与地图裁剪不限制完整分组或总体。
- 原始字段、源值、空值与合法零保真；有导出时读取真实文件核对行数和字段。分批呈现不截断证据，原始记录或聚合表的行粒度明确。

## 地图与实际操作

| 动作                             | 应观察到的结果                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| 国家控件、快选、代表点、排行确认 | 范围、指标和选择一致，真实位置可见；未标注及少量样本可访问                         |
| 悬停、拖动、缩放、重置视角       | 悬停不筛选，背面不穿透拾取；导航与筛选分开，标签避开侧栏；CSS 缩放后仍命中正确对象 |
| 切指标或背景                     | 数值、图例与固定尺度一致，装饰不改变统计；相机与选择保持，零高度和遮挡符合编码     |
| 打开分析、分组、清除、返回       | 证据同步、局部条件可见，关闭保留主屏国家和视野并归还焦点                           |
| 刷新、慢请求、快速切换或重开     | 触发控件有反馈，旧内容保持，旧请求和退场回调不覆盖新状态                           |

分析入口和图标工具可用键盘，tooltip 与动效状态一致，浮层优先关闭、焦点不困住；有多个语义的入口分别操作，不以程序调用代替实际用户路径。

## 呈现与动效

检查实际桌面、受影响的低矮屏与窄屏，卡片末行、标签、样本量及返回入口完整，地图保持可用区域；移动端纵向滚动、宽表内部滚动。主题、玻璃强度、图表、表格与地球同步，偏好失效或存储不可用不改变业务范围。

按[设计契约](design.md)观察首次入场、更新和动效状态，具体时间从模板读取。ready 可能只标记开始入场，截图与数字核对等待有限动画完成；另观察正常中间帧，不通过禁用交付动画代替验收。空白画布、地球表面和标记的悬停状态，以及手动暂停、确认选择、弹窗和减少动态分别有效。

## 性能、降级与释放

图形改动用同画质、同视角比较实际帧与响应，四主题和相关背景检查保真，不据绘制次数宣称流畅。反复操作无实例、监听或 GPU 资源无界增长，静止、后台与离屏停止无效工作。

涉及资源时验证 WebGL 不可用／contextlost、候选源失败、纹理失败、缓存回退及初始化中途退出；可用的数据、选择和明细继续运行。释放所有拥有的资源和等待任务，迟到结果不能恢复已销毁场景。单文件交付明确网络要求，加载验收按[资源指南](resource-loading.md)。

交付说明主要发现、支持的下一步、实际验证与限制；浏览器不可用时说明未验证体验，不以源码或旧报告替代。
