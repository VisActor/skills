# 模板适配

新建先运行[完整模板](../templates/template.html)，再按问题替换示例业务；已有页面沿用宿主。保留适用的地图、外观、导航和生命周期，指标、图表与卡片结构按[分析方法](metric-analysis/guide.md)调整。模板默认摘要与图型只提供接入示例。

## 字段与完整记录

先建立源列到业务字段的映射，区分源字段、显示名称、Builder ID 与查询别名。带空格或点号的列可映射为稳定标识，保留原始字段供溯源和导出；schema 必须覆盖查询使用的派生字段。

- 原始空值与合法零保留，展示兜底和缺失分组键单独维护；导出不能写回兜底文案或筛选占位符。
- 业务地域身份与定位编码分开，无法映射位置的合法地域仍属于业务统计；定位覆盖采用独立分母。
- 地图、列表、悬停与详情共用稳定 ID 和完整记录入口。查询只返回投影字段，需显式选择完整事实字段，或用返回 ID 查记录索引；缺失 ID 显式失败，不以数组位置或同名城市代替身份。
- 接入后独立读取源数据，核对一条完整记录以及实际存在的空值、零值和未定位样本，经查询到地图／列表／详情逐字段比较。不能比较同一适配器的两份输出就宣称保真。

## 标准模板的修改入口

模板是单文件，先读文件顶部模块指南，不假定存在统一业务配置 API。

| 职责           | 现有入口                                                                                             | 适配重点                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 数据与查询     | `loadFeed`、`normalize`、`schema`、`chart`、`summary`、`eventTable`                                  | 事实粒度、字段、聚合、同范围证据；接入按 [server-runtime](server-runtime/guide.md#数据接入判断)        |
| 筛选与刷新     | `rangeConditions`、`applyRange`、`updateFilters`、`refresh`                                          | 传入可见触发控件，保留取消、版本保护、失败恢复与快照语义                                                                   |
| 地图与记录     | `initializeMap`、`renderMap`、`eventIndex`、`recordDetail`、`renderList`                             | 统一 ID、真实位置、定位避让、返回与完整字段；接法见[地图接入](open-street-map.md)                                          |
| 分析           | `quakeMetric`、`quakeAnalysisContext`、`bindMapMetricAnalysis`                                       | 默认问题、基准、计算与发现，继续探索和明细；按[空间分析](metric-analysis/map.md)设计                   |
| 地图表现       | `map-basemaps`、`MapBasemaps.createRenderer`、`renderMapEffects`、`positionMapEffects`、`syncMotion` | 保留图层恢复、投影、暂停与释放；不改嵌入的第三方运行时                                                                     |
| 外观与启动     | `map-ui-styles`、`MapUI.createAppearance`、`MapUI.loading`、`prepareMapEntrance`、`enterMap`         | 样式与时序由本页 token 管理，首屏相机入场与后续导航分开                                                                    |
| 图表表格与释放 | `renderMetrics`、`renderDistributions`、`DashboardTable`、`pagehide`                                 | 复用实例、完整记录、变化尺寸更新及幂等清理；表格按[公共适配器](visual-query/references/table-theme.md) |

仅换业务文案也要核对标题、启动状态、地图、弹窗、可访问名称与导出，避免残留示例语义。外观和动画默认从模板继承；维护入口见[L-Card](L-card.md)。

## 查询与分析契约

`MapQueries.create` 的维度元组为 `[field, encoding, alias]`，度量为 `[field, alias, aggregate]`，聚合默认 sum，业务指标需明确声明。`MapQueries.rows` 默认返回别名键，VSeed 内部字段映射使用 `fieldIds`。

返回行缺少所选字段应在接入或投影处修正，不吞错补零。别名模式要求唯一输出名；使用源字段命名的 `'field'` 模式时，同一字段同时作维度和度量可能重名，应使用独立的职责字段，不能只改显示别名。

指标与分析共用条件和聚合定义。`countDistinct` 忽略 null，缺失是否作为一组需由 schema 与查询明确；比率、分位、排序和门槛使用公开 Builder，不在详情另算总体。相机与临时悬停归 UI，可保存分析条件归 DSL。

按[发现与行动](metric-analysis/guide.md#发现解释与行动)补充比较与检验，不能只改 `finding` 文案而缺少相应查询证据。模板现有通用分组与极值摘要需要按业务扩展，不代表已具备所有诊断方法。

## 更新与生命周期

复用连接与宿主实例，范围提交、查询、呈现遵守同一版本。局部分析不改主页条件，关闭还原焦点与视野；原位更新、主题和加载反馈沿用宿主。数据变化时缓存失效，异步返回不能复活已销毁页面。

启动先保留尺寸、验证依赖与最小查询，再等待地图可用帧或明确降级。销毁取消请求、动画和等待任务，释放观察器、图表、地图及数据资源。接法见[组合指南](visual-query/references/composition.md)，只验证本次变更涉及的路径。

## 目录复核分析示例

从“已人工审核”进入“发现问题 → 检验证据 → 定位记录”。审核状态量与震级／网络内的审核结构共用打开时范围；对照自动待审核比例、M≥4.5子集和未知状态，不据全量待审核数推断较大震级积压。

定位阶段的完整 automatic 队列由 Builder 筛选，按震级、时间降序；比较图仍使用各网络全部事件作分母，范围分别标明。选择 VTable 记录或首条候选后可定位并查看冻结快照的事件详情，关闭分析不更改主页筛选。`is_pending` 与 `pending_strong` 仅作逐行派生字段，聚合仍由 Builder 执行；未知状态不算待审核。无候选时说明原因并禁用定位，不生成风险评分。
