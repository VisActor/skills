# 布局与地图避让

默认继承[完整模板](../templates/template.html)的 L 形构图：地图铺底，左侧概览与底部分析各有完整容器。内容、卡片数量与面积按问题分配，用户指定布局优先；材质与控件见[L-Card](L-card.md)。

## 尺寸与避让

- 先确定连续的地图可用区域，再安排指标、比较和明细。全局筛选与工具集中，标题、图例、来源和导航保持可达。
- 用卡片和控件的实际占位计算安全区域。定位、范围适配和提示框避开遮挡；首次布局、主动定位和复位才调整视野，自动刷新保留用户导航。
- 尺寸变化时 resize 地图与图表，重新计算安全区域。长标签与完整行内容有读取路径；图表、表格的内部滚动不撑破容器。
- 全球视野结合当前中心处理世界副本与跨日期线，定位采用最短合理路径，不能只适配经纬度的普通最小／最大值。

## 初始化与响应式

加载期保留地图和图表所需尺寸并禁用未就绪交互。数据与可用地图首帧就绪后衔接模板入场；地图失败时能独立阅读的数据可先显示，明确降级并保留恢复入口，迟到响应不能揭开已取消的场景。

宽屏保留地图与卡片的空间层次，低矮屏让长内容内部滚动；窄屏允许页面纵向滚动，保留独立地图区和可读图表。检查用户窗口及相关断点的内容完整性、导航、浮层与关闭入口，不靠压缩字号或裁切末行掩盖溢出。
