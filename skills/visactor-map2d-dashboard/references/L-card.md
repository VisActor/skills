# L-Card 外观契约

[完整模板](../templates/template.html)是外观与控件的维护位置，交付保持单 HTML。直接维护模板内的样式与模块；场景布局、相机入场与地图安全区见[布局](layout.md)。

## 表面与主题

外容器负责背景散射、轮廓光与柔和阴影，内卡以填充和轻阴影区分两层，不重复叠加模糊。设置与分析外壳共用玻璃表面，分析内卡承载稳定阅读面；图表、地图标记、VTable 与控件消费同一套语义 token。

沿用深蓝、石墨、冰蓝、银雾主题及主题兼容底图；深浅光学与主题色分开维护。玻璃强度、有效主题偏好及恢复默认由现有设置逻辑管理，存储不可用仍能运行，外观变化不清空业务范围或视野。具体默认值、圆角、字号、底图目录和运动时长直接读取模板，不在文档复制参数表。

## 控件与呈现

玻璃材质维护 `dashboard-material`，分段与请求反馈维护 `dashboard-interaction-runtime`，选择器与玻璃强度维护 `map-glass-controls`。2D／3D 沿用同套实现；修改共用行为时同步核对另一地图模板，各自保留地图专属功能。

设置、分析弹窗与国家菜单的外壳共用 `--glass-background` 和 `--material-filter`；分析遮罩只调暗背景。内卡、搜索与选中项使用填充和阴影，避免重复模糊。主题与强度变化不触发业务查询或重置地图。

主页、设置和分析复用现有分段、图标、选择器与浮层。图标操作有说明与焦点反馈，长选项可搜索；实际触发查询的控件显示 loading，闲置 spinner 不占位，纯呈现变化不伪造取数。

沿用地图先出现并启动可用动效、容器依次出现、标题与控件随后呈现的入场编排。内部 Card 跟随外容器，等待区域不可误操作，筛选与滚动不重播；更新保留旧内容并原位过渡。减少动态直接呈现最终态，关闭和键盘操作不等待动画。

维护外观时核对整页深浅主题、内外层次、文字图形对比和窄屏命中；不重复增加占位品牌或工程说明。表格实现沿用[统一主题与适配器](visual-query/references/table-theme.md)。
