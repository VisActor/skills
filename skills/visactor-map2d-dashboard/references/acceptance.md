# 二维地图验收

新建对照所用模板，修改对照原页面，只验证受影响路径。记录本次操作、查询与截图证据；源码存在或历史结果不证明本次体验成立。

## 分析与决策

按[分析验收](metric-analysis/guide.md#验收)与[空间分析验收](metric-analysis/map.md#空间分析验收)，从关键问题走通比较、解释检验、记录核对及下一步。确认深入后增加证据，不能以图表种类、指标数量或最高／最低摘要评定深度；数据不足时结论降级并说明缺口。

## 数据与空间

- 从独立源数据复算总体和有意义的筛选范围，核对单位、去重、分母、权重、时间与缺失；比率和分位不由 Top N 或可见明细估算。
- 核对实际地图业务图层中的稳定 ID 和有效坐标，覆盖完整记录、实际缺失、零值与未定位记录。地图、列表、详情一致，已知事实不因漏投影显示为未知。
- 跨日期线、密集点、少量点和当前关注对象的取景可读；聚类、单点与选中可辨，定位和提示不被卡片遮挡。地域匹配与边界口径可追溯。
- 有导出时读取真实下载文件，按稳定 ID 比较原始字段、空值与行数，确认范围和记录粒度。

## 实际交互

| 动作                                       | 应观察到的结果                                                             |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| 从地图、列表和地域控件选择同一对象         | 确认条件、选择与记录一致，定位落在安全区域；悬停和导航不擅改范围           |
| 图元选择、切换分组、清除、返回             | 读数、发现、图形和完整 VTable 同范围；Top N 外证据可达，局部分析不污染主页 |
| 打开分析与独立定位                         | 各自执行预期操作，无冒泡重复；鼠标和键盘可用，关闭保留视野并归还焦点       |
| 连续筛选、慢请求、失败后重试、快速关闭重开 | 触发控件有反馈，旧内容保留；最新范围生效，失败或旧响应不被标为新结果       |
| 换主题、底图或刷新                         | 业务图层、筛选与用户导航保持；空结果清除失效对象，快照刷新不暗示新增事件   |

数字核对等待过渡结束。模板的 `data-metric-value` 为目标值，`data-animating` 标记过渡；ready 信号可能只表示开始入场，不能据此判断全部内容已稳定。

## 呈现、动效与恢复

检查实际窗口及受影响的低矮／窄屏：地图连续可操作、图表标签和列表末行可读、页面无横向溢出，宽表在内部滚动。深浅主题、设置与分析同步，内外玻璃层次和正文对比清楚；外观参数以[模板](../templates/template.html)为准。

正常偏好下观察地图、容器与后续控件的入场顺序、选中反馈与原位更新；减少动态直接最终态，后台停止无效绘制。截图等待有限入场完成，另观察动画中间状态，不修改交付参数来方便截图。

验证相关加载失败、空结果、存储不可用、地图回退和延迟初始化退出。错误有恢复路径，资源释放且迟到任务不写回；主题偏好失效不阻断页面。交付说明发现与限制、实际验证及未验证部分，不把源码检查写成浏览器验收。
