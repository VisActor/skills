# 地图接入与空间语义

优先沿用模板中的 MapLibre、底图和导航模块，修改入口见[模板适配](template-adaptation.md)。空间比较与判断见[地图分析](metric-analysis/map.md)。

## 位置数据

- 明确点代表地域汇总、实体还是事件；实体与事件使用稳定 ID，地域身份带父级或权威编码以区分同名地点。
- 核对来源、精度和坐标系，统一为 WGS84 `[经度, 纬度]`，校验空值与范围。行政代表点不当作事件实际坐标，不用省会或随机位置补点。
- 地域匹配使用明确版本与精度的边界，保留未匹配及未定位记录在适用的总体和明细中，说明地图覆盖。不能凭地点描述猜归属。
- 事件区分发生、修订和查询截止时间；按 ID 更新已有事件，刷新不把旧事件当新增。静态快照的选中反馈不暗示实时事件。

## 接入与底图

沿用同版本 MapLibre JS / CSS、现有底图目录与可见来源署名。新增底图时验证资源、层级、CORS、署名和目标网络；[MapLibre 示例](https://maplibre.org/maplibre-gl-js/docs/examples/)用于查阅具体接法。

切换底图保留相机、筛选和业务图层，`setStyle` 后在 `style.load` 恢复业务层。实际失败或超时才进入明确的回退状态；离线交付需单独安排可用资源。容器变化调用 resize 并按[尺寸与避让](layout.md#尺寸与避让)更新安全区。

地貌影像、阴影与三维高程分别表达不同能力；需要真实地形时使用有效 DEM 并恢复 terrain 配置，不从影像亮度伪造高程。底图、标注和装饰不能干扰业务编码或重复遮挡地名。

## 标记点与动效

- 大量点用地图批量图层，少量重点才用 DOM／SVG。先核对实际业务点集的 ID 与坐标，再决定聚类；聚类和单点可区分，关注的极端记录不被合并隐藏。
- 世界副本、缩放下限与跨日期线策略按数据和可见区域确定，避免重复大陆占据主要阅读区或定位绕远路。
- 点标外观沿用现有设置与主题，样式切换保留选择和视野；位置由地图投影管理，动画作用于标记内部。
- 选中反馈、近期事件与关系飞线各自有真实语义。没有关系数据时移除连线；保留选中反馈的投影、暂停和清理，动效不能改变统计值。

## 控件与联动

地图、图表、列表与选择器通过统一业务入口更新 Builder。悬停预览、拖动导航、确认筛选、定位和详情分别处理；图表标题分析保留图元及图例原有操作，复位视野不等于清空条件。

空结果清除失效点线，选中对象离开结果集时同步清除高亮和详情；保留当前地域及空态。图例与标记共用真实编码和未知值规则，主题与刷新不隐式重置范围。

数据变化才更新点集，选择变化更新高亮，相机移动更新投影。暂停、后台与减少动态统一控制动效；请求与销毁按[组合指南](visual-query/references/composition.md)管理。
