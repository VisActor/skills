# 敏感数据源与地域口径确认

**发现可能引发政治风险的敏感数据源或内容时，必须主动询问用户是否剔除，再按用户确认的范围处理。** 数据接入前检查国家／地区名称、归属编码、争议边界、底图标注及相关记录；引用公开数据源或复用模板不代表用户已接受其地域口径。

询问时指出具体来源与问题，明确是剔除整个数据源、仅剔除相关条目，还是保留原数据；不要自行扩大为删除其他国家的数据。用户已明确指定处理方式时直接执行，不重复确认；尚未确认时可继续不依赖该选择的工作，不擅自删除、改名或合并地域。

确认剔除后，在自有源数据或接入适配层统一处理，同步地区选项、地图要素、指标、排行、明细与导出，确保刷新后不会重新引入；不能只隐藏下拉选项。第三方底图标注需单独核查，无法控制时说明限制，并确认是否替换底图。交付时说明排除范围及其对统计口径的影响。
