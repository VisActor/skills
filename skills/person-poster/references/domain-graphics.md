# 领域图形：让事实具有可识别的形状

在参考图用奖杯、球衣、唱片或动作组织信息，而当前草稿主要剩下文字列表时读取。先决定图形表达什么，再选择素材或画 SVG；增加图标数量本身不提高信息密度。

## 从事实选载体

| 信息关系 | 可用表达 | 需要保留的语义 |
| --- | --- | --- |
| 少量独立荣誉及年份 | 一次荣誉一个符号，相邻写年份；重复次数来自事实清单 | 每个符号代表什么；年份与次数一致 |
| 球衣号码、乐器、创作媒介 | 球衣/器具/唱片轮廓配可编辑数字或短标签 | 这是身份标记，不把面积解释为数值 |
| 同一种事件的计数 | 可辨认的重复符号与总数；过密时收敛为总数 | 单位、计数范围；符号能数清才承担数量编码 |
| 得分、篮板、助攻等独立指标 | 不同语义符号与各自数值、单位并列 | 不同量纲不共用组成分母；不能合成一个饼/环 |
| 排名、赛季、销量或准确组成系列 | 完整 原生 VChart spec | 类别、尺度、顺序及数值归图表拥有 |
| 球场线、唱片纹路、舞台轨迹 | 内容背后的低对比共享载体 | 纯装饰，不伪装成准确比例、时间轴或统计图 |

同一图形可有不同作用。例如唱片既可表示音乐身份，也可按明确单位计数；未定义单位时，不让读者把一张唱片理解为一百万销量。获奖与提名也不是天然互斥的组成部分。

## 画法服从最终大小

先根据照片、字体和最终展示大小确定填充或描边、视角、细节与比例。计数符号需要容易重复辨认的外轮廓；较大的身份图形可以容纳可编辑数字。小尺寸减少内部细节，避免每个区块换一种笔触。

真实人物照片可以与简化符号共存；共享色彩、基线、间隔和分隔节奏即可，不要求为了统一风格重绘人脸。官方奖项、球队或品牌标志使用核实素材并记录来源；自绘符号明确记为自绘语义图形，不声称是官方标志。

## 从局部参考实现当前图形

将当前事实的图形、主数、单位和范围作为同一组证据放进草稿。按语义选择载体、数量和字级，再编写当前作品需要的 HTML/CSS/SVG。与整页共享颜色、字体和对齐，不要求使用固定图标库、组件接口或样式文件。

先决定符号的单位：逐次荣誉序列的总数从同一份事件列表得出；精选事件明确标注“精选”并保留总计与选集的区别；一个奖杯代表某项赛事身份时，与该项次数配对。这样符号、总数和年份共享事实关系，而非把演示片段的符号数量带入另一组总数。

自绘 SVG 可用 `currentColor` 继承整页颜色；`img` 引用 SVG 不会自动继承外层 CSS 颜色，需要内联或改实际 SVG。核实的外部素材与自绘语义图形均可使用，来源记录到当前作品的 manifest。

关键独立事实可采用较完整的图形轮廓与主数共同表达：荣誉形象托起次数，唱片中心承载榜单总数，票券结合场次与时期。让它们在整页实际显示尺度上仍有形状和字级，辅助说明只留下单位、范围或必要限定。较长数值可放在形状旁，避免把所有值挤进固定小图标。整页围绕当前人物与这些局部关系排布，不把资源依次堆成等权面板。

## 在人物轮廓旁验证

1. 给每组事实指定主要位置，选图形时写明它提供的新信息。已有完整图表就不再用另一组符号重画同一系列。
2. 以照片中的脸、手、器具和可见轮廓确定空间，再放图形与短标签。按一组信息的整体边界对齐，而不是把所有图标塞进相同卡片。
3. 完整同宽对照中查看符号能否帮助理解、主数字是否突出、文字列表是否真正变成可读证据。细节太多就简化图形；仅空白太多时先检查画布容量和分组，不补无意义图标。

领域改变时重新选载体和构图：篮球可使用球衣与荣誉；音乐可能使用保留舞台背景的照片、唱片身份和独立榜单指标。迁移的是“事实 → 载体 → 空间”的判断，不是符号库存、紫金配色或当前人物的坐标。
