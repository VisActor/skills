# bar

横条图使用 direction: horizontal，xField 为数值、yField 为类别。左侧 band 轴 inverse: false 保留自上而下的数据顺序。

读取 [完整原生示例](../chart-examples/long-label-bar.spec.json)，替换数据、单位、字段、字体及当前空间；这是合成数据，不是人物事实。

所有示例使用 VChart 2.1.7，animation: false。原始 spec 文件生成内嵌 JSON；对深拷贝创建图表，完整接入见 [图表桥接](../chart-bridge.md)。完整系列由图表承担，独立事实和标题由 HTML 承担。
