# grouped-column

同一类别内比较多系列，stack: false；分类字段数组包括时期与系列，seriesField 决定颜色。 横向和纵向分别交换数值/类别字段。

读取 [完整原生示例](../chart-examples/grouped-column.spec.json)，替换数据、单位、字段、字体及当前空间；这是合成数据，不是人物事实。

所有示例使用 VChart 2.1.7，animation: false。原始 spec 文件生成内嵌 JSON；对深拷贝创建图表，完整接入见 [图表桥接](../chart-bridge.md)。完整系列由图表承担，独立事实和标题由 HTML 承担。
