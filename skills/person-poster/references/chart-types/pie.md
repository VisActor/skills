# pie

使用 categoryField/valueField；这是原生 pie 的字段，不是柱图字段。分项来自同一分母；圆环使用 innerRadius，勿伪造互补组成。

读取 [完整原生示例](../chart-examples/pie.spec.json)，替换数据、单位、字段、字体及当前空间；这是合成数据，不是人物事实。

所有示例使用 VChart 2.1.7，animation: false。原始 spec 文件生成内嵌 JSON；对深拷贝创建图表，完整接入见 [图表桥接](../chart-bridge.md)。完整系列由图表承担，独立事实和标题由 HTML 承担。


圆环的数值 `innerRadius`、`outerRadius` 都相对于同一个布局半径，内半径应小于外半径。例如 `innerRadius: 0.45, outerRadius: 0.8` 可作为草稿起点，不是固定样式。内外半径相等或颠倒会使环退化或极细；不要把 innerRadius 理解成 outerRadius 的百分比。实际环宽和标签空间须在最终 mount 与阅读尺寸复验；缩小外半径留出长标签时，同时检查内半径。mark 覆盖或动态半径以实际图元为准，静态提示不代替观察。

外部名称太长时增加图表宽度/高度，或使用相邻完整图例与段内数值；不能缩小必需文字直到阅读图不可读。100% 单项份额与多项组成共享分母说明，不能让漂亮圆环弱化单位与限定。

名称移到图例后仍要核对数值是否完整落在环带上；内洞、弧边与标签宽度可能挤压百分比。数值放不下时改为外部百分比及引导线，保留相邻完整名称图例，再看实际阅读图，不能只确认 label.visible 为 true。


静态PNG必须让读者直接配对“完整类别—数值—色段”。多个非高亮类别同色时，只有人名的图例加只有数字的环内标签不能完成配对；改用完整类别+数值的外部标签，或可区分类别颜色及清楚的图例。空间不足时选择横条图，不靠悬停提示补救静态信息。内部百分比可随扇区旋转，先看实际输出；旋转难读时采用水平外部标签或改载体。长名称、数值、必要份额口径在600px整图中均须达到12px基线，给标签分配空间而非缩小文字。
