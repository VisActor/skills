# 实践来源与迁移检查

这里保存两次实践背后的决策，不提供必须沿用的坐标、事实或固定模板。使用本 skill 不要求历史 `output/` 文件存在。

姚明与麦当娜两次实践使用了 AI 人物插画，这是当时的素材选择，不是本 skill 的默认来源。新作品优先使用用户提供或搜索核实的真实图片，保留下面的轮廓编排原则，按实际照片适配构图。

## 姚明：稳定人物与体育证据

- **构图依据：**高挑全身人物可形成稳定纵轴，数据沿两侧与底部组织；身体轮廓决定侧边证据的宽度。
- **数据关系：**赛季得分/篮板是完整系列，交给两张 column；命中与未命中的组成用两张 pie；场次、荣誉和单场纪录作为独立事实。
- **视觉系统：**红色主调、窄体数字、清晰中文；篮球、篮板、盖帽、球衣、选秀、荣誉等图标与指标相邻，形成一致笔触。
- **实际修复：**从统一大粗字调整为主次字重，增加语义图标；未改变统计与轴尺度；大数字的可见字形需要比直觉更宽/更高的保护盒。
- **验收记录：**1200×2160 CSS 画布，2400×4320 PNG；四张图表、42 个 required 区域。数量说明当时的成品，不是新作品最低要求。
- **可迁移原则：**用人物纵轴收束多维体育数据，完整保留赛季缺口、入选与实际出场、常规赛与季后赛等口径差异。

## 麦当娜：不对称动作与音乐证据

- **构图依据：**举手与持麦克风形成不对称轮廓，左侧与右侧信息区错位；手臂跨分隔线，但面部、器具和关键数字互不遮挡；浅唱片纹理统一人物与数据。
- **数据关系：**两类 Billboard 榜单各有范围；五个年代的舞曲榜冠军条目用 column，四次巡演名义票房用 bar；获奖、名人堂、首专年份、售票场次与观众数分别表达。
- **视觉系统：**洋红/深紫/暖白，衬线姓名、窄体数字和中文正文；麦克风、唱片、舞台、门票与荣誉语义共同服务音乐主题。
- **实际修复：**核对 alpha 后按可见轮廓排版；修复字体下探导致的行框溢出；把被默认避让移入柱内的一个数值恢复为清晰外部标签。
- **验收记录：**1240×2200 CSS 画布，2480×4400 PNG；两张图表、30 个 required 区域。格莱美提名口径冲突、唱片销量估计未选作精确事实，保留可证实的历史指标。
- **可迁移原则：**人物姿态与领域语义驱动构图和图标；采用新题材字体、更多图表或更多图标，都不是单独的质量保证。

## 迁移时的决策检查

| 新请求 | 应发生的决策 | 暴露的失效 |
| --- | --- | --- |
| 仅找到可信半身照片，参考是全身人物 | 核实身份/时期，按半身轮廓调整信息区并保留出处 | 为复刻全身布局直接生成替代真人肖像 |
| 另一位有投篮动作的篮球人物，提供赛季数据 | 先看举手/篮球轮廓，再安排完整赛季图表；选择适配身份的颜色与图标 | 只替换姚明名字、头像与数字，仍按旧侧栏坐标放置 |
| 音乐人提供长巡演名称与不同币种 | 先解决币种、范围与比较成立性，再给长名称分配宽证据带 | 无换算依据就比较柱长；省略币种与年份 |
| 科学家仅有几个可靠生涯里程碑 | 用人物、简短事实和事件编排；收紧画布，只有真实数值系列才图表化 | 为追求密度编造引用量，或把事件年份画成柱长 |
| 深色舞台照片完全不透明 | 用实际矩形与色面设计，或按授权使用图片编辑能力；如实记录来源 | 文件是 RGBA 就当成透明人物，文字放进实际背景里 |
| 用户只要求优化现有海报字体与图标 | 保留数据、轴与统计范围，针对字级、字重和语义图标修改并复验 | 无授权改数据、全页构图或生成新人物 |
| 用户明确要求人物 Page Schema | 保留输出技术要求，转入页面工作流并说明能力约束 | 静默生成 HTML，再称其为 Page Schema 成品 |

这些是设计与人工检查情境，不是匹配固定文案的自动测试；新案例出现实际失败后，只把能改变后续决策的通用原因补入相应参考资料。

## 柱图与真实照片构图验证

以明确标注的合成数据制作实际发布 runtime 对照，而非拿截图数值充当人物事实。以下为旧运行版本的历史观察，只用于说明检查方法；当前 2.1.7 必须重新验证，不继承历史通过状态：

- 同一15类别/含零值与极值系列，在1040×400 CSS画图区中，直接读数与带轻网格两种策略均可用；前者紧凑，后者多一个刻度参照，不能因此统一去掉全部图表坐标。
- 最高725标签在0—800范围时被移到柱内，扩展为统一0—900后回到柱外；数据和零基线保持不变。图表高度缩短也会触发这个问题，独立图与嵌入版需要分别查看。
- 密集短编号可以在明确编号含义后展示；完整长名称在同一柱图中明显相撞。改为横向bar后15个名称与数值可读，顺序与数值不变。不能据此把真实作品统一改为编号。该失败对照技术检查通过，证明静态检查不能替代图表局部验收。
- spec类别字符串中的换行在该验证组合中未形成预期双行标签；写入换行不等于解决标签问题，必须看实际渲染。
- 真实周杰伦首尔首映活动照片用于“偏置证据翼”和“周围组织证据”两种草稿，保留矩形照片、原貌与来源，主数字/次级事实拉开层级。偏置方案留出完整图表翼；周围方案让照片承担中轴。两者都是构图验证，图中数值为合成值，不是新完成的周杰伦生涯海报。
- VChart在渲染时改变了mount的定位样式；外层承担整页绝对坐标、内层承担图表尺寸后恢复稳定布局。大数字字体的下探用实测盒子与底部空间修复，不移除 required 标记。

验证记录是独立生成流程的开发证据，不要求安装者持有任何 `output/` 文件。后续人物应按真实类别、数据量、照片形态与交付尺度选择策略，不继承测试的颜色、轴上限或坐标。

## 剪影素材未完成时的边界

外部宿主生成的科比截图中，人物周围残留明显灰色矩形、底部仅渐隐，且主体与图表之间有大段空白。只有截图，无法确认实际是否调用过抠图、候选alpha状态或HTML引用文件；不能把可见失败归因为某个模型/服务。

临时格式试验验证：不透明灰色图返回 `needs-background-removal`；同一灰色矩形加透明边框可返回 `prepared`，但始终保留 `cutoutAcceptance: pending`。这说明alpha格式不是语义抠图证明。剪影路线必须查看真实像素与最终引用文件；照片路线只用于有意保留背景的构图，不能默许剪影处理失败。此试验不证明原科比素材的具体错误，也不提供实际背景分割模型。

## 科比：完整参考对照与跨题材草稿

完整作品采用可追溯的真实运球比赛照片、透明剪影、独立场均指标、冠军年份符号、退役球衣身份与完整20赛季柱图。以相同600px宽度与用户参考并排查看，不再用合成数据的局部图表试验代替成品证据。该作品为1200×1840 CSS、2400×3680 PNG；尺寸记录不构成新默认模板。

- **素材：**身份、时期与场景由原始图片页核实。背景编辑候选重绘了人物细节，被弃用；采用宿主本机分割产生的alpha，并将其作用于原照片RGB。浅底与紫底检查脸、手、篮球、肢体空隙和鞋缘，HTML引用同一结果。宿主分割实现不是skill依赖；真实照片的噪点与原图鞋尖边界另记限制，不用AI补画消除。
- **信息表达：**五个冠军符号分别对应年份，球衣表示8/24号身份，星环与数字表示全明星入选。不同量纲的场均得分/篮板/助攻独立读数，没有复制参考中的组成弧形。自绘图形为语义符号，不冒充官方奖项标志。
- **整页修复：**主指标、场均、号码与荣誉围绕实际动作错位编排，完整赛季带接续人物区。球衣数字的字形下探靠扩大真实行框解决；单场纪录日期主动分行，避开前脚；最佳阵容说明按完整语义分行。
- **图表修复：**20个完整跨年赛季标签在实际宽度下相撞；改用明确解释的四位赛季起始年份，原始数据仍保留完整赛季身份、数值和顺序。峰值单独强调；数值、零基线、全部类别和颜色映射在最终图中复查。
- **数据限制：**不沿用旧文章中的当前历史排名；全明星入选与出场区分，名人堂届别与典礼日期区分；来源中冲突的得分王描述未采用。照片不被标成81分之夜或告别战。

麦当娜迁移草稿重新使用真实舞台照片与有来源的榜单/奖项事实，选择保留背景的偏置照片、衬线姓名、唱片身份和暖粉深色系；没有照搬科比球衣、奖杯、紫金或两侧栏。草稿中唱片圆纹不编码比例，获奖与提名独立显示，没有为了凑图表发明系列。它验证了选择会随题材与素材改变，尚不证明所有音乐人物完整海报都可稳定达到同一质量。
