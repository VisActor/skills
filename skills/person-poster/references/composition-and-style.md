# 构图与视觉系统

## 先决定哪些信息值得看

先写一句人物叙事，再按关系组织证据。例如“跨越联盟的职业生涯”需要赛季趋势、球队阶段与荣誉；“不断重塑的流行力量”需要榜单表现、年代跨度与巡演记录。人物姓名相同，叙事不同，数据区与构图也会不同。

建立三个阅读层次：远看识别人、标题与关键数；中距离读数据分组；近看能读完整类别、时间、单位与限定。模块数量随真实证据变化。可先选少量核心事实，再围绕它们安排可比较的数据系列与简短里程碑；不规定数字、图表或图标配额。

## 参考先转成决定，再做构图草稿

用户给参考图时，在简报记录五项决定：人物与数据的空间关系、主次数字、分组/分隔方式、领域图标语法、图表视觉规则。说明准备沿用的关系以及实际照片/数据带来的调整，不能只写配色或“高级、舞台感”。不复制参考图的事实、坐标或错误数据。

第一次完整生成或重构时，先用实际人物素材、姓名、一个主要指标和有真实大小的数据区做可渲染草稿。草稿使用已核实的数据；设计试验若使用合成值则显著标明，不交付为人物统计。先查看总览：人物是否引导阅读、主数是否比次级信息更强、图表完整标签是否有空间、面部/器具是否受到保护。沿共享边界、基线和分隔节奏关联照片与证据；矩形照片也能用，不要求每次抠图。

“矩形照片能用”只适用于主动选择保留照片背景的构图；依赖剪影的构图先完成真实抠图及素材验收，不用渐隐藏住处理失败。以实际可见人物而非整张图片的矩形判断主体尺度。人物、侧边证据与主图应在总览中形成连续阅读关系；若中部空白将它们割成上下两张图，先调整人物大小、图表位置或画布高度，不靠新增装饰/重复事实填补。

仅当空间关系尚不清楚或当前版明显失败时比较两种草稿；常规编辑不增加双方案或用户确认步骤。草稿通过后再写完整细节，主图的实际标签需求须与构图一起决定。不要先固定等权卡片网格，再把人物放进剩余区域。

## 先分配证据空间，再形成构图

在当前作品的简报中，用短句记录：主证据及其实际标签宽度、关键事实的图形载体、人物姿态与原生裁边、脸/手/器具保护区。先把这些真实大小的内容放入草稿，图形和图表配置只承担局部关系。按 [视觉校准](quality-reference.md) 判断层级和连续性，不预定左右分区、字级或比例。输入关系相同可以得到相近布局，变化来自新的信息与轮廓，不靠随机换色制造差异。

| 当前输入关系 | 空间决定 | 草稿要查看什么 |
| --- | --- | --- |
| 一组完整比较或长类别是主证据 | 先给类别、数值和绘图区足够宽度，人物与次级事实承接剩余连续空间 | 主图是否可直接阅读，人物与主证据是否仍属同一张海报 |
| 多组独立事实适合不同图形 | 将形状、主数与短标签组成局部重心，沿人物的真实空隙组织，允许不同宽高 | 图形是否在整页尺度帮助理解，主次是否清楚 |
| 半身、胸像或带原生裁边的照片 | 用画布边、摄影框或共享证据带承接裁边，再选择人物大小与画布比例 | 裁边是否有落点，照片是否为当前证据留下有效空间 |
| 举手、奔跑、演奏等伸展动作 | 先保护伸出的肢体/器具，再在不规则负空间分配证据 | 动作是否引导阅读，脸/手/器具和数据是否互不竞争 |
| 两个身份或阶段需要比较 | 由同一人物连接不同证据场，共用字号与颜色语义 | 区分是否表达内容关系，跨场文字是否可读 |

这些是空间判断，不是整页模板菜单。居中、偏置、对角或跨色面可以是判断后的结果。用户参考与核实素材优先；胸像、侧脸等同样可用，不为满足全身、居中或双侧栏而默认AI重造人物。

## 从轮廓推导版面

1. 先为姓名/标题预留稳定区域。根据预计数据量确定画布比例和粗略人物位置；1200×2160 这类竖幅只是起点，用户尺寸优先。
2. 检查实际素材的 alpha 边界与关键部位。透明图片的完整矩形通常远大于可见人物，不能用矩形宽度推断主体占比；黑色预览底也不能证明图片不透明。
3. 需要测量时运行 `scripts/inspect_subject.py`。`--place` 对应图像元素实际的、无额外变换的居中 `object-fit: contain` 盒子。先用分带轮廓作保守占位，再目视标出脸、手、器具等语义保护区。
4. 保护区通常从可见轮廓向外留出约 16–24 CSS px 的文字间距，再按字重、姿态和缩略图可读性调整。这个量是起点，不是自动碰撞阈值。
5. 把宽图表放进完整证据带，把独立事实放进身体周围自然形成的空间。人物可压住底纹或分隔线；数据与人物发生竞争时，先调整信息区和素材放置，再考虑换姿势。
6. 对齐共享边界、基线和分隔节奏，允许左右证据区不同高、不同宽。用同一画布的空间关系统一整页。

层级可分为背景/载体、人物、信息三层，但 z-index 更高不代表可以盖住人物面部；信息层与人物关键部位都受保护。轮廓报告是保守几何辅助，不会自动理解头、手、鞋或相邻两块独立空隙。

## 数据密集而可读

- 同一统计系列交给一张完整图表。省掉重复图例、重复卡片与长段解释，把节省的空间留给标注和主体。
- 排版前为关键事实指定主要展示位置：侧栏、图表、荣誉或事件轴。其他位置只提供新的关系或简短交叉提示。荣誉和生涯模块讲相同年份/事件时合并，保留内容差异，不把重复次数当作密度。
- 在整图上检查证据如何沿人物展开：自然负空间可承接一组相关信息，长类别图表可移入完整证据带；人物之后连续堆叠报告区时，重新检查共享边界、视觉载体和阅读流，保持整页联系。
- 侧栏适合独立指标、荣誉、年份与短句；系列标签很长时，调整为宽图表或改变构图，不把长词挤成竖排。
- 作品名、年份范围、数字与单位是阅读语义单元，给它们完整行位或适度 nowrap；普通说明可换行。通过宽度与层级安排断行，避免孤立一两个字，不对整段文字强制禁止换行。
- 独立荣誉可用奖杯/奖章/器具图标序列；图标大小与数量只有在明确编码数值时才承担统计含义，并写清单位。
- 采用 waffle/重复符号表达数量时，让读者能分辨单元、计数单位和少数类别。连续色块被看成柱条时，调整间距/单元形状或改为适合的组成载体；准确比例与完整标签仍由图表负责。
- 由字级、留白和细线形成分组。重复边框和等尺寸卡片若成为主视觉，会削弱人物与跨区证据的联系。
- 数据不足时，收紧画布或改用更强的核心叙事；不补造数字、不靠装饰增加假密度。
- 初排可从标题 90–170、核心数字 100–180、次级数字 40–80、中文标签 20–28 CSS px 试起；这些范围适用于约 1200px 宽画布，不是缩字验收标准。最终必须看导出的阅读尺度与实际测量。

## 字体角色

| 角色 | 选择依据 | 同步范围 |
| --- | --- | --- |
| 人名/主标题 | 体育可用窄体、有力度的字形；音乐/文化可用有辨识度的衬线或展示体 | 主标题与少量同级标识 |
| 数字 | 宽度稳定、形状清晰；配 tabular-nums，区分核心与辅助字重 | KPI、图表数值、年份、百分比 |
| 中文/正文 | 具备全部所需汉字、标点与单位，长短标签都清晰 | 中文、单位、注释、图表中文 |

姚明使用 Oswald + Noto Sans SC；麦当娜增加 Cormorant Garamond 主标题。这证明字体应按角色和题材选择，不要求所有人物沿用这些家族。通常一个展示字体、一个数字字体与一个中文字体足够；可以合并角色，避免无意义增加字体。

每个字重必须对应真实字体文件/变量范围。下载中文子集时按**当前作品全部可见文字**生成，包含图表与标点；前一张海报的子集不保证覆盖新名字。给大数字留足行框和底部空间，依据 `scrollHeight/clientHeight` 修复，不靠裁切隐藏字体下探。

初次预览用 `text-and-chart-data.json` 的实际文字、computed font、行框和溢出数据定位问题，再调整空间。指标是定位辅助；字间距、混合字体、换行和 fallback 仍要看局部图。一次标题溢出不应触发整页改成绝对定位：先检查真实字体、padding、盒模型和所在布局容量。

## 配色、图标与共享载体

- 从人物服装、球队/创作身份或叙事气质中选主色，再选中性色和一个有作用的辅色。图表分类颜色需有稳定含义；装饰与图表不互相争夺色彩。
- 背景中的球场、唱片轨道、舞台或几何色面可以成为共享载体。纯装饰不标注为精确比例，也不遮挡数据；有准确编码的载体属于图表。
- 图标先列语义，再统一填充/描边、线宽、视角和细节。篮板、盖帽、篮球、球衣与选秀属于体育语义；唱片、麦克风、舞台、门票和荣誉属于音乐语义。
- 通用荣誉符号可自绘 SVG；品牌、球队、官方奖项标志需可信素材与来源，不能把自绘符号声称为官方标志。
- 图标放在对应指标附近，以一套比例、对齐和留白规则组织。细节程度随最终尺寸调整；只有意义不重复的图标才值得占用空间。

需要把事实变成奖杯序列、球衣或唱片等表达时，见 [领域图形](domain-graphics.md)。先改变信息的载体和空间关系，再考虑增加图标；完整系列仍归图表。
