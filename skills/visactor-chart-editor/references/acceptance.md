# 编辑器验收要点

按[功能矩阵](standard-parity.md)选择受影响场景，用真实操作与独立结果验证。技能不附带测试工程或历史 JSON 快照；以下是验收要求，不是已执行的通过声明。

## 数据与交互

默认 supermarket 完整数据的销售额为 16,068,954.125，利润为 2,147,538.925。独立解析 CSV 计算，并与查询结果对照，不能只比较同一引擎的两次输出。

覆盖字段搜索、四槽拖拽与重排、日期粒度、数值聚合、别名、格式、排序、WHERE / HAVING、limit、撤销与重做。图型使用合法编码验证，检查 ListTable / PivotTable / PivotChart、图例与竞赛时间轴。空结果清除旧图；无效配置反馈错误，修正后可恢复。保存恢复保留完整 DSL，失败不破坏原配置。

## 视觉与动画

检查桌面与 390px 窄屏、深浅色、中英、全屏、键盘焦点及减少动态效果。图型面板选择后保持展开，悬停不抖动、不误触下方图表；工具栏同高且操作可达。指标为绿色，维度跟随主题，外框保持中性色。

初始化需先显示加载卡片，首图或合法空态就绪后展示工作区。检查失败重试、超时、关闭清理；语言、主题、动画偏好刷新后恢复，无效或不可用 localStorage 不阻塞操作。

Morph 必须采集中间帧，验证多个不同路径、有限坐标、连续图元与结束清理，并与独立新建目标图比较终态。淡入验证透明度变化与稳定几何；不能用终态截图或“没有报错”代替过程验收。边界见 [Morph 经验](morph-analysis.md)。

## 导出与离线运行

解析真实下载的 CSV / XLSX，检查别名列头、筛选聚合值、排序与 limit、中文、换行、引号、空值、负数及公式样式文本；Excel 保留数值类型。验证数据复制及 PNG 下载 / 剪贴板写入，覆盖普通图、表格与分面图；图片只包含当前绘图区，表格为当前视口。剪贴板权限被拒时提示清楚且下载可用，忙态和空态禁用导出。

将完整 HTML 复制到空目录，在断网浏览器上下文通过 file:// 打开。验证数据、图表、表格、主题与导出，无额外 HTTP 请求或未处理异常。检查快速连续切换、页面关闭和实例释放。

在源码仓库做对照时可启动文档服务，访问实际地址下的 `/VBI/vbi/practices/standard.html`。包源码变更另按仓库开发规范验证；模板浏览器验收不能替代包测试。记录本次实际结果与必要的中间帧证据，完成后停止自己启动的服务，不将临时日志、历史快照或测试工程放入技能分发包。
