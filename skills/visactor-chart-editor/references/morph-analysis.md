# ChartEditor Morph 经验

通用排查与验收方法见 [visual-query 的 Morph 经验](visual-query/references/morph-transitions.md)。这里保留编辑器当前实现的边界，避免把历史方案当成现行逻辑。

## 所有权与数据身份

修正优先落在 VSeed 的 DSL、主题和管线；模板只管理实例更新，不二次改写生成的 spec 或引擎私有方法。`animation.morph` 可显式开关，内置深浅主题默认开启，图表显式配置优先；整体关闭动画与系统减少动态效果仍有更高优先级。

`animationMorph` 引用已有 `DimensionKey`，不遍历或复制 `data.values`。完整维度身份在 `unfoldDimensions` 原有行遍历中生成：按字段名排序的原始维度元组，排除折叠指标。不同指标共享维度组，允许柱条与双轴拆分、合并；保留原生数据 key 和 mark key。

只有需要隔离几何结构的管线传入 chartType，例如雷达使用 `createReshapeWithEncoding('radar')` / `createPivotReshapeWithEncoding('radar')`。不要给所有图型都加独立前缀，否则跨图型的有效匹配会失效。

## 实例与内部模型复用

启用动画时，公开 `updateSpec` 更新参数使用 `reuse: false`，让 VChart 执行原生匹配与 morph。矩形复用可能抢先走普通属性补间，导致柱条换向或条形图切双轴时没有路径变形。只看顶层 `type: bar` 会漏掉顶层为 common 的双轴图。

DSL chartType 改变时，通过 `updateSpec` 第四参数 `{ change: true, reMake: true }` 重建内部模型，同时保留 VChart 实例。普通与并列图可能共享底层 bar 类型，仅关闭图元 reuse 不能避免旧分组模型残留。Morph 开关变化也需要重建模型，更新旧 mark 的动画资格；仅数据变化不强制重建。

记录实际完成更新的图型，并串行处理最新请求，避免快速切换使用过期状态。引擎类别变化或减少动态效果偏好改变时按需重建实例；释放观察器、事件和透视图过滤回调。相同图型的数据更新可能是普通属性补间，不要求出现路径 morph。

## 不适合路径变形的场景

- 饼 / 环的非正值会形成零角度扇区；通用路径转换可能在中间帧生成大圆。VSeed 复用折叠统计判断，在这类输入下采用原生淡入，保留原数据、终态及显式动画配置。正值饼环继续支持路径变形。
- 雷达的面和线不支持与点相同的路径 morph。热力格子只变成点会与独立出现的面叠加，产生奇怪飞入效果。雷达使用独立身份范围，跨结构切换协调淡入；显式 radial 动画仍保留。
- 层级图的原生主体 mark 不一定启用 morph。旭日图与矩形树图保持原行为，不因终态正确就宣称支持相互路径变形。

## 过程验收

柱、条、普通 / 并列 / 百分比、双轴双向切换要检查连续中间路径、有限坐标、临时子图元清理和独立新建目标图的终态。补充快速打断、多维正值饼环、真实含非正利润的饼环、热力与雷达，以及关闭后重新开启 morph。

路径变形、普通属性补间和淡入分别验收。路径至少有三个不同中间状态；淡入检查透明度与稳定几何。数据更新用不同类别的相对数值变化，避免整体倍增被自动坐标缩放抵消。减少动态效果验证实际几何稳定，不只检查顶层 animation 字段。最终截图不能替代这些检查。
