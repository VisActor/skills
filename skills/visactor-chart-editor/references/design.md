# 工作台视觉规范

[完整 HTML](../templates/template.html) 是视觉基线；[桌面](../templates/desktop.png)与[窄屏](../templates/mobile.png)展示可运行默认态。

- 桌面 236px 字段区配弹性主工作区；主区依次为工具栏、四槽和大幅图表。700px 以下纵向排列，字段列表独立滚动，工具栏按功能分成两行，页面本身不横向溢出。
- 中性雾灰背景与白色阅读面，主题色只轻微影响背景冷暖，1px 中性边界保持工作区层次。强调色集中于选中、焦点和图形，品牌栏、字段和操作区有稳定层级，避免额外装饰挤占绘图区。次级文字与所在背景至少保持 4.5:1 对比度，不能依靠降低文字透明度营造玻璃感。
- 图型、导出、历史、数量 / 全屏与设置组成五个独立工具分组；分组容器和设置弹层是仅有的玻璃控件层：从当前主题的 `--surface` 派生半透明底色，使用单层背景模糊、内缘高光和柔和阴影。字段列表、四槽、主题预览卡和绘图区仍用稳定的阅读面；不对图表或文字做折射。工具栏按钮在悬停和按下时给出轻反馈，语言选中面连续移动。减少透明效果、强制色彩或缺少 `backdrop-filter` 时回退为实色；减少动态效果时直接呈现最终态。
- 用户要求去掉外围宣传、数据源条、额外操作按钮、CSV 上传、色板、配置面板、图表标题 / 副标题、结果数量 / 悬停说明 / 成功状态和 Live Preview 标签；编辑区直接接在品牌栏下方。保留图表工具栏中的图型、上限、history 与全屏；中英语言及外观放在工具栏全屏按钮右侧的设置面板。绘图区填满余下空间；页脚仅保留右对齐 `Powered By VisActor`，高约 21px，不另外占用大块留白。提示用自然语言解释操作与结果，避免展示函数名、内部图型代号或框架名称。
- 完整字段可搜索、展开、筛选，四槽保持维度 / 指标 / 明细过滤 / 结果过滤的语义。拖入位置、选中、可编辑、删除、加载和无数据状态清楚，长字段仍有读取路径。
- 设置面板提供浅色经典 / 朝霞 / 花园 / 典藏 / 冰蓝 / 樱粉、深色经典 / 午夜 / 极光 / 石墨共 10 套主题，默认 VSeed 原生浅色。主题卡片仅用底色和四色色点预览，同步选择明暗模式和配色，不另设深浅色开关；提供选中状态、键盘焦点、Escape / 关闭按钮 / 点击面板外部关闭和焦点归还。设置面板宽 356px、圆角 28px；700px 以下贴近底部，左右留 10px、底部留 12px，最大高度 82dvh，可独立滚动。顶部标题为 14px、标识为 24px；桌面工具栏按钮高 28px，分组内边距 3px、组间距 8px，图型入口宽 140px。窄屏或带粗指针的触控设备保留 44px 点击高度，设置入口为桌面 36px / 触控 52px。
- 颜色通过 CSS `--accent` 与 VSeed `color.colorScheme` 驱动；图例、坐标、tooltip、格式和单位沿用原生图型。多系列色彩可区分，主题切换同步控件与 Canvas，不能只改页面背景。
- 配色只改变填色，不给堆叠柱 / 条增加描边；通过 VSeed `barStyle.barBorderWidth: 0` 保持接缝干净。界面边界使用随明暗适配的中性色，不按主题染色。
- 表格沿用 VSeed → ListTable / PivotTable / PivotChart，保持完整透视布局与原生滚动；不以普通 HTML 表格替代，也不把入场透明帧当作正常对比度。
- VChart 更新保持实例与 morph：普通更新使用 650ms cubicInOut，可配对图元使用引擎原生路径变形；不强制统一图元标识，VChart 2.1.7 跨图元 morph 的真实时长不受此 650ms 完整控制。首图就绪后直接呈现稳定工作区，移除装饰性整页入场及其中断监听。按钮悬停 / 按下约 160ms，语言选中面约 240ms；设置面板展开 220ms、收回 160ms；全程不模糊文字或移动拖拽目标。reduced-motion 直接最终态；全屏和 resize 后重新测量。
- 查询错误与空结果覆盖旧图而保留配置；导入错误保留有效 Builder。错误、焦点、弹层和 tooltip 均不能被外壳遮挡。

以相同数据、视口、缩放核对默认态、环图、表格、深色、空态与窄屏。除动画结束截图外，保存 morph 中间帧，核对实例复用与真实变形。[验收矩阵](standard-parity.md)负责行为证明，截图负责人工阅读质量。

设计参考 Apple [材质](https://developer.apple.com/design/human-interface-guidelines/materials)、[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars)与[无障碍](https://developer.apple.com/design/human-interface-guidelines/accessibility)原则：玻璃用于操作层，内容层保持稳定对比度；Web 用 CSS 渐变、单层背景模糊与内缘高光近似材质，不模拟图表折射。

查询或导出超过 150ms 时，仅触发控件显示文字右侧的旋转图标，并用 180ms 展开 / 收回宽度，空闲不占位；主题卡片在既有选中标记处反馈，保持网格稳定。重新查询时保留已加载图表，绘图区置灰；查询到绘制完成使用同一条“正在加载图表…”提示，完成或错误后撤下提示并清理控件状态。提示使用可访问状态区域，等待期间仅拦截旧图交互，字段和筛选仍可继续操作；页面初次加载沿用独立加载层。反馈只由宿主 UI 管理，不写入 DSL。

Header 仅保留自绘四格几何占位标识和“自助式分析”（English 为 Self-service Analytics），不放外部品牌、工作空间路径或右侧标语。冰蓝 / 樱粉使用同色系浅至深色阶，朝霞使用灰紫至珊瑚粉的连续色盘；控件强调色单独保证可读性，不能将其覆盖到首个图表系列。预览从完整色盘等距抽取 4 色，图表使用完整色盘。

花园使用 `8F7289 / ED7B61 / 29A15C / 529AC9 / D5B2BD / F6B09C / 9CCBA7 / 99BADF`；典藏使用 `073F7F / 866AA3 / BE0E23 / F49600 / 83A0BE / C1B7CF / E18791 / F9CB80`，替代原浅色青瓷与杏茶，浅色与深色独立选择。

深色第一项“经典”使用 VSeed 原生深色主题：预览色通过公开 `darkTheme()` 读取，渲染不覆盖 `color`，保留原生分类 / 连续色阶。午夜采用蓝灰层次与蓝青金色，极光采用中性紫灰层次与紫青绿，石墨采用中性炭灰与橙青蓝；主题明暗 / 图表交互仍走 Builder。页面初始默认 VSeed 原生浅色，不因为深色区顺序而改为暗色。名称统一为“自助式分析” / “Self-service Analytics”，包含 Header 与浏览器标题。

控件强调色与图表系列独立：朝霞、冰蓝、樱粉使用更深的玫瑰灰、钢蓝和莓粉，深色经典使用柔和亮蓝 `#6B92FF`，图表原有色盘保持完整。十套外观使用同一套主文字 / 次级文字 / 阅读面 / 背景语义，深色保持背景最暗、阅读面略亮、玻璃高光克制的层次；遮罩按明暗模式调整，避免暗色弹层边界消失。

浅色第一项“经典”与深色第一项对称：通过公开 `lightTheme()` 读取预览，使用原生浅色强调色 `#8D72F6`，渲染不覆盖分类 / 连续色阶。默认外观为 `classic-light`；切换到原生深色时选择 `classic-dark`。

## 控件与弹层的一致性

- 菜单、图型面板、选择器和浮层使用同一套几何：外圆角 20px，菜单内边距 8px、条目圆角 12px。设置面板保留 28px，主题卡片保留 16px / 内样本 10px 的嵌套关系。玻璃仅应用于浮层外壳，内容和图表维持稳定底色。
- 菜单条目统一行距、图标列和留白，选中项包含勾选标记；键盘焦点覆盖挂载到 body 的浮层。图型卡片保留完整名称、描述提示与选中边界，长字段和菜单文字可换行，数字采用等宽数字排印。
- Ant Design 菜单继续使用原生定位、打开 / 关闭生命周期与方向动效，共用 120 / 180 / 220ms 动效 token。设置面板由触发点定位并双向过渡，窗口尺寸变化后重定位；中断时从当前画面继续，关闭完成后归还焦点。减少动态效果偏好直接结束过渡。
- 连续操作同一控件保持其 loading 旋转与宽度，不重新收回再展开；图表查询到渲染完成保持同一状态文案。拖拽落点使用固定尺寸与 opacity / transform 反馈，拖拽坐标和业务行为仍由原组件负责。
- `any-pointer: coarse` 和窄屏共同决定触控尺寸，窗口宽度单独决定单行 / 双行工具栏布局。字段、配置标签、菜单项和按钮提供至少 44px 点击高度；触控下显式显示标签移除入口，输入文字为 16px。浮层限制在可视区域内并可滚动，低透明、强制色彩和减少动态效果的回退覆盖共用浮层。
