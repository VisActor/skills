# 分析与决策

帮助用户从现象形成可核对的判断，再确定下一步。主页突出主要发现，主动探索逐步增加解释与证据；分析按任务需要展开，不要求每个指标都有弹窗或凑齐固定图表。

本篇负责分析方法、证据和探索动线。查询与渲染按 [visual-query](../visual-query/guide.md)，地图任务补读[空间分析](map.md)；外观和组件实现沿用宿主。

## 先明确指标与问题

设计页面前形成简短的分析计划，用于选择内容，无需另建文件或全部展示：

- **判断与行动：** 谁使用结果，要决定、核查或观察什么；已知目标、可控因素、资源与时限是什么。关键定义缺失会改变结论时先澄清，其余可继续取证。
- **数据能力：** 事实粒度、稳定 ID、单位、公式、时间和地域覆盖、可用维度、明细及缺失项；区分实体快照、事件和汇总。
- **候选问题：** 从目标和初步数据选择少量值得验证的问题，说明比较基准、可能解释、什么证据会支持或推翻判断。探索结果可以否定最初假设。
- **下一步路径：** 从发现进入哪项比较或检验，如何核对记录、返回总体；最终支持什么行动，或需要补什么证据。

只有日期覆盖与粒度可比时才做周期变化；真实父子关系支持层级下钻。已有页面局部修改只重审受影响的问题与证据。

## 按问题选择分析方法

先计算，再选择能回答问题的表达。下表是候选方法，不是页面必须具备的模块；简单图表可以支持深入判断。

| 问题                         | 所需证据与方法                                                           | 可选表达                 |
| ---------------------------- | ------------------------------------------------------------------------ | ------------------------ |
| 变化值得关注吗，发生在何时？ | 可比基期、完整时间窗口、绝对差异与相对变化；有依据时检验季节性或异常     | 趋势、两期差异、日历热图 |
| 差异集中在哪些对象？         | 总体与分组的量、占比和分母；仅对互斥且可加指标计算变化贡献               | 排行、帕累托、差异条图   |
| 均值掩盖了什么？             | 样本量、中位数、分位、分布和极端记录，区分普遍偏移与少量尾部             | 直方图、箱线图、分位点图 |
| 哪些因素与现象共同变化？     | 同一事实粒度的联合分布，必要时按相关维度分层；核查组内与总体方向是否一致 | 散点、分面、交叉热图     |
| 结论是否依赖分析选择？       | 对合理的样本门槛、权重、阈值或时间窗口做敏感性比较，保留原口径           | 多口径对照、排名稳定性   |
| 接下来先处理谁？             | 并列观察影响、规模、证据质量；成本与容量已知时再评价可行性               | 优先队列、矩阵、记录表   |

“最高／最低”和均值可作为起点。继续检查差异大小、内部异质性及解释是否稳定，避免所有入口都重复同一排行。区间估计或统计检验需符合抽样与独立性等条件，描述性样本不能因画了置信区间就代表总体。

## 数据形态与比较口径

- 实体快照按稳定业务键计数，事件按事件 ID 去重并区分发生、修订与截止时间；快照没有历史时不生成增长。时间比较使用明确时区、可比覆盖与同类业务条件，不完整时段和缺失记录单独说明。
- 总体从完整有效范围重算，不平均分组均值，不累加重叠分组去重数。比率使用同范围分子分母，说明权重；组别构成变化可能影响总体，必要时分层比较。
- 合法零与负值保留，空结果计数显示0；无定义的均值、极值、零分母比率显示缺失。计算保留精度，仅展示时舍入。变化说明基数，百分点与相对百分比区分；方向和好坏按业务解释。
- Top N、抽样与分批加载明确范围，不能由可见行估算总体。分组样本量与未覆盖部分影响结论时一起呈现。

## 发现、解释与行动

每条重要发现应能回答：**哪个范围出现什么差异、幅度多大、相对什么、依据在哪里。** 必要的样本量、权重、数据时间与限制就近呈现，详细口径按需展开。

- **事实：** 引用实际计算结果，图表和 VTable 能核对到同一范围及粒度。筛选变化后重算发现与证据，旧文案不能描述新条件。
- **解释：** 将关联、候选原因与已验证原因区分。对关键解释检查可用的反证或替代解释，如样本结构、覆盖、缺失及极端值；缺乏证据时保留为假设，不从相关性直接写成因果。
- **行动：** 指出证据支持的对象与下一步，可以是复核、补采、继续观察或业务行动。若建议干预，说明预期观察指标与验证方式；效果预测、优先分数、成本和阈值必须有定义与依据。
- **停止条件：** 问题已被足够证据回答时停止扩图；差异不稳定、数据不足或没有可靠发现时如实说明。数据缺口应明确到需要的字段、历史、覆盖或业务定义。

模型总结只消费已计算的值、公式、范围、比较结果及有效性，不猜测缺失指标。可保存的指标定义、分析关系、条件与计算交给所属 DSL 和公开 Builder；缺少支持时说明边界。保存发现文案不能替代可重算的定义，API 按需查 [VBI](../api/vbi/guide.md)。

## 入口与容器接入

有独立分析价值时提供可发现、键盘可达的入口；只有定义时标为口径说明。沿用宿主轻量入口和分析容器，图表标题、图元选择与独立定位各自保留含义，避免一次手势重复触发。

详情先回答概览尚未回答的问题，再就近提供相关比较或验证动作。不同指标可复用容器，但问题、方法与证据按指标决定。明细使用 VTable，行粒度应支持当前发现；只有聚合结果时如实说明不能穿透原始实体。

## 分组选择与完整结果

- 图表与分组入口读写同一选择；Top N 外分组仍可访问，必要时保留已选项和总体比较背景。切换维度清除失效局部条件，选中项及清除方式可见。
- 分组菜单和汇总覆盖完整有效范围；VTable 使用完整结果与虚拟滚动，不增加手工分页器或按固定行数切片。远程分批取数需说明加载范围，不静默截断；只有确有后续问题时才开放明细继续分析。

## 范围、联动与返回

进入分析捕获已确认的时间、地域与业务范围，保留指标固有条件。悬停只预览；图元确认才叠加条件。分析内选择默认只影响关联读数、发现、图形和明细，明确“应用到看板”才改变主页。

自动刷新明确采用冻结截止点或同步刷新策略，同一分析读数和证据一致。返回恢复上级范围与选择，关闭保留主页筛选、视野和入口焦点；关闭、重开和快速切换不能让旧请求覆盖新结果。按[组合与联动](../visual-query/references/composition.md)复用连接、按需查询、取消请求并释放临时 Builder 和实例。

## 交互与平滑更新

复用宿主控件、主题和加载反馈；保持已呈现内容与布局，原位更新图表和 VTable，不在筛选时重播入场。趋势区域点击与 crosshair 使用同一真实维度映射，提供触屏和键盘等价入口；悬停不隐式提交条件。浮层优先处理 Escape，关闭与返回始终可达。

具体更新接口、表格主题与生命周期查[HTML 接入](../visual-query/references/html-integration.md)、[表格适配](../visual-query/references/table-theme.md)和[组合指南](../visual-query/references/composition.md)，本篇不重复样式参数或动画时长。

## 验收

1. 从页面能看出正在回答什么问题、采用什么比较基准，以及当前结果支持的下一步；没有可靠发现时说明原因和数据缺口。
2. 重要发现可由独立读取的源数据或查询证据复算，覆盖总体与有意义的筛选范围；样本量、权重、分母、缺失与不可比情况解释正确。
3. 关键解释已检查可用的替代解释或明确尚待验证；合理口径变化使判断反转时予以说明。不能只以图表种类、统计量数量或数据无误评定分析深度。
4. 实际完成“发现 → 比较或检验 → 记录核对 → 返回”，确认每步增加有用证据，范围、发现与完整明细一致，Top N 不阻断核查。
5. 核对宿主交互、键盘、窄屏、空结果、失败及过期请求；按改动范围验证，不将源码检查或历史结果作为本次体验证据。
