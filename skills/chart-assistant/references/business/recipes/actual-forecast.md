# 实际与已给定预测

用于同一指标在明确截止点前后的实际与预测走势，复用内置 `line` 和[虚实折线](../../solid-dashed-line.md)。[完整实例](../../../examples/business/actual-forecast/common-option.json)使用合成数据：2026年1—3月实际销售额为100、110、105，4—6月已给定预测为120、125、130。没有给定业务单位，实例不编造单位；示例值、期间和截止点不得带入用户数据。本配方不生成预测算法，不根据当前日期、空值或增长走势自动推断截止点。

## 1. 先确认预测和边界

需要同一业务对象、指标、期间粒度、可比较口径、已给定预测值及明确实际截止点。截止点为3月意味着4月开始预测，3月到4月的连接使用虚线；用户要求不同连接起点时按其说明执行。

- 缺少预测值时请求补充，不把最后实际值向后复制、不插值、不外推。缺少截止点或实际／预测角色时先澄清，不以当前日期自动分段。
- 保留真实0、负值及缺失值：0是有效观测，`null`不是0。负销售额是否具有业务含义按输入确认，不取绝对值或截零；缺失值不补零，也不制造一段连续趋势。
- 时间顺序按真实期间核对，数字月份不能按字符串形成1、10、2月顺序。跨年使用完整年月；排序移动整行，保持实际与预测对应。
- 同一期间有实际与预测两个不同值时，先确认是在比较重叠期间的预测误差，还是展示截至点后的预测。不能把两个不同的截止点值当成同一接点、覆盖源实际或静默丢弃源预测。
- 多业务对象各自保留完整业务键、实际和预测；不能将一个对象的截止值连接到另一个对象。不同单位、粒度或指标先澄清。

## 2. 同一对象拆两列，接点只用于画线

本地数据或明确允许转换的 snapshot 可以拆列，实例使用以下完整宽表：

| 月份 | 实际 | 预测 |
| --- | ---: | ---: |
| 2026-01 | 100 | null |
| 2026-02 | 110 | null |
| 2026-03 | 105 | 105 |
| 2026-04 | null | 120 |
| 2026-05 | null | 125 |
| 2026-06 | null | 130 |

映射为 `{"x":"月份","y":["实际","预测"]}`。3月预测列的105是连接锚点，不是新增预测观测。真实实际合计为315，真实4—6月预测合计为375；若业务允许跨实际与预测合计，六个月为690，不能直接把拆列全部值求和得到795。默认不主动增加合计、附表或累计标注；请求合计时先确认期间及实际与预测能否混合。

段外填 `null`，不能补0；真实缺失仍缺失。若截止点实际值缺失，不能伪造接点或用前一期冒充截止点，应说明无法在该点连续衔接，按完整已有数据呈现断点或请求补充。拆列并重复接点属于物化转换，不是来源的新增记录。

## 3. 已核对身份与稳定表达

实例复用[单对象虚实折线完整示例](../../../examples/solid-dashed-line.json)相同内置模板和数据形状下的模型身份：`series-0`、`series-1`；分组样式的实际键与两列名一致，为`实际`、`预测`。只在此结构下复用身份，其他输入结构从物化或readback获取，不能按列数猜series数量或ID。

两段使用同色、同线宽、同点样式。实线 `line.style.lineDash:[0]`，虚线 `[8,6]`，写入真实 `dataGroupSpec` 分组的 `line`；不使用叠加普通线或marker伪装预测走势。关闭两个实际series的 `spec.seriesLabel.visible`，本例还关闭普通值label及图例，由标题说明虚实含义，避免截止点重复数值标签和长系列名引线。若用户要求图例，沿虚实折线的真实图例项映射分别配置实线／分段路径符号，不能只改文字后声称符号已区分。

按[MBB规范](../../mbb.md)保留已知期间、指标与主题，默认标题如“2026年1—6月销售额实际与预测”，次级说明“实线：实际（截至3月）；虚线：已给定预测（4—6月）”。rich标题换行片段承载说明；标题不写死增长率、最高预测值或结论。未知期间或单位省略，明确静态结论标题按用户要求保留并说明改数后的更新限制。

完整年月保留在原始数据中，不为了窄图把2026-01等改成丢失年份的单月文本。实例沿[轴标签协议](../../model-spec.md#3-axismodelspec)显式采用底轴 `sampling:false` 及 `label.autoHide:true/autoRotate:false/overlapStrategy:"autoHide"`，配合现有TextStyle.angle布局，在空间不足时隐藏部分轴文字以避让，源月份和全部观测保留，不缩小主题字号或编造formatter。窄容器仍须开发回归核对最终可读性，不能将此配置视为全部尺寸已通过。

本例为静态snapshot，不绑定公式。手动将截止点实际105改为108，只改该单元格不会自动更新预测列的连接锚点105；需要按同一对象同步更新两列的截止值为108，才保持连续。接点更新不改变4—6月给定预测；图表不会自动重新计算预测、截止点或回复中的合计。生成或明确请求复核时检查接点一致，不承诺人工改数自动告警。

## 4. 来源与交付检查

来源资格单独按[来源与同步](../../sources-and-sync.md)核对。`direct-live` Sheet必须由源表提供可直接消费的两段列；模型侧拆列后不能声称原URL自动同步。需要转换时说明snapshot及手动重建边界，`source.pageUrl`不等于可同步。

按[commonOption交付前校验](../../workflow.md#commonoption-交付前校验)核对配置，并检查原始观测、截止点、空值、真实0、接点相等、接点仅计一次、同对象同色、虚实线型和实际seriesLabel关闭。结构校验不证明线型命中和业务口径一致。

开发回归单独覆盖截止点及给定预测编辑、撤销重做、保存重开、缺失断点、真实0、窄容器及PNG。固定实例、模型工作流、真实宿主和来源同步分别记录，不把已生成配置称为真实宿主验收通过。

窄容器中的完整年月标签可按原生轴标签autoHide避让，保留所有源月份与数据点，不缩字号、改时间语义或填补缺失。图面只显示部分轴文字不等于丢弃观测；其余月份可经数据或交互读取。自动旋转配置是否生效须实际核查，不由JSON合法推定。
