# 参照与时间基准

同一对象的当前水平和相对增长可能给出不同的排名。事件当时跌得最深的对象，也可能最早恢复。先确定读者需要比较哪两个事实，再决定是否并列视图。目标与实际、同比差异见[基准比较](baseline-comparison.md)，实际与预测的分段见[实际与预测](actual-forecast.md)。

## 选择参照

| 读者要比较什么 | 需要的数值和口径 |
| --- | --- |
| 当前谁的水平高 | 同一期间的原始值。比例注明分母，条形长度从零开始 |
| 谁相对自身基期增长更快 | 外部已给定的基期 100 指数或相对变化率，标明基期和度量单位 |
| 比例本身相差多少 | 百分点差，可同时展示两个原始比例，便于还原起点 |
| 不同日期的事件之后怎样变化 | 横轴取各自事件后的相对日、周或月。纵轴可用原始水平、相对基准的差额、百分点变化或指数 |

确定对象键、指标定义、期间、分母、比例尺度和数值基期。事件比较还需每个对象的事件日期、相对时间单位、观察截止及空值含义。日历月偏移与固定 30 天含义不同。日期对齐、重基、聚合和业务指标计算由外部工具完成。若输入只有原始记录，先请求所需组件结果。两组实例共用一份[合成输入](../../../examples/business/reference-time/input.json)。

## 当前水平与基期指数

当问题同时关心“谁领先”和“谁在追赶”时，让读者先在条形图中找到重点对象，再沿相同颜色到趋势图中找到它。[水平与基期指数实例](../../../examples/business/reference-time/level-and-index.json)用 `horizontalBarGroup` 展示各渠道当期新客转化率，把社群运营、直播带货和其他渠道都保留在左侧横条中，条尾显示当前比例。右侧用 `line` 从同一个月、各自的基期值出发，背景轨迹作比较，重点轨迹在终点标出身份和指数。两侧的短标题分别说明数据支持的发现。

- **确定哪些对象需要一路追踪。** 重点由比较问题和数据决定。同一对象在两栏用同一强调色，其余对象按需减弱。若要区分每个对象，则保留足够的身份标识。只有一个问题时，一栏就可能足够。
- **让单位帮助读者判断。** 左栏按原始比例格式显示，社群运营从基期的 10.0% 升到当前的 13.2%，组件保存 0.132，条尾显示 13.2%。右栏把各自基期设为 100，社群运营的指数 132 表示较自身基期增长 32%。若读者问转化率本身提高多少，答案是 3.2 个百分点，已按百分点给出的差值使用普通数值格式。
- **确认基期有比较意义。** 各对象起点都设为 100 会隐藏原有水平差异。零基期无法计算普通比值，负基期和异常小基数也可能使常规“增长更快”的解读失效。缺少有效基期或口径变化时，请求明确的替代参照。有对象被排除时，在相应面板说明范围。
- **按图面决定标签。** 读者需要认出少数重点对象并比较终值时，优先在对应线尾直标，核对最后一个有效点、图面留白及相邻标签间距。图例已能低成本辨认所有系列且终值无关时，可只用图例。本例用两个点标注按月份与指标命中末点，名称作为文字前缀，数值取自该点。追加月份或更名时同步更新目标与前缀。系列标签和普通点标签分别配置，见[标签](../../labels.md)。

## 事件跌幅与恢复轨迹

[事件对齐实例](../../../examples/business/reference-time/event-alignment.json)按事件逐行排列。左栏用 `dumbbell` 连起同一门店的事件月水平和共同观察期（第 1 至第 8 月）内的最低水平，各行沿用同一套端点配色，标出原始比例及下降的百分点数。右栏同一行画该门店截至观察日的转化率变化。读者可以从左侧跌幅最大的行，横向找到它何时跌破基准、是否回到基准，以及观察结束时还相差多少。若输入只有轨迹，没有原始水平或可比低点，就只展示有依据的部分。

- **让面板可比。** 同组端点使用同一比例轴。右侧各行使用相同的横轴范围、纵轴范围和绘图宽度，使同样长的一个月、同样大的一个百分点在每行占据相同距离。横轴 0 对应各自事件日期，水平参照由纵轴的数值基期决定。数值基期也可以是事件前月或外部给定区间，须由输入明确。
- **分别绑定事件和水平参照。** 用已有[参考线](../../semantic-marker-anchors.md#4-直线field--value必要时-bindaxis)把事件 0 绑定到实际相对时间字段，把水平参照绑定到对应数值字段。百分点变化的基准是 0，基期指数的基准是 100。同一坐标系内共享一个参照即可。月份等距且有序时可用分类轴。实际间隔不等且距离有意义时，按已有底轴配置使用数值间距（`type:"linear", linearToBand:false`），并核对渲染位置。
- **让每条线停在自己的观察截止。** 对未观察部分保留 `null` 并用 `invalidType:"break"` 停线或断线。标签跟随最后的有效观测，注明会影响比较的截止差异。例如南站店只观察到第 8 月，之后的公共横轴留白。数据缺报与尚未观察都可能表现为 `null`，其含义由输入提供。
- **比较恢复速度时使用共同观察窗口。** 对象自身的较晚记录可以保留，但只能在都有观测的相对时间段内作横向判断。“截至本期仍低于基准”有明确的观察边界。判断“恢复最快”还需统一恢复标准，如首次回到基准或连续数期高于基准。前后轨迹本身不能证明因果。

## 编辑与交付

配色、图数、分组、排版和标注密度按问题选择。画布保留读者理解结论所需的标题、单位、基期及观察窗口。讲解与下一步建议按需提供。

换数时读取最新完整编辑态，按对象和事件键更新授权范围内的组件。原始比例、独立指数、端点、跌幅和轨迹都是各自保存的组件结果。修改某个原始值或移动参照线不会重算其他值。重定基期或调整事件日期需要外部提供新的对齐结果。按[换数流程](performance-page.md#agent-换数保留人工编辑)处理本次受影响的对象顺序与颜色、端点、面板尺度、参照绑定、末端标签、观察截止和[结论标题](baseline-comparison.md#稳定主题标题)，保留仍适用的人工编辑。

转换过的结果按[来源协议](../../sources-and-sync.md)判断 direct-live 资格，不将转换或对齐后的快照称为未经转换的URL自动同步。
