# 商务任务入口

先识别要回答的业务问题，再选已有图型；用户明确图型优先。业务角色一般是生成时的判断依据；明确支持新开发宿主时，统计分布与受限持续评价可使用下面的专用协议，不生成任意表达式或经营归因。

| 用户任务 | 当前入口 | 输入要求与边界 |
| --- | --- | --- |
| 实际对预算、同比基准、同口径目标差距 | [基准比较配方](recipes/baseline-comparison.md) | 成对主值、单位、期间、唯一业务键；含差额、差异率及百分点 |
| 实际与已给定预测 | [实际与预测配方](recipes/actual-forecast.md) | 需要已给定预测与截止点；接点重复仅画线，不重复合计或生成预测算法 |
| 已知因素构成利润／现金变化 | [已知贡献桥配方](recipes/known-driver-bridge.md) | 数值起点、已知有符号贡献、累计小计与源终点核对；不从两期利润推导经营原因 |
| 同时比较规模和构成 | [规模与结构配方](recipes/size-and-mix.md) | 真实规模与组成，核对独立总量、非负值及静态带宽更新边界；不能由占比虚构规模 |
| 直方图／箱线图、层级差异持续评价 | [统计与评价配方](recipes/statistical-and-evaluation.md) | 新开发宿主需明确支持；分箱／四分位规则明确后才生成；方向 unknown 不判好坏，用户覆盖优先 |
| 多图共同排序／尺度、图表附表组合 | [多图与组合配方](recipes/linked-charts.md) | 相同本地快照和唯一类别、明确单位换算；关系由开发编辑器建立，不从 commonOption 注入 |
| 排名、构成、关系、流程、分布 | [选图](../templates.md)、[自动洞察](../auto-insights.md) | 先检查输入和表达增量；本入口不表示全业务场景已验收 |

所有新建任务执行 [MBB 规范](../mbb.md)，包括其中的商务角色与填充规则；用户已有样式和明确偏好优先。默认只交付请求所需图表，不自动增加附表、文档或数据来源。来源资格按 [来源与同步](../sources-and-sync.md) 单独判断。

配方及示例说明配置如何生成；不证明模型首次生成、生产宿主、改数或同步已通过验收。
