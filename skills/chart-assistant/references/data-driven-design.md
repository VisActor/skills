# 数据驱动的表达、样式与布局

新建图表或整体优化时使用本页，无需指定 OWID、MBB 或其他风格关键词。局部编辑只应用与请求有关的判断，保留其他作者表达。规则决定哪些信息需要出现、如何帮助比较，不要求添加固定组件，也不改变现有 DSL。

## 1. 先确定读者要核对的判断

先确定比较对象、参照、时间、单位、分母与数据覆盖，再选择图型、强调、标签和标注。有参考图时同时提取可见表达；明确的用户要求优先，其次保留参考图或已有作者表达，最后才使用默认样式。

为重要决策保留简短工作记录：**可见事实／数据依据 → 读者判断 → 使用条件 → 配置落点 → 验收方法**。设计目的属于推断时标明，并用其他适用案例复核；不要把单张图的颜色、位置或作者意图固化成通用规则。记录留在工作资料，不新增 `designIntent/labelPolicy/layoutPolicy` 等产品 JSON 字段，不把分析过程填进图面。

| 数据任务 | 应保留的证据与结构 | 避免改变判断 |
| --- | --- | --- |
| 两期水平／变化比较 | 相同对象的起止值、共同尺度、端点身份与必要数值；可用哑铃或两期斜率图 | 取得年度 CSV 后不自动改成全年趋势；不增加中间年份观测 |
| 连续趋势、转折与交点 | 真实时间顺序、缺失、起止范围、需要解释的时期 | 不因追求平滑而编造观测；实际和预测分开标识 |
| 多对象趋势中的重点 | 主角、参照与完整背景对象；颜色、线宽和对应名称共用身份 | 不按“最大值”机械选主角，不擅自删成 Top N |
| 构成比较 | 各层含义、分母、顺序、必要份额及总量 | 累计边界不冒充层值；同一数值不重复标为分项和总计 |
| 多面板比较 | 共同口径、面板顺序、总标题／各面板标题职责、跨图是否比较量级 | 量级比较使用共同尺度；独立趋势阅读保留原图各自尺度 |
| 连续指标关系 | x/y 指标、单位、对象、参照线／区域的依据 | 不用分区替代相关性，不把气泡大小当作 x/y 阈值 |

对象身份与统计地区不可互换，例如北非、撒哈拉以南非洲、非洲整体及大洋洲是不同对象。缺原地区数据时记录缺口，保留可核实部分；不能替换地区后称为原图还原。只有少量印出点时，保留这些点，不声称已经重建完整分布。对数轴先确认所有参与值及其含义适用，刻度按真实 scale 生成，不凭图上不等距猜数。

## 2. 决定哪些元素需要绘制

标题、副标题、轴标题、刻度、图例、普通标签、来源、脚注、标注均按信息增量和用户意图选择，允许省略。用户要求不绘制时显式关闭相应组件；不换成另一个组件偷偷补回。没有可核实来源不生成来源文字，没有必要的口径说明不生成脚注。溯源／同步元数据与图面来源文字分别判断：隐藏图面文字不删除已有 live binding。

- 需要标题时选择可证实的主题或判断；次级说明只补充未被表达且影响解读的时间、单位、分母、样本与参照。没有这些信息不补占位行。
- 已由标题、类目、数值标签或图旁说明清楚表达指标时，可以省略轴标题；需要估读时保留尺度上下文。隐藏刻度不改变 axis domain、单位或可比关系。
- 需要区分系列时优先考虑靠近线尾／层边界的直接名称；原图或用户要求完整图例时保留。图例和直标可有不同职责，不机械全开或全关。
- 多面板使用同一组系列、相同顺序与颜色含义时，整组优先保留一份公共图例；系列或颜色含义不同的面板保留必要的局部图例。为公共图例在总标题下方或整组底部独立留空间，按整组宽度排列与对齐，不能将各子图图例堆在相邻面板之间。减少局部图例后，绘图区重新利用空出的空间，保留各指标的单位与独立／共同尺度选择。
- 编辑已有组合图时，可保留一个已有原生图例的身份、关闭其余重复图例，再在完整编辑态的该图例 `layout` 条目中保存公共位置与尺寸；同时调整所属面板绘图区，保持整组面板对齐。不虚构 `sharedLegend` 字段，也不把静态文字替代项宣称为原生图例的动态筛选或跨图联动。
- 面板共享的标题和必要来源可由一个画布文字区域承担；各面板仅保留自己的身份与必要端点。小图高度、对齐和字号比例保持一致，不能把来源塞入最后一个面板。
- 文字、绘图区与说明区按实际存在的内容分配空间。用户要求省略某区域后重新利用空间，不保留空占位；保留已有手动布局。

配置选择见 [模型组件](model-spec.md)、[标签](labels.md)、[画布元素](components.md)。默认主题与字体候选见 [MBB](mbb.md)，不将候选的具体字体或配色当作全部任务的固定外观。

## 3. 建立样式的业务身份

有可靠叙事重点时，让主线／主要对象与背景在线色、粗细或透明度上可区分；需要保留的其他对象仍存在。背景可使用同一协调弱色和较细线，直接名称继续说明各自身份。若分类色已承载语义，则保留色义，用线宽或明暗建立层级。没有重点时保持均衡，不自动高亮最高、最低或末期。

线尾名称默认继承对应线色，名称与线之间需要辨认落点时显示末端点。当前系列直标的 `label.style.fill` 是公共覆盖；不能逐系列写不同公共 fill 期待各自生效。保留线色继承；确需单项不同色时使用已支持的 `seriesLabel.label.styleMap` 业务定位，见 [标签](labels.md#3-series-label)。背景色也须足够辨认其名称，用线宽建立重点而非把文字淡到不可读。

标题片段、点说明、普通／总计／轴标签可用各自支持的富文本或内容配置，分别表达名称、值与解释。强调文字与其对应图元的色义一致；单位、紧凑量级与舍入精度按指标和参考图选择，不为所有指标强行统一小数位。真实格式见 [数据与格式](data-and-formatting.md)。

## 4. 先选标签职责，再选显示与位置

| 职责 | 首选配置 | 显示判断 |
| --- | --- | --- |
| 系列／对象名称 | `seriesLabel` | 起点、末端或两端；不把每段预测线当成新对象 |
| 单个观测或柱段数值 | `label` | 全部、首尾、极值或指定业务对象，按需要选择 |
| 可相加类别总量 | `totalLabel` | 仅在总量有意义且不重复分项值时显示 |
| 补充事实、变化或背景 | 点／差异／区域标注 | 通过 [表达增量检查](auto-insights.md#表达增量检查所有图型通用) 后才增加 |

少量柱／条的关键数值可直接显示。单图趋势不默认成对添加首尾数值；这不要求删除已有或用户要看的末期单值。需要读取最新水平时保留末值，起点值仅按比较任务选择，密集曲线不采用全部数值标签。小多图需要比较各面板起止水平或变化时，可用首尾值，保持共同时间口径；并非所有小多图都要显示。保留的折线／面积图数值标签应靠近对应可见点；为避让必须移远时加一条短引线，让读者能辨认所指观测。只显示必要点，不为此点亮整条密集曲线。堆叠只需重点层份额时才关闭其他层标签，明确选择的是哪层以及比较目的；常规构成阅读保留必要分项值和身份，不因“最后一层”位置而只显示它。单系列的末点数值与系列名是不同职责，不能因标题已说明对象就把必要末点值一起关闭。

新建或整体布局优化时，柱／条标签先考察所属图形内部：最终格式化文字与留白能容纳、对比度足够则内部显示；横条通常考察右侧内部 `inside-right`。薄段放不下且并非必须读取时省略该标签，数据段保留。用户或比较任务要求必显时，优先在条形内部用与该段一致的背景色托住对比色文字；衬底只承担文字可读性，不改变真实段宽、数值或累计边界，不覆盖相邻必要标签。无法容纳此方式时按用户允许范围调整布局；只有用户／参考图要求外置，或独立短柱适合外置时，才采用靠近图形的外标签及必要引线，不默认用长偏移把薄段标签移远。

普通标签支持时优先使用普通标签；单标签类型未声明 `position` 时不虚构覆盖。需要独立内标签且模板支持语义点时，可用段中心 `target`、`itemContent.position:"insideMiddle"` 和 `itemContent.text.labelBackground`；值使用 `itemContent.text.formatConfig.content:"value"`，省略显式 `text`，绑定真实成员值而非累计值。格式与衬底字段见 [点标注布局](point-marker-layout.md#3-近点数值与薄段内标签)。只改数值格式／去重的局部请求保持位置。没有图形／文字边界时给出候选，不宣称自动判断空间已成功。

相邻哑铃端点按各自角色放置数值，避免重合；方向箭头与端点颜色单独判断。原图有方向时，用 `config.dumbbellArrow.from/to` 指定起终指标，不按最小/最大值猜方向；省略配置不会自动加箭头。相等、缺失或过短端点间距保留点与标签而不画重叠箭头，模板条件见 [专用图](template-catalog-specialized.md#dumbbell)。不将普通两期变化写成 CAGR。

## 5. 选择标注承载方式与引线

先判断锚定谁、是否需要随数据变化以及布局归属，再选择承载方式；文字或箭头的存在不直接决定使用 `mark-point`。

| 表达需求 | 承载方式 | 生命周期 |
| --- | --- | --- |
| 已支持模板中一个数据对象的补充事实或独立值标签 | 图表 `marker.markPoint + target` | target 随数据／映射重新解析；`text.formatConfig` 可绑定原始值，显式静态文字不会自动更新 |
| 两个数据对象的可比差异 | 模板支持的差异 marker、完整 `from/to` | 动态格式随实际端点重算 |
| 已知阈值、时期或区域 | 参考线／区域；散点自由分区按已有协议 | 绑定实际值与 scale，遵守来源及同步范围 |
| 固定说明、多图公共文字 | 画布 `text`／需要时的形状容器 | 保持布局与作者内容 |
| 画布元素之间的方向或关系 | `straightLine/elbowLine/curveLine` | 使用实际元素 ID 与连接锚点 |
| 数据锚点需要画布上的连接 | 已支持的 `chartConnectorLine` 或经核验的两阶段布局 | 一次性解析与后续连接器生命周期见 [连接器](semantic-chart-connectors.md) |

根据参考形态和阅读路径选直线、折线、弧线、有箭头或无引线；原生点说明已支持 `itemLine.type:"type-arc"`，不能将弧形缺失直接归为新功能。具体结构见 [markers](markers.md)。优先短路径、小曲率，不能为使用弧线让路径绕圈或穿过相邻标签；曲率与偏移一起按实际落点调整，不复用一组长偏移到所有尺寸。端点落在被解释的真实对象上，不把箭头指向临近的数值文字。没有需要表达的方向时不增加箭头。

原生位置点标注可用不等于业务 target 已支持该图型：当前哑铃端点与百分比堆叠的语义点仍受限制，不能由弧线能力推断定位能力。指定图型时保留它并报告缺口；未指定图型时可在保持数据关系的前提下选已支持的表达。数据已是各行合计100的份额时，普通堆叠与0–100尺度可表达同一构成，但不能据此替换需要运行时归一或动态占比计算的模板。

自由画布线或文字需要跟随数据时，必须有经核验的数据定位和重算链路。分区面使用最终 scale 转换与真实 polygon，不把数据等值线画成固定屏幕角度。现有语义 `ranges` 不接受任意多边形；三角参照区先核对自由分区协议、轴映射、保存及同步能力，不伪造 `mark-area` 字段。Marker 的持续业务 target 与连接器／单图元的一次性原生身份分别保留。

## 6. 布局与完成检查

先留出实际需要的标题、直接标签、绘图区及说明位置；按文字长度、单位、点密度和目标尺寸安排候选。图例属于图表实际边界，来源／脚注属于自己的画布文字区域，两者分别留空间，不能只以名义绘图区高度摆放底部文字。窄图按完整词句换行，避免拆词。检查整个引线路径、箭头落点、普通值标签与边界，不能只检查说明框。遮挡时先调整相关文本、引线或可用空间；不为解决局部碰撞删除数据、关闭必要标签或移动数据锚点。需要缩短文字、改变已指定位置或扩大卡片时遵循用户范围。

有实际渲染能力且任务要求看效果／复刻时，用最终配置在目标尺寸查看图面；可取得边界时读取图形与文字边界，修正命中的布局，再看结果。未取得边界或未实绘时只能称候选布局；不承诺已实现任意尺寸自动避让。数据刷新后文字内容与位置分别复核，不能把目标跟随当成静态解释已更新。

逐项区分：**按用户意图省略、已有可读证据、已配置／已实绘、缺数据、能力不支持**。结构校验通过不等于必要标签／标注已经出现；也不能把尚未正确配置的富文本、直标、弧线或分区列成缺少功能。完整入口见 [交付检查](validation.md)。

## 7. 示例与边界

- [两期比较与端点直标](../examples/data-driven-endpoints.json)：只取官方原图的 World、North Africa、Sub-Saharan Africa 三个对象；两期、对象及完整尺度固定，不代表该案例全部地区的复现。
- [构成的选择性标签](../examples/data-driven-selective-labels.json)：完整三类数据仍绘制，只打印重点层值；不将其他层隐藏为缺失。
- [数据点弧形说明与画布文字](../examples/data-driven-point-canvas.json)：数据说明用业务 target，独立来源用画布文字；两者的锚点与更新职责不同。
- [共享尺度的小多图](../examples/data-driven-small-multiples.json)：原图年龄层份额在同尺度独立条形面板中逐项比较，输入层值而非累计值；这是另一种数据表达，不称堆叠版式复现。
- [趋势小多图的首尾值与对应点](../examples/data-driven-trend-panels.json)：比较三地区相同时间内的水平变化，使用共同尺度；首尾值服务这一比较任务，不作为单图趋势默认。

案例的数值来自可核实的官方原图／数据，作为特定配置参考，不把其值、颜色或布局复制给无关数据。公开数据沟通案例见 [OWID Data Insights](https://ourworldindata.org/launching-data-insights)；这些表达判断适用于一般任务，具体品牌外观只在用户要求或参考图还原时采用。地图不属于本 Skill 的内置图能力，保留来源和缺口，不将地理名字自动转成地图。
