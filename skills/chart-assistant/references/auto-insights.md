# 自动洞察与标注

新建图表，或用户要求分析数据/优化整图时执行本流程，无需风格关键词或显式标注请求。只改图例、字号、颜色等局部编辑时保持原有标注与范围；用户要求不加标注时遵从。这里是模型生成时的数据分析步骤，不是运行时自动异常检测功能。

## 1. 扫描可比较的事实

先确认业务问题、指标方向、单位、时间粒度、缺失与重复键，再计算候选结论。保留数据、映射、图型和原顺序；只在分析中计算比较量，不新增派生列或为标注聚合数据。URL 尚未读取到真实数据时，先获取可见数据再分析，不从标题猜异常。

| 数据语义 | 扫描候选 | 必须确认 |
| --- | --- | --- |
| 有序时间序列 | 相邻变化、起终点净变化、增长转回落或回落后恢复 | 同一指标与粒度；缺期时不能称环比，未有上年同周期不能称同比 |
| 实际与预算/目标 | 有符号差、相对偏差、越过真实阈值 | 配对的业务键和单位一致，变化的预算应保留系列，只有固定阈值才用参考线 |
| 构成/贡献 | 主要增加或扣减项、本层数值/份额变化 | 累计边界不冒充层值；瀑布扣减方向以模板语义判断 |
| 散点/横截面 | 与已给基准偏离的对象、同类比较中的突出点 | 总量最大不自动是异常；类别不可强行当时间，气泡size不充当X/Y阈值 |

相对变化为 `(后值-前值)/前值`，仅在正值、可比基数上直接解释增长率；零基数改报绝对变化，负基数需解释口径，不强称增长。百分点与相对百分比区分；年度CAGR沿用 [年度契约](semantic-marker-anchors.md#31-年度字段声明)，不能把季度行数当年数。

## 2. 选择值得表达的发现

每个候选需要有明确业务对象、比较基准、可复算数值和与读图目的的关系。优先：用户关心的目标偏差/越界，其次改变结论的转折或主要贡献，再次普通峰谷。默认选一个主要叙事，标注数量从 0 开始；发现重要事实不等于需要增加标注。

“异常”必须有已知业务阈值、可靠历史基线，或用户接受且适合样本的统计方法。没有这些依据时，用“本期回落”“区间最高”“与目标差…”等事实措辞。少量样本不凭空定异常阈值，不静默套固定增长率/均值/标准差规则；若任务必须判异常却缺少判定口径，先说明缺口。相关变化不写成因果，也不自动写促销、故障、季节性等未给出的原因。

### 表达增量检查（所有图型通用）

对每个拟新增的标注或强调，先回答：去掉它，读者会失去哪条必要信息，或明显增加哪一步查找/比较？只有答案具体、与业务问题相关，才加入配置；仅重复已有标题、数值标签、图例或显著形状的内容，结果为“不新增”。重要事实即使存在，也可以用 0 个 marker 完成交付。

- 先看现有表达是否足够，再选最小手段：保留现状 → 必要的直接标签或局部图形强调 → 承载补充事实/关系的标注。不是每个层级都要叠加；已有图形清楚传达重点时不强制额外改色。
- 单对象需要强调时按 [重点着色](mbb.md#71-单图形选择性强调) 调整该对象。区域用于有意义的时间段、分类范围或业务阈值带；不能为了突出一个柱、点或扇区，就用贯穿绘图区的区域框替代单图形样式。缺少可靠 mark 身份时保留原图或说明限制，不用更大的框绕过定位能力。
- 标题讲结论、标签讲必要数值、标注补充读者难以直接得到的关系或背景。同一事实默认只保留最直接的一处；用户明确要求的标注/强调按要求执行，采用最简表达，也不顺带增加其他装饰。
- 副标题只承载尚未表达且影响解读的时间、单位、范围、口径或基准；没有这些信息就省略。生成过程、保留原序、主题/配色执行说明不进入图面；“未提供单位”等缺项应在确实影响判断时向用户说明，不用来填副标题。解释真实编码所必需的图例或说明仍保留。

完成条件：逐个候选决定“标注、已由标题/标签充分表达、无可靠依据或当前能力不支持”。通过表达增量检查的内容才落实到配置；“已充分表达，无需新增”也是完整结果。无需把整个候选分析表放进图面。

## 3. 把发现映射为现有标注

通过表达增量检查、确认需要标注后，先判断结论是“两个对象之间的关系”还是“一个对象的补充事实”，再选类型；不能因为发现发生在某个点，就默认使用mark-point。

- **有参考图时先结合形态、对象和口径，再定差异类型**：差异竖段在端点侧面通常是 `hierarchy-diff-line`，顶部横向括号跨接两端点上方通常是 `total-diff-line`。斜向直线只有在比较总量端点且年化口径明确时才是 `growth-line`；层份额或段值的比较不能仅因斜线改为 growth。两端总量的相对变化使用 total 的 `percentage`，不把两端增长率冒充 CAGR。只有无参考图、用户未指定形态的新建场景才按语义默认：堆叠层/同类别系列等层级比较默认 hierarchy，整柱/总量比较默认 total。规则见 [按参考图判别差异类型](semantic-marker-anchors.md#按参考图判别差异类型)。
- **有明确比较起终点时，优先差异标注**：例如“Q2较Q1下降”“实际低于预算”“本期比上期增加”，只要两端可比、可唯一定位且模板支持，使用连接两端的差异标注。单系列柱的两个柱值或整栈总量比较优先 `total-diff-line`；年度复合增长等符合增长契约时使用 `growth-line`；同一堆叠层用 `hierarchy-diff-line`。这些是未给定形态时的语义默认；有参考图或用户指定形态时形态优先（见上条）。按 [语义锚点](semantic-marker-anchors.md) 填有序from/to，用动态格式计算差值/增长率，不写死结论。
- **单点事实才优先点说明**：已知事件、产品发布、数据口径备注、某对象独有且不依赖另一端点的解释，用 `marker.markPoint` 的 `name:"mark-point"`；原字段 `target.match` 与必要 `metric` 定位，并按 [点说明布局](point-marker-layout.md) 生成文字偏移和引线。
- 同一比较不同时生成差异线与复述差值的点说明。模板不支持差异、两端无法稳定定位或用户显式要求点说明时，才退回点说明并保留比较基准；不通过改图型/猜坐标强行画线。
- 明确业务阈值/区间：`reference-line` / `mark-area`；统计发现不自动生成固定业务阈值或四象限。
- 已由标题、直接标签或图形编码清楚表达的事实不重复画线、加点说明或框选。

提交前核对目标唯一、公式/单位正确、文案有依据、模板支持。目标不唯一时补全业务键；仍无法定位则说明限制，不猜series、坐标或数组序号。静态分析生成的文字是当前数据快照：不能承诺同步后重选异常点或自动更新静态文案。需要随数据变化的差值优先用受支持的动态格式；不新增自动检测DSL字段。

## 4. 无标注提示的例子

用户仅要求“把Q1 120、Q2 80、Q3 125、Q4 130万元销售额做柱状图”。模型可识别Q2较Q1下降40万元（33.3%），Q3恢复至略高于Q1，再判断表达是否必要。若读图目的需要精确比较回落幅度，且标题/标签尚未表达该差值，可突出Q2，以Q1为from、Q2为to生成一条total-diff-line，动态显示−40与−33.3%；若只需看季度走势，或这些信息已充分表达，则不加标注。这是两个季度总量的比较，不是Q2的单点事件；不再叠加同义点说明，也不为Q3恢复额外堆线。不称统计异常、不猜下滑原因，也不机械突出最高Q4。需要显示精确回落幅度时的配置见 [auto-insight-quarterly-dip.json](../examples/auto-insight-quarterly-dip.json)。

如果用户仅说“把这张图的图例移到左下角”，即使同样数据包含Q2回落，也只执行图例编辑。

## 5. 跨图型取舍示例

| 场景 | 最少必要表达 |
| --- | --- |
| 柱图标题已写“A领先”，A柱明显最高且标签为120 | 不再加“A=120”点说明或整列区域框；用户要求强调时仅调整A柱样式 |
| 折线标题和末点标签已写本期130 | 不再用引线复述130；未在图中表达且口径可比的起终点增长率，可用一条动态差异标注 |
| 饼图最大扇区已标“A 60%” | 不再加“A占比60%”说明、框或额外引线 |
| 散点已直接标出用户关注的对象A | 不再框选A；若给定真实目标阈值，可保留能帮助判断达标与否的参考线 |
| 瀑布图标题写主要扣减项、成本柱已标−600 | 不再加“成本扣减600”或整列框；需要强化时只在保留扣减色义的前提下调整成本柱 |
| 已知口径切换事件、明确业务阈值或尚未表达的可比差值 | 有信息增量，选择对应点说明、参考线或差异线；不因“少标注”而遗漏必要信息 |
