# 从素材到可叙述的数据

## 建立资料范围与候选发现

用户提供材料时先检查覆盖与来源，再决定是否扩展；有主题时先找支撑核心比较的原始记录、官方资料或可复核研究。把数据、事件解释、身份图片分开查证，它们可能来自不同来源。

先抽样检查粒度、字段和可获取范围，确认能回答问题，再扩大收集。保留原始文件和版本，清洗后的记录能回到来源位置。非结构化材料可先抽取少量记录，逐条对照原文复核，明确哪些是原文事实、哪些是编辑标注。

寻找候选发现时，尝试会改变判断的比较：总体与构成、数量与贡献、年度与累积、典型与尾部、同口径与表面差异、绝对时间与相对阶段。这些是探查方向，不是固定分析清单。

对值得继续的发现留下三项：支撑记录与计算；另一种可能解释或口径；为区分它们还需要什么资料。证据仅支持描述时，讲清可观察的差异、趋势与关联；解释原因需要额外依据。

## 让数据需求服务表达

| 想表达的关系 | 数据需要具备什么 |
| --- | --- |
| 每个单元是一项真实记录 | 可辨的记录粒度、稳定身份与必要属性 |
| 跨期追踪同一对象 | 可匹配的身份与观测；退出、缺失和新增可区分 |
| 部分组成整体／新增累积 | 同单位、同范围、可加总；历史起点明确 |
| 片段怎样展开、呼应或分岔 | 保留原顺序和出处。连接重复或变体需要可核对的标注，比较真实间隔需要时间记录 |
| 实物直接编码尺寸／组成 | 可测尺寸或组成数据；照片透视不自动等于真实比例 |

只有聚合数据仍可做完整故事。根据输入选择合适粒度，不为了某种动画虚构微观记录。

## 先明确一条记录是什么

保留来源对象、观测和展示实例的区别。例如同一产品的不同容量、同一人的多个角色、同一对象的不同观测日期，可能需要不同的键，不能随意混成一个点。

按实际需要整理以下信息，不要求原材料天然为表格，也不要求使用固定字段名：

- 稳定对象标识及原始名称；记录粒度和多标签处理。
- 观测时间、覆盖范围、计量单位、分类定义与总体分母。
- 来源定位、获取日期、原始文件或版本；每条派生结果的计算方式。
- 缺失、估计、区间、修订及不同来源冲突。

文本可整理为作品、人物、主张、事件或关系记录；抽取结果需能回到原文。只出现相同名字或相近表述，不足以推断合作、转述或传播关系。

## 检查会改变故事的口径

| 数据形态 | 需要先检查 | 常见误读 |
| --- | --- | --- |
| 多期总量 | 范围、覆盖期、单位和统计定义是否一致 | 覆盖时间更长被解释为人更多 |
| 总量与人均／份额 | 分子与分母匹配，分母是全体还是已选子集 | 前十名内部份额被写成全球份额 |
| 指数／增幅 | 基期、原值、零值、名义与实际口径 | 同基期指数被当作相同绝对规模 |
| 部分与整体 | 部分是否互斥、穷尽、同单位、同时间 | 三个分项被画成全部总量 |
| 多标签记录 | 是否重复展示，何处去重，权重能否分配 | 同一人的完整权重在多个类别重复相加 |
| 成员或状态更替 | 稳定 ID、各期范围、缺失与进入退出定义 | 换一批人被画成同一批人改变属性 |
| 收入、成本、转化 | 粒度、币种、时间窗、加总和转化分母 | 独立模拟表被拼成资金流或漏斗 |

做最小的数据核对：键唯一性、期数、缺失、端点、分项合计及支撑主结论的计算。模拟数据可以用于演示，但标注其性质，结论不能当作现实发现。

## 丰富数据应回答问题

补一个维度前，写出它改变的比较：规模→人均；数量→权重；总体→构成；年度→相对事件时点。不能仅为制造更多章节而追加字段。

没有个体明细时，可以用聚合图形或“一单元代表固定数量”；不反推虚构的人物、企业、购买记录或流向。只有年份和总量，也可以产生好的连续比较，不需要强行升级为网络。

数据来源未查清、版本冲突或关键口径缺失时，保留原件，隔离冲突项，选择已支持的较小问题。不要静默改数让结论成立。历史快照若能回答问题，不必追逐最新年份；标题和时间范围需与快照一致。

## 发现与解释分开

对每个候选结论指出：哪些记录直接支持；哪些是派生计算；哪些是机制解释或假设；什么反例会改变结论。两个指标一起上升，不能单凭相关性声称一个驱动另一个。视觉相似、素材真实感和动画路径都不增加因果证据。

生成的插画不能替代档案、测量、现场记录或产品规格。照片负责识别时，几何数据仍由可追溯数值生成。
