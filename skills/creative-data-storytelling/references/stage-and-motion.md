# 舞台、运动与章节交接

本页安排阅读空间、历史参照与运动节奏。沿用[作品结构定义](../SKILL.md#作品如何组织)和已确认的[数据对应](visualization-design.md#核对前后数据的对应)；实现接法见[实现参考](implementation.md)。

## 决定哪些状态共享舞台

需要持续追踪对象、保留比较参照或观看组成过程时，用共享舞台；单张图已能讲清的发现与背景说明，通常自然滚动阅读。大图或情境引入也可占据主要视野，停留由实际阅读需要决定。

更换时期、指标或角度时，现有舞台若仍能解释，就继续使用；需要独立证据、新空间或较长背景时再换场。章节边界和配图出现不自动要求清屏；主题停顿后接回明确问题或证据。

### 文字推进与舞台回应

文字解释已有画面，或提出需要选中、展开、重排、换口径的新问题；状态按理解需要安排，不与段落数对应。文字可在侧边、空区或浮层经过，给图形留出可读时间与不被遮挡的空间，段落间距按实际内容设置。

新对象与陌生编码出现时交代读法，指标或单位变化时重新标明；已完成的引导可收起，必要身份与参照仍可辨，包括直接进入某段的读者。

解释结束后，舞台随页面滚出，接后续图文或探索。固定范围与触发接法见[文字滚动与舞台更新](implementation-stage.md#文字滚动与舞台更新)。

### 让历史仍可比较

讲发展变化时，历史可留为已展开的曲线、旧记录、参考端点、关键时期分布或累计基底；用重点色、线宽、标签或放大突出当前。保留可辨的身份与比较依据，旧说明不必全部常驻。

数据密集时可压缩细节、有依据地聚合期间、并置关键时期或缩为定位参照，让当前问题获得空间。转折、例外与基准仍需可辨，不因记录妨碍结论而舍弃它。只需当期构成或旧口径已不可比时，可退出旧内容并交代范围。

## 按关系分配空间

依据要比较的关系，同时安排图形、实际正文与素材，为主证据留出所需空间：

| 主要关系 | 空间选择 |
| --- | --- |
| 宽分布、水平条带或长时间跨度 | 给量值方向连续空间；短文可放上方、侧边或空区，以完整图形和标签实际占用为准。年代仅是状态时单独标出；时间位置承载趋势时保留时间轴 |
| 两个对象的细致比较 | 名称、基准与差值靠近对象；聚焦后为细节释放空间，定位参照按需要保留 |
| 大量单元或关系 | 预留分组、连接和详情空间；图例靠近其解释的图形，重点标签保持可辨 |
| 组成比较或序列展开 | 先建立整体与共同基准，随后展开需要读取的数据分项／片段，标签跟随对应位置 |

上下、左右、叠加布局按实际占位选择，长文可进入独立段落。身份素材随对象安排，普通配图随相关正文进出；除停留画面，也给移动中的文字与素材留出经过空间。主辅视图分工见[构图判断](visualization-design.md#主图与辅助信息的职责)。

## 从关系选择动作

沿已选定的[表达关系](visualization-design.md#从关系选择表达)，明确哪些参照保留、哪些属性变化。先让主要变化可读，次要变化可错峰或分阶段发生；轴、标记与标签共享当帧映射，含义变化时交接图例与口径。

例如从总体比较两组对象，可以原位高亮，也可以提取并放大；前者保留位置，后者释放细节空间。动作由这个选择产生，具体推导见[连续比较](expression-methods.md#compare)，几何接法见[关系到实现](implementation-geometry.md#把关系落实为几何)。

高亮、渐显和轻微错峰可引导注意，艺术运动也可增强主题与质感；量值映射保持正确。没有直接数据对应时，可明确替换并交代新问题，不强造形变关系。

## 主题驱动的转场

从前后可延续的内容选择动效：产品图片移到对应量值标记，已有纹理作为交接边缘，主题轮廓展开成数据单元。

不规则边缘可用二维 SVG/CSS 遮罩、路径或透明纹理，核对边缘质量与运动范围。装饰起伏与量值几何分别处理，数值标记继续锚定数据。

## 两种时间

**阅读停留由读者掌握，衔接动画按自身时长播放。** 状态触发后即使停止滚动，动画也会完成并停在可读终点；快滚跳转和反向从当前可见画面接续，不强制播放积压章节。

连续拖动或滚动若本身解释一个变量，则每个中间位置都应对应明确的值和可读状态。例如拖动日期边界查看截至该日的数据；两个章节叠在一起的半透明过渡画面不具备这种含义。

可按“识别 → 移动 → 解释”安排注意力，但并非每次都要三段。短距离变化可以直接发生；说明在对应关系清楚时出现。对象和轴不要整体淡到不可读。

## 探索的交接

按[收尾与探索](narrative-design.md#收尾与探索)选好问题后，初态延续当前对象与编码，主要操作靠近结果；统计、说明、图例和详情同步，缺失与空结果解释原因。

章节控制与读者筛选分开，进入探索有默认选择，返回主线恢复明确状态。导航按实际用途提供；接法见[探索交接与控件](implementation-stage.md#探索交接与控件)。
