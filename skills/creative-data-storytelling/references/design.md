# 叙事与可视化设计

把读者的追问、画面中的证据和前后衔接一起推敲，写入一份[设计稿](workflow.md#design-record)。本页组织整篇阅读，并按追问直接选择表达与示例；具体设计理由随示例说明，接入与接口见[实现参考](implementation.md)。

## 组织整篇故事

从用户关注点与数据出发，明确读者的原有认识、主问题与结尾能回答到哪里。主线选用会推进判断的证据，篇幅随新增理解安排，重复证实合并，必要背景就近补充，旁支留给详情。追问原因或机制，需要相应证据；材料只支持差异或关联时，将问题收在这一层。构图揭示证据不足或更有价值的发现时，可以调整问题与顺序。

段落之间应有可理解的追问。例如平均等候从 30 分钟降到 20 分钟，超过一小时的比例却没有明显改变，可以从“平均等候短了，超过一小时的比例也降了吗？”进入，收尾保留两项比较，回答“平均等候缩短了，久等的比例却没明显下降”。依次展示接待量、平均值、超时比例，仍把这层关系留给读者拼接。业务概况也可以并列指标，不必强造反转。

时间字段不决定章节数。可以从结果回看历史、从长期聚焦短期、从整体进入组成或群体差异；停在值得解释的变化与转折，普通年份可在过程中经过。具体追问与表达一起在[选择表](#从追问选择表达)中推敲。

### 开篇与收尾

开篇先确定什么值得读者看下去：一个具体对象、经历、反差或待解释的关系，再按问题、读者经验与素材条件选择入口。集中呈现一个容易进入的重点，较长背景、成组指标与完整读法随证据展开。

| 可选入口 | 何时有帮助 | 怎样接入第一项证据 |
| --- | --- | --- |
| 熟悉的物件、人物或情境 | 抽象问题需要生活背景，具体对象能建立代入感 | 延续对象身份或问题；短例 `opening-material` 让汉堡成为报价标记，`opening-reference` 从开放告示自然滚入同一参照的比较 |
| 简短文字、问题或生活观察 | 少量文字已能建立期待 | 下一画面直接回应；短例 `opening-question` 从平均等候的变化追问久等的比例，无需装饰图 |
| 点阵组成的主题形象 | 熟悉形象能引出对个体或群体的追问，记录数量足以支撑轮廓 | 短例 `opening-particles` 将同一批点从熊猫形象移入年龄分布；形象色不编码年龄，落位时交接读法 |
| 一个单元或基本关系 | 后续整体依赖陌生读法 | 先认识这个单元或关系，再扩展到群体与比较；下方 `unit-scale` 示范保留原份、展开倍数并交接比较 |
| 一个易读的数据发现 | 少量比较或变化本身有吸引力 | 保留已看见的现象，展开它带来的追问；`opening-question` 的两个均值随后成为分布中的参照 |

用实际标题、短引入和主体安排视觉中心。外观或场景细节承担吸引力时，先看代表素材，再选择原图、插画或轮廓；文字也可担当主视觉，用字形、排布和留白突出重点。素材取得与处理见[素材指导](material-direction.md#选择形式与取得方式)。

第一项证据展开或检验开篇的对象与追问；需要先认识单位、读法或基准时，说明它怎样帮助回答刚提出的问题。更换时期、指标或范围时，交代为何接着看这里。入口可以组合、同台演进或自然滚动。总体图若能直接读出一个关系，也可开篇，先给必要身份、单位与参照。

结尾综合已呈现的证据，回答开篇追问及其成立条件，让读者带走比起点更清楚的判断。收束可回看全景、保留关键比较、重新理解开篇对象，也可用简短正文完成，按回答所需选择。已解释的问题给出答案，支撑回答的新证据在主线中完成，延伸问题再留给探索。

有值得继续追问的问题时，选择一项主要操作与可见结果，例如换时期比较分布、查看代表是否典型。沿用已建立的编码与基准，让操作显示差异、例外或具体记录的意义；额外筛选和完整记录按需打开。控制接法见[探索交接](implementation-stage.md#探索交接与控件)。

文末简列数据来源，有公开出处时附原始链接；保留影响理解的口径和限制，完整来源与详细方法按需查看。考证过程与制作检查留在已有研究或交付记录中，按[文件分工](workflow.md#研究设计与验收各自记录什么)保存。

## 从追问选择表达

先明确这一段带来什么新理解，用下表找到相关参照并读其短解释，再确定构图。**连续片段**示范一段解释怎样展开；**基础示例**抽出局部机制，用动作解说帮助作者理解。两者的说明都交代设计理由与改编空间。同一追问可换用其他图形，未覆盖的关系自行设计。

用表中 ID 执行以下命令；将路径替换为当前 Skill 目录，可从作品目录运行：

```sh
node /path/to/creative-data-storytelling/scripts/examples.mjs inspect <id>
```

`explanation` 返回完整短解释，`read.layout` 可预览构图与运动；代码定位与依赖见[实现参考](implementation.md)。其他候选用 `list` 浏览短目录，或 `list --query 关键词` 按中英文关键词筛选；无匹配时会标明并返回短目录，无需通读全部示例。

| 叙事中的追问 | 可选表达与取舍 | 数据条件与比较依据 | 参照 ID 与关键过程 |
| --- | --- | --- | --- |
| <a id="overview-detail"></a>看见全局后，哪个局部值得细看？ | 原位已清楚则高亮；精读需要空间则提取或放大；仍需全局定位时保留简化参照 | 稳定身份与选取依据。缩略图标出主图所在范围，只承担定位，不另讲一遍分析；整体到局部不限定条形、点或线 | 连续 `overview-detail`：原位辨认 → 同一对象移入局部 → 显示差额；基础 `comparison` 做局部提取，`history` 保留总体定位 |
| <a id="compare"></a>有了直观差异，到底相差多少？ | 成对点、对齐端点、长度带、差值标记；只问增减时可直接比较差值 | 同口径与共同基准；长度编码有明确零点，差值视图覆盖正负。让差额可见，减少来回读数 | 基础 `difference`：两期端点转成有方向的差额；`comparison`：提取同一对对象继续比较 |
| <a id="comparison-basis"></a>对齐条件后，差异是否仍成立？ | 匹配容量或时期、总量转人均、原值转指数，按问题选择 | 条件匹配用真实对应记录；人均有同范围分母，指数有可核对的基期。控制一个条件不代表对象完全相同，也不自动解释原因 | 连续 `comparison-basis`：总量 → 相同人口份额 → 人均；`material-trend`：价格走势转为同比比较 |
| <a id="history"></a>变化怎样发生，与旧水平相比如何？ | 轨迹、关键时期并置、参考端点或历史轮廓；过程用轨迹，精读两期可并置 | 同口径有序观测，缺测或不可比记录不补成连续路径。密集历史可聚合或保留关键时期，保留当前判断需要的转折与基准；旧口径不再适用时交代范围 | 连续 `time-history`：显露轨迹后延续旧基准看差距；`material-trend` 让素材跟随观测推进；基础 `history` 聚焦时间窗口 |
| <a id="record-comparison"></a>新记录加入后，如何补充原来的认识？ | 共同尺度中的条形、区间或点；保留旧参照，同期并行记录可分组展开 | 区分新记录、对象更新和数量累加。排列顺序不自动表示等时距；只看当前比较时可收起无关记录 | 连续 `record-comparison`：旧条连续让位 → 新记录接入 → 比较端点；`material-height`：扩展共同尺度再接入更高对象 |
| <a id="composition"></a>一个整体由什么构成，哪部分更重要？ | 组成带、分项贡献、固定量单元；展开时保留总量或边界以认出归属 | 分项可加总，核对覆盖、重叠、剩余项与分母；不同类别自身的比率不能相加成整体 | 连续 `material-composition`：场景实物 → 组成带 → 比较份额；`records-composition`：具体记录 → 提取类别 → 回到分母，扩大分类后再比较时期；基础 `amounts` 接入分项 |
| <a id="accumulation"></a>各期新增差异，怎样形成累计结果？ | 年度并列比较，再接入历史基底或累计轨迹；只问年度变化时无需累积 | 基底可比、期间完整；移出或负项须计入净变化。只有两个存量时只能解释净差额，不能补造流入流出 | 连续 `increment-stock`：年度并列柱 → 同批柱段首尾相接 → 累计轨迹；基础 `amounts` 接入分项 |
| <a id="unit-scale"></a>单位之间是什么关系，量级相差多少？ | 分段长度、固定份额、共同参照下缩放；单位已熟悉时可直接比较记录 | 换算依据明确；同量换单位保留总体，重复份数增加总量，缩放只改变像素映射。独立记录不冒充原参照的组成 | 连续 `unit-scale`：原份等分 → 扩展视域后接入更多份 → 沿用参照比较记录 |
| <a id="unit-distribution"></a><a id="unit-records"></a>U1 · 群体内部的差异和尾部在哪里？ | 等大单元沿量值堆叠、蜂群或分组网格。如书籍按页数与类型构成分布，可查尾部书目 | 逐条记录有意义时保留单元；只看集中与跨度时可聚合。避让方向不代表第二变量；细比量值保留共同轴，密集处可聚合后局部展开 | 基础 `units`：分布与分组；蜂群需另算避让 |
| <a id="unit-intro"></a>U2 · 怎样从熟悉的主题进入数据？ | 记录组成文字或物件轮廓，再展开为数据排列。如书目组成一本书，再看作品年代 | 轮廓负责识别，落位后才用坐标编码。真实记录一条对应一个位置；装饰粒子另行交接，数量不冒充统计。轮廓复杂度适应记录数 | 开篇 `opening-particles`：主题形象 → 同批记录落入分布；基础 `units` 继续演示分组与权重 |
| <a id="unit-weight"></a>U3 · 数量最多，贡献也最多吗？ | 等大单元转面积或每项长度，或重排成贡献带；只精读组间总量时用共同基线长度 | 同批记录有权重且标尺可比，比例视图说明分母，缺失与零分开。面积按量值换算；长尾可提取详情，点击范围不改变编码面积 | 基础 `units`：等大项目改看服务时长贡献 |
| <a id="unit-detail"></a>U4 · 熟悉的对象是典型还是例外？ | 代表与分布对照，群体中定位后提取详情。如将某位创作者的作品放回完整分布 | 有总体与代表选择依据，荣誉或角色对应时期。先建立名称或图片与单元的联系，放大后仍可定位回群体；照片大小不默认表示成绩 | 连续 `person-coverage`：代表位置 → 群体分布 → 同一范围的覆盖；其人物是百分位示意。基础 `units` 提供记录详情，`identity` 绑定图片与数据锚点 |
| <a id="unit-cohorts"></a>U5 · 两期成员与分布怎样变化？ | 保留身份更新、两期并置、历史分布轮廓。如参展作品逐年加入或退出 | 可匹配成员才跟踪留存、加入、退出与缺测；否则比较两批分布。单元标定与覆盖范围可比，时期长短不同不能仅凭点数解释增长 | 暂无完整示例；实现可用[身份匹配与完整状态](implementation-geometry.md#把关系落实为几何) |
| <a id="unit-regroup"></a>U6 · 同批记录换个分类，隐藏了什么结构？ | 分组重排、矩阵、保留旧类别色。如展品从年代改按材料排列，仍看材料中的年代构成 | 有稳定 ID 与多个属性；前后排列各支持发现。多标签可分组显示，统计总体仍按身份去重。重排表示观察方式变化，实际去向需另有路径依据 | 基础 `units`：同批记录从分布重排为分类；新的分组逻辑自行配置 |
| <a id="aggregate-units"></a>只有汇总数据，怎样逐份理解数量？ | 固定量图标、方格、分段物件；精确比较可用长度 | 交代每份量、分母与余量，标定变化时重新说明。有路径人数可展开匿名计数槽位；只有各期边际总量时不能任意配对成真实个体去向 | 暂无完整示例；可借[单元布局](implementation-geometry.md#主题轮廓与单元重组)，另处理份数与余量 |
| <a id="sequence"></a>哪一步转折，哪些片段呼应，经历各持续多久？ | 按阶段或参与者排列、标出增删、连接复现、对齐起点。只比较两段时可并置，多处呼应可沿原序列定位 | 能回查原片段，呼应有依据；场次只表示先后，时间距离需保留真实间隔与缺测。共同起点比较时长，全长归一才比较阶段占比；弧线不表示数量转移或因果 | 连续 `sequence-recurrence`：保留场次，用弧线揭示前后呼应；基础 `sequence`：发生日期 → 共同起点 |
| 对象之间有什么联系？ | 弧线、节点链接、邻接矩阵；排序帮助读关系，密集连接可换矩阵 | 可靠关系数据，连线与权重含义明确 | 暂无对应示例 |
| 长期变化中是否存在周期？ | 极坐标、环形排列、周期网格；精确差值可展开比较 | 角度或周期有实际含义，排列不制造周期 | 暂无对应示例 |
| <a id="flows"></a>去向如何，各阶段留下多少？ | 桑基／流带、阶段队列、漏斗 | 流带有带权连接，阶段比较有同群体与明确分母；边际总量不能推断流向 | 连续 `cohort-flow`：建立人数 → 一组分流 → 接入另一组 → 比较同一终点；多阶段留存仍需另设计 |
| <a id="fit-constraints"></a>数值差异带来什么后果，满足一个条件是否足够？ | 实物轮廓与适配、对齐指标或容许区间；几何有解释作用时才用真实形状 | 同单位的量值与实际约束；容量不能代替形状，示意轮廓不能当作真实试穿 | 连续 `multi-constraint`：固定对象，换观察条件与候选方案；`object-fit`：同尺度试放 → 回到样本 → 比较功能结果 |
| <a id="objects"></a>熟悉的实物能帮助理解什么量值？ | 图片标识对象或组成分项、沿轴移动，或以真实尺寸比较；具体分工见[素材指导](material-direction.md#配图与引入或参与编码) | 身份由图像识别，量值由对应几何表达。尺寸编码校准可见端点，不含透明留白；抽象量借物体尺寸编码时须说明读法 | 连续 `material-composition` 展开组成，`material-trend` 沿走势推进，`material-height` 共尺度比较尺寸；基础 `identity` 绑定图片与数据锚点 |

单元可以代表真实记录，也可以代表固定数量；先建立含义，再选择 U1–U6 中需要的操作。各行是取舍依据，不是必做步骤。相符过程可取整段、局部或组合，重选素材、图形、布局和运动；保留当前比较成立所需的身份、口径与参照。

## 关键构图与前后衔接

用真实数据、相邻正文和代表素材推敲结果画面，再设计怎样到达它。正文强调差值，图中就应看见双方及其距离；强调占比，要看见部分和总体；强调变化，要有可比时期与基准。若判断依赖合计差异，独立排出各项读数仍把关键比较留给了读者心算。

结合所选示例的具体解释推敲这一过程。有实质分歧时，依据数值跨度、对象数量、精度与空间比较少量构图。

把画面读法写具体：每个标记代表什么，位置、长度、面积、颜色和连线分别表达什么，参照是什么。精读量值采用可比尺度；面积按数据换算，颜色区分类别、量值与当前强调的职责。图片可识别对象或建立情境，图片大小若不编码数量，就让读数由对应几何承担。技术计算见[对象与几何](implementation-geometry.md)。

### 对象关系决定怎样变化

> 上一幅画面让读者看见了＿＿；接下来需要看清＿＿，因此我们要对已有画面进行＿＿。

这句话用于设计备注。随之确认前后数据的对应，再选择动作：

| 对应依据 | 可支持的变化 | 需要保留或说明什么 |
| --- | --- | --- |
| 同一批可识别对象／观测 | 筛选、提取、重排、属性更新 | 稳定身份；区分更新、加入、退出与缺失 |
| 可计算的部分、整体或累积关系 | 展开组成、合并、接入增量 | 单位、范围、分母与覆盖；保留归属及已有量和新增量的区别 |
| 没有直接对象对应，但比较问题成立 | 并置结果、转换参照、清楚交接视角 | 可比口径及变化范围，不把任意点对点运动画成个体流向 |

选出已有记录与把汇总量拆成分项，所需数据不同；同一对象更新与两批样本对比，也不能用同一种身份对应处理。时序不自动提供可加总性或因果。平滑运动只连接已成立的画面，不增加事实关系。

### 主画面与阅读空间

需要追踪对象、比较参照或观看组成过程时，让多段文字共享舞台；单张图已讲清的发现与背景说明可自然滚动。阅读状态按理解需要安排，多段正文可以解释同一状态，不按段落数分屏。

当前问题决定主画面。同一批对象进入局部比较时，让原来的对象成为比较主体；总体仅在仍需定位时收拢为参照，避免保留完整全景又在下方新建另一张主对比图。共享容器、配色或整图淡入淡出不能代替对象关系。需要独立证据、新空间或较长背景时再换场，配图出现不自动要求清屏。

按实际图文占位选择上下、左右或浮层布局：长时间跨度、水平条带需要量值方向的连续空间；正文也要有足够列宽与经过区域。主证据、标签、控件在文字移动时仍需可读。辅助图只保留有用的定位或细节，身份图片随对象安排，普通配图随相关段落进出；主题与排版见[素材指导](material-direction.md)。

### 停留与衔接

**有解释意义的结果由读者停留阅读，只负责连接的动画按自身时长完成。** 停止滚动仍应到达清楚的终态；快滚或反向从当前画面接续。若滚动或拖动本身解释一个变量，每个中间位置就应有可读含义。接法见[舞台控制](implementation-stage.md)。

让主要变化先可辨，次要动作与说明可错峰；轴、标记和标签共享当帧映射，口径变化时交接单位与图例。解释结果的文字出现时，对应证据应已可读。艺术运动可增强质感，量值几何保持正确；动画后留下可读结果，最后一段读完再让舞台自然滚出。

### 正文与图形分工

正文讲问题、发现与意义，主语、时间和比较对象清楚。提问、解释与直接陈述随内容选择；段落推进来自证据，而非反复使用“先……再……”等句式。图形读法在初次出现或变化处就近短释，标签负责身份、单位、关键读数和比较条件；制作指令留在设计稿，考证与计算过程放来源详情。标题提出重点，正文补足证据与意义，图注说明必要条件；呼应应带来信息，不必反复换句话总结。

例如，去年同期销售额为 100 万元，今年为 90 万元。制作备注“在 100 万元参照与 90 万元端点之间标出差额”，对应正文可以是“今年比去年同期少了 10 万元”。事实与比较不变，正文说清发现。

缩放与标注由画面完成；必要的“虚线为去年同期”等读法放在图旁。比喻、幽默和文学表达可建立语气，但不改变观测定义或扩大结论。

会改变判断的范围、分母与不确定性就近说明；相同口径与限制可共用图注，变化或确有误读风险时再提醒。读数采用当前问题所需的日期、时长与单位；内部序号、日期偏移先转换为读者可理解的表达，偏移本身是分析对象时说明参照。呼应的关键读数保持对象、时期、分母及单位、精度和舍入规则一致；坐标刻度按自身间隔简洁显示。
