# 叙事与可视化设计

把读者的追问、画面中的证据和前后衔接一起推敲，写入一份[设计稿](workflow.md#design-record)。本页组织整篇阅读并帮助选择表达；具体方法的条件与取舍按需查[方法卡](expression-methods.md)，制作接法查[实现索引](implementation.md)。

## 组织整篇故事

从用户关注点与数据出发，明确读者的原有认识、主问题与结尾能回答到哪里。主线选用会推进判断的证据，必要背景就近补充，重复证实合并，旁支留给详情。只能支持关联时不扩大为原因；构图揭示证据不足或更有价值的发现时，可以调整问题与顺序。

段落之间应有可理解的追问。例如平均等候从 30 分钟降到 20 分钟，超过一小时的比例却没有明显改变，值得讲的是“改善是否普遍”；接待量、平均值、超时比例依次各放一张图，还需要读者自己拼出这个反差。业务概况也可以并列指标，不必强造反转。

时间字段不决定章节数。可以从结果回看历史、从长期聚焦短期、从整体进入组成或群体差异；停在值得解释的变化与转折，普通年份可在过程中经过。具体追问与表达一起在[选择表](#从追问选择表达)中推敲。

### 开篇与收尾

开篇让读者认出主题、产生追问，并获得读懂第一项证据所需的理解。按问题、读者经验与素材条件选择入口：

| 可选入口 | 何时有帮助 | 怎样接入第一项证据 |
| --- | --- | --- |
| 熟悉的物件、人物或情境 | 抽象问题需要生活背景，具体对象能建立代入感 | 延续对象身份或问题，如产品图片与价格标记关联，再加入可比较的型号 |
| 简短文字、问题或生活观察 | 少量文字已能建立期待 | 下一画面直接回应这个问题，无需额外准备装饰图 |
| 一个单元或基本关系 | 后续整体依赖陌生读法 | 先认识这个单元或关系，再扩展到群体与比较；[基准与倍数示例](../assets/examples/unit-scale/index.html)演示一种接法 |
| 一个易读的数据发现 | 少量比较或变化本身有吸引力 | 保留已看见的现象，展开它带来的追问 |

入口可以组合，可以自然滚动，也可以是舞台的简洁初态。总体图若能直接读出一个关系，也可开篇；先给必要身份、单位与参照，完整范围和导航随问题展开。图片取得与主题选择见[素材指导](material-direction.md)。

结尾回应主问题及证据边界。仍有值得追问的问题时，可交接探索：选一个问题、一项主要操作与可见结果，例如换时期比较分布、查看代表是否典型。沿用已建立的编码与基准，让操作显示差异、例外或具体记录的意义。完整记录与来源按需查看，不把默认展开的长清单当作探索主体。无需为收尾另加指标或强制返回开头构图；控制接法见[探索交接](implementation-stage.md#探索交接与控件)。

## 从追问选择表达

先明确这一段带来什么新理解，再根据数据选择构图。同一追问可以有多种表达，手法也可组合；表中的方法链接提供更具体的条件和推导，不规定章节顺序。

| 叙事中的追问 | 可选的可视化表达 | 数据条件与主要取舍 |
| --- | --- | --- |
| 看见全局后，哪个局部值得细看？ | 原位高亮、范围放大、提取对象、定位参照；[局部取舍](expression-methods.md#全局到局部原位强调提取还是保留缩略图) | 局部已清楚时原位强调；细节需要空间时提取；仍需定位时留下必要参照 |
| 有了直观差异，到底相差多少？ | 成对点、对齐端点、长度带、差值标记；[连续比较](expression-methods.md#compare) | 对齐口径与基准，让差额可见，减少来回读数 |
| 看起来不同，对齐条件后仍如此吗？ | 固定容量、时期或分母，更新比较；[改变比较口径](expression-methods.md#改变比较口径) | 所需条件可核对；同容量不代表同硬件，同人均不代表已解释成因。说明控制了什么、仍有什么差别 |
| 变化怎样发生，转折在哪里？ | 轨迹、关键时期并置、当前与旧基准；[历史与基准](expression-methods.md#历史中的变化与基准) | 过程用轨迹，精读两期可并置；分清当期值与累计量，缺测或不可比记录不补成连续路径 |
| 一个结果怎样组成或累积？ | 组成条带、分项贡献、历史基底、累积曲线；[组成与累积](expression-methods.md#组成与累积) | 分项可加总；拆开已有整体与接入新增量不同，核对覆盖、重叠与剩余项 |
| 认识了单位关系，量级相差多少？ | 分段长度、固定份额、共同参照下缩放；[单位与量级](expression-methods.md#同量换单位与量级参照) | 换算依据明确；同量换单位保留总体，增加份数则表现总量增长 |
| 平均或总量背后，群体内部怎样不同？ | 堆叠点阵、蜂群、分组矩阵、分布轮廓；[单元分布](expression-methods.md#unit-distribution) | 个体、尾部或详情有意义时用单元；只看集中与跨度可聚合，避让位置不冒充第二变量 |
| 数量最多，贡献也最多吗？ | 等大单元转面积／长度、贡献带、排序；[数量与权重](expression-methods.md#unit-weight) | 同批记录有权重；单元保留个体，长度利于精确比较，面积需照顾长尾和小值 |
| 这个熟悉的对象是典型还是例外？ | 代表与分布对照、从群体提取详情；[个体与群体](expression-methods.md#unit-detail) | 有完整总体及代表选择依据；保留它在群体中的位置线索 |
| 换个分类，会发现原来隐藏的结构吗？ | 分组重排、矩阵、保留旧类别色；[记录重排](expression-methods.md#unit-regroup) | 同批记录有多个属性；重排表达观察方式变化，路径不自动表示真实去向 |
| 庞大的汇总量相当于多少份？ | 固定量图标、方格、分段物件；[聚合单元](expression-methods.md#aggregate-units) | 交代每份量、分母与余量，聚合份额不冒充个体；精确比较可用分段长度 |
| 哪一步发生转折，哪些片段呼应，经历各持续多久？ | 按阶段或参与者排列、连接复现、标出增删、对齐起点；[序列可视化](expression-methods.md#sequence) | 能定位到原始片段；呼应有可核实对应，时长有共同时间尺度，只知先后时不暗示等时距 |
| 对象之间有什么联系？ | 弧线、节点链接、邻接矩阵 | 有可靠关系数据；排序帮助读关系，密集连接可换矩阵 |
| 长期变化中是否存在周期？ | 极坐标、环形排列、周期网格 | 角度或周期有实际含义；形状帮助认模式，精确差值可展开比较 |
| 去向如何，各阶段留下多少？ | 桑基／流带、阶段队列、漏斗 | 流带需要带权连接，阶段比较需要同群体与明确分母；边际总量不能推断流向 |
| 熟悉的实物能帮助理解什么量值？ | 尺度比照、组成对照、图像沿轴移动；[图像与实物](expression-methods.md#objects) | 图像帮助识别，几何承载读数；实际尺寸才按长度缩放，价格等属性绑定量值标记 |

## 关键构图与前后衔接

用真实数据、相邻正文和代表素材推敲结果画面，再设计怎样到达它。正文强调差值，图中就应看见双方及其距离；强调占比，要看见部分和总体；强调变化，要有可比时期与基准。若判断依赖合计差异，独立排出各项读数仍把关键比较留给了读者心算。

有实质分歧时比较少量构图，依据数值跨度、对象数量、精度与空间选择。先查下方[连续片段](#选用连续片段)是否支持这个过程；构图取舍仍不清楚时，再读相关方法卡。

把画面读法写具体：每个标记代表什么，位置、长度、面积、颜色和连线分别表达什么，参照是什么。精读量值采用可比尺度；面积按数据换算，颜色区分类别、量值与当前强调的职责。图片可识别对象或建立情境，图片大小若不编码数量，就让读数由对应几何承担。技术计算见[对象与几何](implementation-geometry.md)。

### 对象关系决定怎样变化

> 上一幅画面让读者看见了＿＿；接下来需要看清＿＿，因此我们要对已有画面进行＿＿。

这句话用于设计备注。随之确认前后数据的对应，再选择动作：

| 对应依据 | 可支持的变化 | 需要保留或说明什么 |
| --- | --- | --- |
| 同一批可识别对象／观测 | 筛选、提取、重排、属性更新 | 稳定身份；区分更新、加入、退出与缺失 |
| 可计算的部分、整体或累积关系 | 展开组成、合并、接入增量 | 单位、范围、分母与覆盖；保留归属及已有量和新增量的区别 |
| 没有直接对象对应，但比较问题成立 | 并置结果、转换参照、清楚交接视角 | 可比口径及变化范围，不把任意点对点运动画成个体流向 |

选出已有记录与把汇总量拆成分项，所需数据不同；同一对象更新与两批样本对比，也不能用同一种身份对应处理。时序不自动提供可加总性或因果。平滑运动只连接已成立的画面，不增加事实关系。

### 主画面与阅读空间

需要追踪对象、比较参照或观看组成过程时，让多段文字共享舞台；单张图已讲清的发现与背景说明可自然滚动。阅读状态按理解需要安排，多段正文可以解释同一状态，不按段落数分屏。

当前问题决定主画面。同一批对象进入局部比较时，让原来的对象成为比较主体；总体仅在仍需定位时收拢为参照，避免保留完整全景又在下方新建另一张主对比图。共享容器、配色或整图淡入淡出不能代替对象关系。需要独立证据、新空间或较长背景时再换场，配图出现不自动要求清屏。

按实际图文占位选择上下、左右或浮层布局：长时间跨度、水平条带需要量值方向的连续空间；正文也要有足够列宽与经过区域。主证据、标签、控件在文字移动时仍需可读。辅助图只保留有用的定位或细节，身份图片随对象安排，普通配图随相关段落进出；主题与排版见[素材指导](material-direction.md)。

### 停留与衔接

**有解释意义的结果由读者停留阅读，只负责连接的动画按自身时长完成。** 停止滚动仍应到达清楚的终态；快滚或反向从当前画面接续。若滚动或拖动本身解释一个变量，每个中间位置就应有可读含义。接法见[舞台控制](implementation-stage.md)。

让主要变化先可辨，次要动作与说明可错峰；轴、标记和标签共享当帧映射，口径变化时交接单位与图例。解释结果的文字出现时，对应证据应已可读。艺术运动可增强质感，量值几何保持正确；动画后留下可读结果，最后一段读完再让舞台自然滚出。

### 正文与图形分工

正文讲问题、发现与意义，主语、时间和比较对象清楚；图内标签负责身份、单位、关键读数和比较条件；来源与详情承接考证、计算过程。制作指令留在设计稿。逻辑来自材料，添加转折词不能替代前后承接；标题、正文和图下注释也无需重复同一结论。

会改变判断的范围、分母与不确定性就近说明；稳定口径可共用图注，变化时重新交代。呼应的关键读数使用一致的单位、精度和舍入规则，对象、时期与分母一致；坐标刻度按自身间隔简洁显示。比喻、幽默和文学表达可建立语气，但不替代证据或扩大结论。

## 选用连续片段

构图时按读者任务和数据关系选择参照，题材或图形不同仍可借用其中的过程。片段演示一个具体问题怎样通过叙事、构图与变化得到解释，可以有多段正文和多个状态。没有整段匹配时，可取其中一个操作或组合几种方法；没有相关参照时自行设计。

| 片段 | 能借用的过程与条件 | 入口 |
| --- | --- | --- |
| `unit-scale` | 先认识基准，保持总量等分，再重复份额、共同缩放并进入记录比较；换算依据明确，可只取其中一个操作 | [HTML](../assets/examples/unit-scale/index.html) · [JS](../assets/examples/unit-scale/scene.mjs) |
| `time-history` | 同口径有序观测：历史继续显露，再让当前端点与旧基准比较；不把当期值堆成累计 | [HTML](../assets/examples/time-history/index.html) · [JS](../assets/examples/time-history/scene.mjs) |
| `record-comparison` | 新记录在共同尺度中加入，旧参照仍可比较，再展开并行记录；适合独立非负量值，不将各条相加 | [HTML](../assets/examples/record-comparison/index.html) · [JS](../assets/examples/record-comparison/scene.mjs) |
| `overview-detail` | 从全景识别对象，再连续提取并对齐尺度；需要稳定身份和可比量值。本段使用零基线条形，整体到局部不绑定条形 | [HTML](../assets/examples/overview-detail/index.html) · [JS](../assets/examples/overview-detail/scene.mjs) |
| `material-composition` | 静态图片识别类别，再与同分母组成区间共同落位；分项互不重复且覆盖总体，图片面积不编码数量 | [HTML](../assets/examples/material-composition/index.html) · [JS](../assets/examples/material-composition/scene.mjs) |
| `material-trend` | 素材直接标记观测，时间推进保留轨迹，再换同比引入参照；比较走势，不把消费价格指数拼成成本 | [HTML](../assets/examples/material-trend/index.html) · [JS](../assets/examples/material-trend/scene.mjs) |
| `material-height` | 新对象超出视域时，先共同缩放并保留旧参照，再加入比较；可只借用尺度交接。本例以素材可见长度编码高度，共用地面并校准计量端点 | [HTML](../assets/examples/material-height/index.html) · [JS](../assets/examples/material-height/scene.mjs) |
| `comparison-basis` | 保留对象与零点，补充分母、突出等份，再改看人均；要求口径可核对，均分份额不冒充实际个体记录 | [HTML](../assets/examples/comparison-basis/index.html) · [JS](../assets/examples/comparison-basis/scene.mjs) |
| `increment-stock` | 先用共同零点比较年度新增，再将相同柱段接到旧存量、形成累计轨迹；保留年份，只覆盖非负新增 | [HTML](../assets/examples/increment-stock/index.html) · [JS](../assets/examples/increment-stock/scene.mjs) |
| `sequence-recurrence` | 先定位一次出现，再连接有依据的前后呼应，回看人物与处境；需要原文位置和关系标注，不把连线当因果 | [HTML](../assets/examples/sequence-recurrence/index.html) · [JS](../assets/examples/sequence-recurrence/scene.mjs) |

摘要用于找到候选。选中后运行 `node scripts/examples.mjs inspect <id>`，直接读取从该例 HTML `#example-notes` 提取的**叙事设计、可视化理由和改编空间**；也可直接读这一小节。判断关键运动时结合该例预览，看对象和参照怎样到达结果，不必通读整库。

依据当前追问确定借用整段、局部操作或重新设计。说明中的理由帮助判断哪些证据需要保留，具体图形、素材、布局和运动可改；只比较结果与解释变化过程，所需步骤可能不同。将取舍与前后画面写进已有设计稿，不另写选型报告。

采用已有实现时，以选中例子的代码为改写起点；自定义部分按[实现问题](implementation.md#按实现问题取用代码)取局部接法。`inspect` 保留具体解释、条件和改写入口，源码的 `entryLines` 帮助定位所借过程，复制清单中的路径相对返回的 `root`；不输出页面或 JS 源码。需要检索时用 `list --query 关键词` 找候选，看过上述入口无需再通读目录。
