# 表达方法卡

本页提供具体构图的推导与取舍，按当前问题选读。表达选择与共同原则见[可视化设计](visualization-design.md#从关系选择表达)，接口和演示用法集中在[实现参考](implementation.md#按实现问题取用代码)。A／B／C 使用模拟数据说明选择过程；单元、序列与图像可以组合，也可另行设计。

<a id="compare"></a>
## 连续比较

比较双方与口径明确后，原位强调能保留全局位置，提取局部能获得细节空间，关键两期并置便于精确对照。时序资料还可保留轨迹、旧记录或参考端点，取舍见[历史参照](stage-and-motion.md#让历史仍可比较)。

### 全局到局部：何时保留缩略图

观察长期趋势中的异常区间：原图已读得清时，直接高亮；局部需要放大且仍需知道它处于全局哪里时，可将总体收拢为定位用的 mini-chart，标出主图窗口。只比较两个已识别对象时，名称与基准可能已足够。

缩略图只保留定位信息。两图时间范围不同时，用选区建立对应，避免相同屏幕位置被误认作同一年。计算见[全局定位与局部尺度](implementation-geometry.md#全局定位与局部尺度)，装配见[历史聚焦演示](../assets/examples/index.html#history-example)。

### 推导 A：总体中的两个样品

模拟材料为六个同口径样品，P 为 42、Q 为 54。要读出差值 12，可以留在总体中加差值标记，也可以提取两者放大细节。前者保留全局位置，后者提供局部空间；本示例选择后者。

全体出现 → 直接标出 P/Q → 两者进入共同比较区 → 轴与对象一起缩放，差值标记跟随端点。数值不变，改变的是尺度与排布；名称足以识别时无需图片。探索可以更换比较对象，全景是否返回取决于下一段问题。

**参考：** [示意 A](../assets/examples/design-frames.svg)、[共同尺度接口](implementation-geometry.md#几何)、[比较演示](../assets/examples/index.html#quantitative-example)。图像参与比较另见[实物推导 C](#objects)。

## 组成与累积

分项需可加总，并明确重叠、剩余项与期间覆盖。只有两个时点的存量时可解释净变化，不能补造流入流出。

一期支出展开为分项，是拆开已有整体：保留外边界或总量标记帮助认出归属。多年新增藏书接入馆藏，是加入新量：上一累计端点成为新增段起点，需计入移出量或有完整净变动记录。长度带利于精确读取，[固定量单元](#aggregate-units)利于逐份阅读。

关键阶段可停读，普通期间可合并为过程，最终比较总量时可弱化分隔线。改看跨期差值时保留两期基准，不把两个存量相加。

**实现：** [区间几何](implementation-geometry.md#组成与累积的区间几何)与[展开／接入演示](../assets/examples/index.html#amount-example)支持非负分段；负项、余量和净流入流出需另算几何。

<a id="unit-distribution"></a>
## U1：记录组成分布

逐项记录的量值、尾部或详情有意义时，可用等大单元沿量值定位并堆叠。例如书籍按页数和类型构成分布，既看长篇集中在哪类，也能查尾部书目；细比页数保留共同轴，改看类别构成可重排网格。只关心总量或记录过密时，聚合表达更直接。

避让方向不代表第二变量，多标签副本需说明并对总体去重。跨期保持单元大小与量值尺度可比，稀疏期不自动放大所有单元。

**实现：** [单元布局](implementation-geometry.md#主题轮廓与单元重组)的 `distributionLayout` 按精确值堆叠，蜂群需另算；[单元演示](../assets/examples/index.html#unit-example)含分布与详情。

<a id="unit-intro"></a>
## U2：主题形象展开为数据

轮廓负责主题识别，再交给第一幅数据视图。例如书目组成翻开的书，再展开为分布；也可由独立装饰点组成主题文字，在进入统计时退场。真实记录只能分配唯一槽位，不能复制填形；装饰点数不作为总体人数。

按实际数量选择可辨的轮廓，弧线、错峰、打散可增强落位过程，重要对象用标签追踪；结果可读后减少无关漂浮。轮廓可来自人物、文字或物件，其位置本身不编码数据。

**参考：** [Hamilton](case-references.md#hamilton)、[轮廓采样与匹配接口](implementation-geometry.md#主题轮廓与单元重组)、[落位演示](../assets/examples/index.html#unit-example)；素材取得见[素材指导](material-direction.md)。

<a id="unit-weight"></a>
## U3：同群体从数量转向权重

用面积比较数量与权重时，同批对象需可匹配，权重非负、分母明确。缺失和零值分开，多标签总体去重。

### 推导 B：项目多，服务时长也多吗

模拟项目有 ID、类别与服务时长。类别总量条易于精确比较；单元面积保留每个项目；共同轴逐项定位便于看具体差异。若当前问题需要从群体回到项目，可以先选单元，再以数值或局部位置比较补充精度。

先每项等大按类别排列，再保持中心，把面积改为服务时长，图例使用相同标定。为最大半径预留槽位可减少无关位移，代价是等大状态更空；长尾难读时可局部提取或改长度比较。极小量用额外点击范围或搜索访问，不抬高编码面积。

**参考：** [示意 B](../assets/examples/design-frames.svg)、[面积换算接口](implementation-geometry.md#几何)、[分组布局](implementation-geometry.md#主题轮廓与单元重组)、[计数与权重演示](../assets/examples/index.html#unit-example)。

<a id="unit-detail"></a>
## U4：代表对象与群体

代表有可追溯的选择依据，如荣誉、角色或编辑标准，时间窗口与身份匹配。在原位置建立标签、头像或封面与单元的对应，再展开细节；头像负责识别，位置继续表达数据，照片大小不默认表示成绩。

例如先介绍熟悉的创作者，再在完整作品分布中定位他的作品，看它们是典型还是例外。也可由群体提取个体，两端仍能认出同一记录。

**参考：** [Love Story](case-references.md#love-story)、[详情演示](../assets/examples/index.html#unit-example)；其接线为 [units.mjs](../assets/examples/units.mjs) 的 `updateDetail / updateRecordOptions`。

<a id="unit-cohorts"></a>
## U5：群体随时间更替

每期总体范围明确，比较的两期共用量值尺度与单元标定；覆盖期不同需说明，不能直接用点数判断增长。成员可匹配时更新属性，并区分进入、退出与缺失；成员不可匹配时并置或更新分布，保留测量参照，运动不代表个体迁移。

例如年度参展作品逐期更新，留存作品保持身份，新作品进入；某两年的风格值得比较时，共同尺度下并置停读。只有汇总量时，使用[聚合单元](#aggregate-units)并说明每份数量。

**参考：** [Love Story 的数据条件](case-references.md#love-story)、[身份与观测更新](implementation-geometry.md#把关系落实为几何)。[类别筛选演示](../assets/examples/index.html#unit-example)只示范进入退出，不包含跨期追访。

<a id="unit-regroup"></a>
## U6：用另一种方式组织同批记录

同一总体有多个属性，前后构图各自支持发现，再安排重排。例如展品先按年代排列，再按材料分组，保留年代颜色就能看不同材料集中出现的时期；若重点是新类别，则换色并同步图例。

新分组含义先可辨，再按同一身份移动到新位置。多标签不擅自压成互斥类别；路径可有艺术设计，但真实流向需另有数据。

**参考：** [Hamilton](case-references.md#hamilton)、[Love Story](case-references.md#love-story)、[单元布局与匹配](implementation-geometry.md#主题轮廓与单元重组)、[分布／分组演示](../assets/examples/index.html#unit-example)。

<a id="aggregate-units"></a>
## 聚合单元：没有个体明细时

一点可代表固定数量或比例，如每格代表相同发电量，按能源类别聚集。写清单位量、分母与不足一格的余量；数量级变化需重新选单位时，交代新标定。形状与聚散可变，完整状态的数量含义仍明确。

展示单元 ID 用于绘制，详情回到真实汇总记录，不能当作个体追踪。先计算份数与余量，再借用[单元布局](implementation-geometry.md#主题轮廓与单元重组)；当前没有完整的固定量／余数示例。

<a id="sequence"></a>
## 序列对齐：比较结构与相对位置

序列具有可定义的顺序、时长或共同起点，才能通过对齐读取偏移、重复或缺席。例如活动按开始日对齐，比较关注高峰的相对时间；文本按段落顺序排列，标出真实重复片段。

绝对日期、相对时间、序号与归一化进度分别定义，强行同长会抹去时长差异；缺段保留为缺失。

**参考：** [Hamilton](case-references.md#hamilton)启发文本单元与结构组织；可借用[尺度接口](implementation-geometry.md#几何)。当前无专门的序列示意或完整实现，片段、基准和连接几何需自行设计。

<a id="objects"></a>
## 图像与实物参与表达

图像可与量值标记绑定、标识组成分项，或在共同参照下体现尺寸。身份、场景与数值几何的分工见[素材指导](material-direction.md#配图与引入或参与编码)。

### 推导 C：熟悉的餐点，怎样读清涨价

模拟总额为 20 与 24，可加总分项为 [5, 8, 7] 与 [8, 9, 7]。直接改变食物厚度容易让人联想到份量；本例保留食物外观，用旁置金额带精确比较，再以图像识别各分项。

先认识整份餐点 → 配对金额带读出总差额 → 展开金额组成，突出第一项从 5 到 8。旧端点提供参照；餐点图片保持完整，分项可由独立的静态图标或名称识别。若材料只有各类价格指数，就改成共同基期的轨迹比较，设计稿随之调整。

**参考：** [ABC 汉堡作品](case-references.md#burger)、[示意 C](../assets/examples/design-frames.svg)。[共同锚点](implementation-geometry.md#几何)可连接图像与数据；C 尚无完整装配，分项几何按材料设计。
