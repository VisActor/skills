# 表达方法卡

从[追问与表达选择表](design.md#从追问选择表达)进入当前需要的小节。本页深入比较具体构图的条件、收益与代价，并用例子连接实现；整篇叙事、阅读空间与通用衔接判断集中在设计指导。

A／B／C 使用模拟数据演示推导，不是固定页面；单元、序列与图像可以组合，也可另行设计。接口说明集中在[实现参考](implementation.md#按实现问题取用代码)，本页不重复说明调用方式。

## 连续比较

### 历史中的变化与基准

同口径的有序观测可以呈现变化路径；要回答“增长后是否回到旧水平”，让历史轨迹继续可见，再将当前端点与旧基准对齐。只需精读两期差额时，并置端点可能更直接；存在缺测或口径变化时，标出断点，不能用平滑轨迹补出连续观测。

历史参照可保留为轨迹、记录行、关键时期分布、参考端点或累计基底，以当前追问选择。数据密集时压缩细节、按有依据的期间聚合或并置关键时期，保留转折、例外与基准；只需当期构成或旧口径已不可比时，可退出旧内容并交代范围。`time-history` 实现“显露变化，再回看基准”，展示当期值而非逐期累加。[完整片段](../assets/examples/time-history/index.html) · [数据与动画](../assets/examples/time-history/scene.mjs)

### 新记录加入共同尺度

接入新记录时，先区分记录加入、同一对象更新和数量累加。不同标准或产品规格是独立记录：共同零点与量值尺度让旧参照、新对象可以直接比较；纵向排列不自动表示等长的时间间隔。同一时期的并行记录可分组展开，微小差值就地标注。

[尺的比较片段](../assets/examples/record-comparison/index.html)从一条参照开始，让新条加入新行，旧条保持长度并调整行距；同代大小尺一起出现，最后在主图比较一对端点。条形适合精读单一非负量值；范围用区间、连续观测用轨迹，按当前问题选择。只看当期构成时可退出不相关历史，不必无限堆行。[数据与动画](../assets/examples/record-comparison/scene.mjs)把真实条长与入场遮罩分开，改写记录、参照和加入顺序，不沿用朝代章节。

### 全局到局部：原位强调、提取还是保留缩略图

局部在总体中已读得清时，直接高亮；精读对象需要空间时，可把同一批标记提取到比较区；放大一段轨迹且仍需知道它处于全局哪里时，可将总体收拢为定位用的 mini-chart，标出主图窗口。只比较两个已识别对象时，名称与基准可能已足够。

缩略图只保留定位信息。两图时间范围不同时，用选区建立对应，避免相同屏幕位置被误认作同一年。计算见[全局定位与局部尺度](implementation-geometry.md#全局定位与局部尺度)，装配见[历史聚焦演示](../assets/examples/history/index.html)。

`overview-detail` 实现“全景中识别一对记录，再连续提取比较”。数据有稳定身份和可比量值时，可以从这一完整过程改写；它采用零基线条形，其他标记按数据关系选择。[完整片段](../assets/examples/overview-detail/index.html) · [数据与动画](../assets/examples/overview-detail/scene.mjs)

### 推导 A：总体中的两个样品

模拟材料为六个同口径样品的重量，P 为 42 克、Q 为 54 克。要读出差值 12 克，可以留在总体中加差值标记，也可以提取两者放大细节。前者保留全局位置，后者提供局部空间；本示例选择后者，用零基线条长比较重量。

全体出现 → 直接标出 P/Q → 原来的两根条移入共同比较区 → 零点保持，刻度与条长一起缩放 → 就位后标出端点差值。重量不变，条的粗细只作强调；名称足以识别时无需图片。探索可以更换比较对象，全景是否返回取决于下一段问题。

“整体到局部”决定如何承接对象，不指定图形类型。少量类别的量值大小适合条形；记录的二维位置或分布可用点，连续轨迹可用线，个体组成可用单元。所选编码的含义应贯穿衔接。

**参考：** [示意 A](../assets/examples/design-frames.svg)、[共同尺度接口](implementation-geometry.md#几何)、[比较演示](../assets/examples/comparison/index.html)。图像参与比较另见[实物推导 C](#objects)。

### 改变比较口径

先判断需要控制的是条件还是分母。同容量比较需选中对应型号／容量的真实记录；总量转人均需同范围的总量与人口；不同价格转指数需各自可核对的正基期。它们都改变比较问题，计算过程不能互相替代。

[借阅片段](../assets/examples/comparison-basis/index.html)保留两个城区的身份，先补人口，再从总量中突出等人口的平均份额，最后换为人均尺度。这个中间步骤让除数可见，代价是多一个需要解释的状态；读者已熟悉人均时可以直接交接口径。均分后的格子是计算份额，不是原始居民记录。图片、原值与新值也无需同时完整保留，留下当前判断所需的参照即可。[数据与动画](../assets/examples/comparison-basis/scene.mjs)

## 同量换单位与量级参照

读者需要先认识基准或量级时，把同量换单位、增加份数和改变视域分清。等分已有整体时总量保持；重复一份时让新增份数可见；需要缩放时，标记与刻度共用当帧尺度，原份仍可辨。换算依据须明确，数值正确的两个终态还不足以解释它们的关系。

[时间片段](../assets/examples/unit-scale/index.html)先将一分钟等分，再保留原份、放远视域并接成一小时，最后将时间带收拢为分钟参照、共同放大后加入两条等候记录。题材、图形与出现顺序可重选；只问两条记录相差多少时可省略单位解释。新记录不是原参照的组成项，应分别建立身份。[数据与动画](../assets/examples/unit-scale/scene.mjs)

## 组成与累积

分项需可加总，并明确重叠、剩余项与期间覆盖。只有两个时点的存量时可解释净变化，不能补造流入流出。

一期支出展开为分项，是拆开已有整体：保留外边界或总量标记帮助认出归属。多年新增藏书接入馆藏，是加入新量：上一累计端点成为新增段起点，需计入移出量或有完整净变动记录。长度带利于精确读取，[固定量单元](#aggregate-units)利于逐份阅读。

关键阶段可停读，普通期间可合并为过程，最终比较总量时可弱化分隔线。改看跨期差值时保留两期基准，不把两个存量相加。

**实现：** [区间几何](implementation-geometry.md#组成与累积的区间几何)与[展开／接入演示](../assets/examples/amounts/index.html)支持非负分段；负项、余量和净流入流出需另算几何。

[新增与累计片段](../assets/examples/increment-stock/index.html)先按年份并列新增量，给年度差异共同零点；随后统一缩放，引入旧存量，让同一批柱段按年抬升接成累计轨迹。年份、数量和 ID 保留，最后读累计差距。只需年度比较时停在前段；要解释累计结果才接回基底。改写时核实新增是否完整、是否存在移出，结论由数据决定。[数据与动画](../assets/examples/increment-stock/scene.mjs)

## 单元可视化

先交代一个标记代表什么。一点代表一条记录时，读者可以在分布与分组之间跟住同一个对象。一格代表固定数量时，格数表达总量，各类别所占的格数表达构成。记录有多个标签时可以分属多组，统计不同对象的总数时按身份去重。

需要观察群体里的个体差异、跟随同批对象重新分组，或从数量追问贡献时，单元能把前后问题落在同一批可辨对象上。若只需精读组间总量差，共同基线上的长度更直接；同篇可以按当前问题组合使用。选择单元后，先明确前后分别要看见什么，再决定改变位置、大小、颜色还是高亮。

| 当前问题 | 方法 |
| --- | --- |
| 记录集中在哪，尾部有哪些个体？ | [U1 · 记录组成分布](#unit-records) |
| 怎样从熟悉的主题进入数据？ | [U2 · 主题形象展开](#unit-intro) |
| 数量多的组，贡献也大吗？ | [U3 · 数量转向权重](#unit-weight) |
| 一个代表在群体中处于什么位置？ | [U4 · 代表对象与群体](#unit-detail) |
| 两期的成员与分布怎样变化？ | [U5 · 群体随时间更替](#unit-cohorts) |
| 同批记录换个分类，会出现什么结构？ | [U6 · 同批记录重组](#unit-regroup) |

按当前问题选读对应小节；几种方法可以组合，阅读顺序由故事决定。只有汇总数据时，先明确[每个显示单元的数量含义](#aggregate-units)。[单元机制预览](../assets/examples/units/index.html)与同目录代码示范其中的分布、轮廓、权重及筛选接法。

<a id="unit-records"></a>
### U1 · 记录组成分布

逐条记录的差异、尾部或详情值得观察时，可用等大单元沿量值定位并堆叠。例如书籍按页数和类型构成分布，既看长篇集中在哪类，也能查到尾部书目。只关心集中范围或组间总量、记录又过密时，可保留聚合轮廓，在需要辨认个体的局部展开。

细比量值时保留共同轴；从分布改看类别数量时，可以将同批记录重排为分组网格。身份、类别色或选中对象可作为前后参照。堆叠方向只用于避让，不代表第二变量。跨期比较保持单元标定可比，样本少的一期自然显得稀疏；局部需要放大时，连同量值轴说明新的观察范围。

**实现：** [units/scene.mjs](../assets/examples/units/scene.mjs) 的 `unitPose / blendUnits / renderUnits` 展示分布与分组接线；`distributionLayout` 按精确值堆叠，蜂群避让需另算。

<a id="unit-intro"></a>
### U2 · 主题形象展开

轮廓先让人认出主题，展开后的排列回答第一个数据问题。如书目组成一本书，再散开看作品年代：轮廓位置负责主题识别，落位后的坐标才编码年代。也可用独立装饰点组成文字或物件，在统计视图出现时退场。

用真实记录构形时，按记录数选择可辨的轮廓，每条只占一个位置；可以标出其中一条，让它在落位后仍可辨。弧线、错峰或打散可加强展开感，目标构图清楚后让读者停下来读。轮廓与数据布局无需相像，关键是交接时能理解这些标记开始代表什么。

**实现：** [轮廓采样与一一分配](implementation-geometry.md#主题轮廓与单元重组)提供槽位与身份接法；[units/scene.mjs](../assets/examples/units/scene.mjs) 的 `cover → distribution` 演示一种展开路径，轮廓、方向和节奏由作品设计。

<a id="unit-weight"></a>
### U3 · 数量转向权重

同批对象有非负权重，且问题需要看清哪些个体贡献更多时，可先用等大标记看数量，再用面积或每项占据的长度表达权重。两幅画面分别回答“有多少项”和“各项贡献多少”，保留身份与组别，让贡献差异落在原来的对象上。各组使用可比标尺；比例视图另交代分母，缺失与零值分开。

**推导 B · 项目多，服务时长也多吗？** 模拟项目有 ID、类别与服务时长。先每项等大按类别排列，再保持中心，把面积改为服务时长，读者便能看到少数长时项目如何改变各组的轻重。为最大圆预留空间能减少无关位移，代价是初始布局更松。也可把同批项目排成贡献带，让每段长度表示该项目的时长；位置、分组与权重共同变化时，应让读者辨认出这些仍是原来的项目。

若只需精读各组总时长，可用共同基线上的长度。权重长尾导致小项难以读取时，可以提取局部或提供详情；扩大点击范围不改变编码面积。

**实现：** [面积换算](implementation-geometry.md#几何)与 [units/scene.mjs](../assets/examples/units/scene.mjs) 的 `groups / weights` 示例；长度贡献带可按可加总项计算[组成区间](implementation-geometry.md#组成与累积的区间几何)。[关键画面 B](../assets/examples/design-frames.svg)展示一种面积方案。

<a id="unit-detail"></a>
### U4 · 代表对象与群体

当熟悉的对象能引出问题，或个体能解释群体中的异常时，可从代表进入总体，也可从分布中提取代表。例如先介绍一位创作者，再定位其作品在完整作品分布中的位置，观察它们是典型还是例外。代表应有可追溯的选择依据，荣誉、角色与观测时期对应。

先在原位置建立标签、头像或封面与单元的联系，再展开详情。需要放大时保留群体中的位置线索，收起后仍能找到对象。图片负责识别，位置或面积继续承担已说明的数据编码；照片大小不默认表示成绩。

**实现：** [units/scene.mjs](../assets/examples/units/scene.mjs) 的 `updateDetail / updateRecordOptions` 接回真实记录；图片需要跟随图形移动时，使用[身份图片与数据锚点](implementation-geometry.md#几何)的接法。

<a id="unit-cohorts"></a>
### U5 · 群体随时间更替

各期都有明确的覆盖范围与统计口径时，可以比较成员、量值分布和构成。成员可匹配时，分别处理留存、加入、退出和缺测：例如参展作品逐年更新，旧作保留身份，新作进入，读者能同时看到规模和构成变化。成员不可匹配时，比较的是两批样本的分布，不把任意点对点运动当作个体迁移。

同一量值轴和单元标定帮助跨期阅读。需要看发展时，可留下此前的分布轮廓、关键端点或记录；需要精读两期时，可并置并突出共同范围。参照保留哪些内容取决于问题，不必让每期完整点阵始终叠在一起。覆盖时长或样本范围不同，点数本身不能直接说明增长。

**实现：** [身份与观测更新](implementation-geometry.md#把关系落实为几何)配合 `blendNodes` 处理进入、退出和更新；历史参照由[完整目标状态](implementation-geometry.md#历史与当前从同一状态生成)一起生成。跨期观测选择与缺测由作品数据层处理。

<a id="unit-regroup"></a>
### U6 · 同批记录重组

同一总体具有多个属性，换一种组织方式能揭示新的结构时，重组可以让两个问题使用同一批可辨对象。例如展品先按年代排列，读出各时期的数量，再按材料分组；保留年代色，就能看出某种材料集中出现在哪些时期。若下一问更关注新类别，则交接颜色和图例。

前后构图各自支持一个发现，先让新组的位置与含义可辨，再按记录 ID 移动。按当前问题保留有用的颜色、标签或选中对象；运动路径可有设计，但终态需要清楚可读。多标签记录可以出现对应副本，统计总体仍按对象去重。重排表达观察方式变化；解释为实际去向时，应有联合分组或路径数据支持。

**实现：** [分布／分组示例](../assets/examples/units/scene.mjs)对同批记录计算两套布局，再由 `blendNodes` 按键衔接；更换分类时使用作品自己的字段与分组逻辑。

<a id="aggregate-units"></a>
### 只有汇总量时

为每格指定固定数量或比例，交代分母与不足一格的余量。单位量改变时重新说明标定。展示单元可回查所属汇总记录，个体详情需要真实个体数据。

汇总记录也可以承载连续单元。例如数据给出各条路径及人数，可按每条路径的人数展开匿名计数槽位，沿已知去向重排；一个槽位只代表这条路径上的一份人数，不提供个人身份。若只有两个时点各组的总数，没有联合分组或路径，仍可比较构成，但不能把任意配对画成真实的个人去向。

**实现：** 先计算份数与余量，再借用[单元布局与匹配](implementation-geometry.md#主题轮廓与单元重组)；当前示例未覆盖完整的固定量与余数处理。

<a id="sequence"></a>
## 序列可视化

用事件、观测或原文片段的位置呈现先后、持续和前后呼应。正文可以先讲结局，图上用场次、段落号或日期标出各片段在原材料中的位置。只知道先后时可以等距排列；用距离表示时间时，保留实际间隔并标出缺测。

**同一句话，谁在叮嘱谁？** 一段虚构的对白：

> 第 2 场，母亲送女儿出门：“到了给我打个电话。”
>
> 第 8 场，女儿送母亲出门：“到了给我打个电话。”

问“谁说过这句话”，可按人物分组。要让读者看出两次送行中母女互换了角色，按场次把两句并排，标明谁对谁说，就够了。若要在整部戏里追踪多处呼应，可标出每次出现的位置，再连接有原文或标注支持的片段，供读者回看上下文。

[序列呼应片段](../assets/examples/sequence-recurrence/index.html)将这一类比较展开为三次出现：先定位片段，新记录可读后绘出呼应，最后回看说话人与处境。它借鉴 Common Threads 的组织方式，使用自写虚构材料；弧线表达有依据的对应，不代表数量转移或因果。场次位置固定，密集或多主题关系需另排布局。[数据与动画](../assets/examples/sequence-recurrence/scene.mjs)集中给出出处、关系依据与阅读端点；持续时长的对齐另见下例。

**哪天结束，哪一段持续更久？** 取香港天文台测站每年夏季（6–8 月）最长的一串热夜。2022 年是 7 月 9–29 日，2024 年是 7 月 20–26 日。按七月日期排，两个终点只差三格。把两串的第一夜对齐，每格的宽度和原日期都保留，便能直接比较 21 夜和 7 夜。若要比较各阶段占全程的比例，再把全长换算成百分比。[日历与第一夜演示](../assets/examples/sequence/index.html) · [整段平移的实现](../assets/examples/sequence/scene.mjs)

## 图像与实物参与表达

图像可与量值标记绑定、标识组成分项，或在共同参照下体现尺寸。身份、场景与数值几何的分工见[素材指导](material-direction.md#配图与引入或参与编码)。

### 推导 C：熟悉的餐点，怎样读清涨价

模拟总额为 20 与 24，可加总分项为 [5, 8, 7] 与 [8, 9, 7]。直接改变食物厚度容易让人联想到份量；本例保留食物外观，用旁置金额带精确比较，再以图像识别各分项。

先认识整份餐点 → 配对金额带读出总差额 → 展开金额组成，突出第一项从 5 到 8。旧端点提供参照；餐点图片保持完整，分项可由独立的静态图标或名称识别。若材料只有各类价格指数，就改成共同基期的轨迹比较，设计稿随之调整。

金额带与餐点图像的布局见[示意 C](../assets/examples/design-frames.svg)。图像随价格标记移动时可使用[共同锚点](implementation-geometry.md#几何)。分项的布局和动画需按作品数据实现。

### 已实现片段：从生活场景进入组成比较

[食物废弃物示范](../assets/examples/material-composition/index.html)先用三张静态插画识别家庭、餐饮和零售，再让它们与各自的占比区间一起落位；色带组成总量后，半数参照线才出现。图像编码类别，长度编码份额，图像面积不编码数量。分项使用同一分母且互不重复时，可借用这种分工。

目录 id 为 `material-composition`；[数据与动画](../assets/examples/material-composition/scene.mjs)、HTML 和 `images/` 位于同一目录。本段没有实现跨期累积，相关判断见[组成与累积](#组成与累积)。

### 已实现片段：图片标识比较中的走势

[汉堡片段](../assets/examples/material-trend/index.html)让图片直接成为各次报价的标记，时间推进时保留已出现的轨迹；同批观测再转同比，时间位置不变。比较食材时保留汉堡，只在端点或有解释意义的观测处留图片，逐项检验是否同步。图片大小用于阅读重点，不编码数量；不同频率按真实日期排列，密集观测可改用小点或只标关键时点。

目录 id 为 `material-trend`；[数据与动画](../assets/examples/material-trend/scene.mjs)和静态 SVG 素材同目录。各类价格指数不能相加成汉堡成本，消费价格走势也不直接代表餐厅采购成本。换题时选择有解释意义的时间节点与参照，核实上年同期口径；重写结论和标签位置，不沿用食材顺序。

### 已实现片段：素材的尺寸就是比较量

[高楼片段](../assets/examples/material-height/index.html)先留下一座建筑作为参照，再按竣工年代接入后来者；共同地面保留，观看范围不够时先把轴与旧对象一起缩小，再接入新对象，原位比较微小超越、跨过半公里和明显跃升。同一帧的高度比例一致，跨状态的比例可以改变。这里素材可见高度直接编码建筑高度，楼宽与立面细节仅用于识别。与纯粹标识类别的图片不同，需要用素材内的地面与尖顶校准映射，不能把图片框或透明留白算进高度。

目录 id 为 `material-height`；[数据与动画](../assets/examples/material-height/scene.mjs)配置记录、素材端点、比较对及每段 `axisMax`。旧对象随尺度一起缩放、横向让位，新对象随后用遮罩显露；真实读数始终不变。运动表示记录加入，不模拟施工。换题时重选新增理由与参照，也可用于非时序的认识补充；对象数量、构图和正文按实际材料改写。价格等抽象量不宜直接借物体尺寸编码，除非读法已明确。
