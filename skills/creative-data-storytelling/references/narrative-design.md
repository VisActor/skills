# 叙事编排：从问题组织阅读

本页负责主问题、证据顺序、正文与引入收尾；具体画面由[可视化设计](visualization-design.md)推敲。

## 主问题先于章节

从用户关注点与数据出发，说明读者的原有认识和需要新增的理解。主题是“某产品的价格”，问题可以是“看起来更贵，究竟比较了什么”。用一句话提出主问题，再串起支持它的证据与最终判断。

有多个方向时，比较最有力的发现、对读者的意义和证据范围；用户已选定则细化。推进判断的证据进入主线，必要背景就近补充，旁支留给详情或有用的探索，重复证实可合并。只能支持关联时不扩大为原因；构图推敲发现证据不足时，修订问题与顺序。

有时间字段时，停在值得解释的变化与转折。可以从结果回看历史、从长期聚焦短期，再展开组成或群体差异；普通年份可在过程里经过。

## 从发现建立阅读关系

把事实接成解释。例如“类别 A 有更多记录”提供一个观察；若投入权重不同，“记录最多是否也投入最多”就产生下一项比较。新段落应回应前文留下的疑问，或用证据修正、深化当前理解。

可用以下关系编排，不要求统一故事弧：

| 当前理解 | 下一段的作用 | 需要的证据 |
| --- | --- | --- |
| 看见总体变化 | 解释哪些部分与总体不同 | 可比较的分项或群体 |
| 熟悉一个代表对象 | 判断它是典型还是例外 | 代表选择依据与完整总体 |
| 得到一个直观比较 | 对齐口径后修正判断 | 配置、时间、分母等可核对条件 |
| 看见一个结果 | 追溯怎样累积或组成 | 有时间顺序／加总关系的记录 |
| 找到共同模式 | 展示会改变理解的例外 | 真实反例与可能的解释边界 |
| 理解作者的发现 | 用相同视觉语言追问自己的问题 | 有价值的可选维度与足够数据 |

需要图形连续变化时，可用下面的句式明确意图，它属于设计备注：

> 上一幅画面让读者看见了＿＿；接下来需要看清＿＿，因此我们要对已有画面进行＿＿。

例如：“已经看见总体增长，接下来要找出哪些群体贡献增长。”再按[表达选择](visualization-design.md#从关系选择表达)决定：可展开可加总分项，也可并置各群体的增量，以共同参照读出贡献。叙事关系提供选择依据，具体构图由数据与阅读任务决定；普通图文也可接续同一追问。

### 对照：指标齐全，仍未回答问题

模拟材料中，平均等候从30分钟降至20分钟，等候超过一小时的比例却几乎未变；要回答的是“等候的改善是否普遍”。

- **看似完成：** 接待量 → 平均等候 → 超时比例，每项一图一句结论，读者仍需自行拼出反差。
- **修正方向：** 先看平均值下降，再追问长等候是否减少。正文可接成“平均等候缩短了10分钟，超过一小时的比例却几乎没变。”有可比分组时再问哪些人仍在长等候；接待量只在帮助理解时进入主线。

业务概况可以并列多指标，不必强造反转或因果。

## 让追问组成连续段落

把相邻正文与[关键构图](visualization-design.md#用关键构图选择方案)一起推敲：这句话要求比较谁，证据在图中哪里，下一段怎样接着解释。构图揭示更有价值的关系时可重写正文；图形无法支持的判断回到证据。确定完整的解释过程后，再按[舞台判断](stage-and-motion.md#决定哪些状态共享舞台)安排阅读形式。

## 把段落写成可阅读的正文

写实际相邻段落，让主语、时间与比较对象可辨。正文讲对象发生了什么、差别为何值得注意；“保留参照、重新排列”等制作指令留在设计稿。逻辑来自材料，补“然而”“背后”等连接词不能替代承接。标题提示问题或发现，普通解释可直接续写，断行与标题密度服从阅读。

按一段完整阅读分配信息，不要求每个状态都附齐所有说明：

| 信息去处 | 承担的内容 |
| --- | --- |
| 正文 | 问题、发现、背景与意义，交代为什么接着看 |
| 图内标签、标注或图注 | 对象、单位、关键读数与比较条件；陌生编码首次出现时的读法 |
| 来源与按需详情 | 支撑发现的出处、考证与计算过程，供进一步核对 |

直接影响判断的时间范围、分母与不确定性就近呈现，如“研究估值”；稳定口径可共用图注，变化时重新交代。关键数字可以复现以建立对应，同一结论无需在标题、正文与图下各讲一遍。

比喻、幽默与文学表达可以建立语气，但应让对象和关系更易理解，不能替代证据或扩大结论。

## 引入与收尾

### 开篇的选择与交接

开篇让读者认出对象、产生追问，并获得读懂后续数据的最低限度理解。按已有经验、问题吸引力、编码陌生程度和素材条件选择入口：

| 可选入口 | 选择依据 | 接入数据时延续什么 |
| --- | --- | --- |
| 熟悉的物件、人物或情境 | 具体对象能建立代入感，或抽象问题需要生活背景 | 保留对象身份或问题，例如产品图片与价格标记关联，再加入可比较的型号 |
| 简短文字、问题或生活观察 | 少量文字已能让读者理解主题并产生追问 | 下一画面给出回应问题的第一项证据；无需为了引入额外准备图片 |
| 一个单元或基本关系 | 后续整体需要读者先理解一个点、一个量或一种对应 | 先让这个单元可理解，再扩展到群体、组成或比较，延续已说明的含义 |
| 一个容易读懂的数据发现 | 少量比较或清楚的变化本身足以引发兴趣 | 保留已看见的现象，再展开总体、历史或组成，回答它带来的追问 |

入口可组合，也可另行设计；可以是舞台的简洁初态或正常滚动段落。总体图若容易识别、读数并提出问题，也可直接开篇。先提供当前需要的身份、单位和参照，完整范围与导航随追问展开；开篇已有证据时直接接下一项发现。

把开篇文字、必要元素与第一项证据一起设计，延续对象、参照、编码或问题。主题轮廓见[主题形象展开](expression-methods.md#unit-intro)，图片准备见[素材指导](material-direction.md)，效果并入[阅读验收](quality.md#开篇与首个数据画面的阅读检查)。

### 收尾与探索

主线结束或中段仍有值得追问的问题时，可交接探索。先选一个问题、一项主要操作与可见结果，如“换个时期，分布仍相似吗”或“这个对象在同类中哪里”。比较、例外和具体记录都可有价值；额外维度确实帮助回答问题时再加控件。

涉及变化时保留比较基准，沿用主线读法，操作后不仅是换一组数字。控制交接见[舞台指导](stage-and-motion.md#探索的交接)。没有值得追问的问题时直接收尾：回应主问题及证据边界，可综合已有发现，不要求新增指标或返回开头构图。
