# 可视化设计推导

本页把读者问题变成可见证据，解决表达选择、编码与前后对应。阅读空间与节奏见[舞台与运动](stage-and-motion.md)，制作见[实现参考](implementation.md)。

## 把发现写成一个视觉任务

“介绍文章的阅读量”是题目；“文章篇数最多的类别，阅读总量是否也最多”是可设计的问题。进一步写成：同一批文章，先比较各类别的篇数，再比较阅读总量，找出两者差异。

明确对象、属性、分母与例外，选定这一画面要让读者看见的关系。例如解释总变化由哪些部分形成，独立展示各项读数还不够，需要让分项与总变化的联系可见。

## 用关键构图选择方案

用真实数据与相邻正文推敲结果画面，再设计怎样到达它。若判断依赖两组的合计差异，就让合计成为直接可比的长度、面积或端点；各项单独排开会把合计比较留给读者心算。

有实质分歧时比较少量构图，如原位标差值或提取局部；按数值跨度、对象数量、比较精度与空间选择，也可组合或提出新表达。将对象、尺度、位置与交接具体到能还原画面，写入[设计稿](workflow.md#design-record)；仅写“突出差异”或图表名称还不足以决定实现。

### 对照：位置没变，前后关系却断了

要解释各区域用水量的变化怎样形成全市净变化，数据已覆盖全部区域、口径一致且可加总。

- **看似完成：** 各区域变化展示后淡出，再出现全市净变化。位置和配色统一，却看不见分项怎样形成结果。
- **修正方向：** 让分项逐步组成总体，或并置分项与总体，用对应区间、连接或联动强调呈现增减的作用。

共享舞台若仅靠整图替换而丢失关键关系，应先补清构图再实现。独立发现可按[阅读形式](stage-and-motion.md#决定哪些状态共享舞台)自然接续；没有对象对应时不制造流向。

## 从关系选择表达

先明确这一段怎样推进理解，再看数据能支持哪些表达。同样讲变化，轨迹揭示过程，关键时期并置便于精确对照，分布可揭示均值遮住的差异；按当前追问选择。下表提供候选与取舍，链接补充构图推导，已有方案清楚时可直接实现。

| 叙事要推进什么 | 可选的可视化表达 | 数据条件与设计取舍 |
| --- | --- | --- |
| 看见全局后，追到一个局部 | 原位高亮、范围放大、提取对象、主图与定位参照；[连续比较](expression-methods.md#compare) | 局部已清楚时原位强调；需要细节时放大，仍需定位时保留全局参照；汇总量拆分需有组成数据 |
| 从直观差异，追问到底相差多少 | 成对点、对齐端点、长度带、差值标记；[连续比较](expression-methods.md#compare) | 先对齐口径，用共同位置或长度精确比较；把差额画出，减少来回读数 |
| 沿时间辨认变化和转折 | 轨迹、关键时期并置、当前值与基准；[连续比较](expression-methods.md#compare) | 过程用轨迹，细比用并置；保留有用历史，区分当期更新与累计增长 |
| 回看一个结果怎样组成或累积 | 组成条带、历史基底、分段堆积、累积曲线；[组成与累积](expression-methods.md#组成与累积) | 有可加总分项或期间量；拆开已有总量与接入新增量是不同过程，标清覆盖与剩余项 |
| 先理解单位关系，再比较量级 | 分段长度、固定份额、共同参照下的缩放 | 换算依据明确，单位和量值同步；同量换单位保留总体，增加份数则表现总量增长 |
| 从平均或总量，追问群体内部的差异 | 堆叠点阵、蜂群、分组矩阵、分布轮廓；[单元分布](expression-methods.md#unit-distribution) | 个体、尾部或详情有意义时用单元；只看集中与跨度可聚合，避免把避让当第二变量 |
| 从数量多，追问贡献是否也多 | 等大单元转面积／长度、排序、累积贡献；[数量与权重](expression-methods.md#unit-weight) | 同批对象有权重；单元保留个体，长度利于精确比较，面积需兼顾长尾和小值 |
| 换一个分类，揭示原来隐藏的结构 | 分组重排、矩阵、保留旧类别色；[记录重排](expression-methods.md#unit-regroup) | 同批记录有多个属性；旧色可显示分类交叉，重排路径不自动表示真实流向 |
| 把庞大汇总量变成可理解的份数 | 固定量图标、方格、分段物件；[聚合单元](expression-methods.md#aggregate-units) | 标明每份量与余量；需精确比较时可用共同尺度的分段长度／面积，聚合份额不冒充个体 |
| 转折发生在哪一步，哪些片段前后呼应，两段经历各持续多久 | 标出阶段或按参与者分行，连接复现的片段，并排标出两版原文的增删，或对齐同类事件的起点。[序列可视化](expression-methods.md#sequence) | 能定位到材料中的原始片段。连接复现需要可核实的对应，比较时长需要共同的时间尺度 |
| 从对象追到联系 | 弧线、节点链接、邻接矩阵 | 有可靠关系数据；排序帮助读关系，密集连接可改矩阵 |
| 从长期变化中辨认周期 | 极坐标、环形排列、周期网格 | 角度／周期有实际含义；形状帮助认模式，精确差值可展开比较 |
| 追踪去向，或追问各阶段留下多少 | 桑基／流带、阶段队列、漏斗 | 流带需要带权连接，阶段比较需要同群体与明确分母；边际总量不能推断流向 |
| 借熟悉实物理解抽象量值 | 尺度比照、组成对照、图像沿轴移动；[图像与实物](expression-methods.md#objects) | 图像帮助识别，几何承载读数；实际尺寸才按长度缩放，价格等属性可绑定量值标记 |

这些手法可以组合。例如每段发言用一个标记，按原顺序摆放，再用人物头像标出同一句话在谁口中重现。[主题形象展开](expression-methods.md#unit-intro) · [个体与群体](expression-methods.md#unit-detail)

## 分配单元、通道和参照

用一句话确定关键画面的读法，例如：

> 每个标记是一项记录；横向位置表示量值；纵向只负责分组和避让；颜色表示类别；强调描边表示当前选中。

每个通道职责明确，叠加强调应有额外阅读收益。

| 选择 | 设计判断 |
| --- | --- |
| 单元 | 一个人、一件作品、一次观测，还是固定量的聚合份额？详情回到哪个对象？ |
| 位置／长度 | 共同尺度、对齐基准、起点与范围是什么？缩放后怎样保留参照？ |
| 面积 | 权重是什么，分母是什么，极小值如何访问？圆面积用平方根换算半径 |
| 颜色 | 用于稳定分类、连续量值还是当前强调？在关键变义时同步解释 |
| 关系连线 | 连接哪两个对象，表示什么关系？有明确方向时是否需要箭头，有量值时是否用线宽编码？ |
| 素材 | 精确编码、对象识别、情境、主题象征分别由谁承担？ |

物件内部纹理、照片比例、舞台照明可以承担美术职责；量值几何从数据单独计算。这样既保留表现力，也容易复查比例。

## 正文重点与图形证据

正文强调差值，图中就应看得见双方与对应距离；强调占比，部分与总体应可辨；强调变化，应有可比时期与基准。静态图和动态舞台都需要这种对应，可用就近标签、同类颜色或端点标记建立。

相互呼应的关键读数使用相同显示单位、数量级和舍入规则，对象、时期与分母一致。不同指标可各用合适单位；切换单位或精度时交代转换关系，坐标刻度按自身间隔简洁显示。

文字解释结果时，对应画面应已可读；触发见[文字滚动与舞台更新](implementation-stage.md#文字滚动与舞台更新)。强调服务当前重点，沿用已有颜色含义。

### 对照：读数都在，关键证据仍不突出

- **看似完成：** 正文比较两批产品的重量分布，大图却仍是历年平均重量，两批分布挤在角落。读数齐全，集中范围、重叠和尾部仍难辨认。
- **修正方向：** 两批分布用共同尺度成为比较主体；背景趋势按定位需要简化、缩小或退出。若原图已包含所需证据，也可原位聚焦。

## 主图与辅助信息的职责

主图承担当下问题的核心证据，主次可随追问交换；局部展开后可以成为主图，总体退为参照。连续性依靠对象、口径与关系，不要求背景布局始终不动。

辅助图、素材与标注用于定位、身份、细节或情境。是否同时显示，取决于读者是否需要来回比较。暂时去掉一项，若只少了一遍重复结论，就合并；若失去必要定位或背景，保留有用部分。具体空间取舍见[连续比较](expression-methods.md#compare)。

## 核对前后数据的对应

从叙事的承接理由出发，判断前后对象、量值与口径如何关联。关系可以组合；对应依据决定哪些视觉操作成立，不能仅凭图形相似就配对。

| 对应依据 | 能支持什么表达 | 设计时确认什么 |
| --- | --- | --- |
| 同一批可识别对象／观测 | 筛选、提取、重排、跨期属性更新 | 哪些身份不变，哪些观测更新，哪些成员进入／退出或缺失 |
| 有可计算的部分、整体或累积关系 | 展开组成、合并、接入增量 | 单位、范围、分母、覆盖是否一致；部分是否重叠，是否需要剩余项 |
| 没有直接对象对应，但比较问题成立 | 并置结果、转换参照、清楚交接视角 | 哪些口径可比，哪些变化需要说明；不暗示不存在的个体流向 |

“整体到局部”可能是选出已有记录，也可能是把一个汇总量拆成分项；前者保留对象，后者需要组成数据。“跨期变化”可能是同一对象更新，也可能是两批样本的分布对比；只有前者支持直接追踪身份。时序提供先后关系，不自动提供可加总性或因果关系。

据此确定保留的身份或参照，以及改变的量值、布局、尺度与编码；历史取舍见[舞台指导](stage-and-motion.md#让历史仍可比较)。真实观测与呈现插值分清，平滑运动不增加数据中不存在的对应。
