叙事、可视化选择与改编

叙事设计：代表与群体。先用一个女孩认识腰围与尺码，再把她放回同龄分布；保留旧群体、加入成年女性，检验同一尺码范围是否足够。

可视化选择：人物缩小入群后，横向位置承担腰围量值；两组共用尺码背景与轴。橙色只突出当前追问涉及的边界和超出部分，使供给范围与人群位置直接相遇。

改编空间：可换成服务覆盖、预算与价格、设施与使用者等题材，也可用点、区间或密度表达。按追问取人物引入、群体对照或边界比较；无须保留人物素材、左右布局或原有步骤。

数据与素材：两组各取 P10–P90 的百分位位置，不是真实受访者，也不是同一个人长大。NCHS 公布百分位间插值，显示中间 80%；00–16 码范围沿用原作参照，不代表所有品牌。只比较腰围，不判断整件衣服是否合身。人物为自绘矢量。

代码入口：coverageData / sizing-coverage.mjs 配分布和边界；coverageX / coverageLayout 管共同轴与避让；example.states 配正文，example.mount 返回 pose / blend / render。替换数据时同步代表选择、标注与布局；只换素材时保留量值锚点。
