叙事、设计与改编

叙事：先给读者一张可以带走的参照，再问新馆是否开放更久。属于情境引入与新记录比较；一短一长的结果，修正“新馆就会开得更久”的预期。

设计：页头以下用整屏空间并置问题与告示，让 42 小时成为视觉参照。开篇整体自然滚出，告示的量值、馆名与绿色延续到条形，再在共同零点下加入新行；答案等端点读得清再出现。连续的是参照身份，图形不必从纸张变形而来。

改编：可换成旧报价、容量、成绩、使用年限等有依据的参照，素材、图形和叙事方向都可重设。告示只是一种入口；有意义的基准也可以直接写在正文。第一项比较要有相同口径，不把新记录画成原对象的更新。

代码：referenceOpening 筛选三条记录与两态，复用 mountRecords；改 records / stops / axis 及 HTML。自然滚动的引入与后面的持续舞台分开布局，舞台仍使用共享 connectReading。进一步调整几何见 原场景代码。
