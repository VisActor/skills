把参照留在眼前

后来的一尺，
比以前长多少？

把几个时代的一尺放到同一条厘米轴上。新的记录加入，先前的参照仍然看得见。

先留下一条参照

秦的一尺，
约 23.2 厘米。

国博的藏品说明给出这一推算量值。我们先用它作参照，再把后来的记录放进来。

两汉的参考量值

名字没变，
端点略有不同。

白云翔的研究给出西汉约 23 厘米、东汉约 23.4 厘米。与秦的参照相比，差别还很小。

同一时期，也有不同的尺

到了唐，
要分开看大小尺。

地方志列出的两条记录分别约为 24.57 与 29.58 厘米。一个“唐尺”的名字，已经装不下这两种长度。

把用途带进比较

造屋和裁衣，
各有一把尺。

《元尺考》考证的营造尺约 31.5 厘米，裁衣尺约 38.9 厘米。它们属于同一时代，承担不同用途。

回看同一条厘米轴

同样一尺，
相差约 7.4 厘米。

这次差别来自同代的两种用途。此前的记录还在，也能看见这两把尺与旧参照的距离。

问“一尺有多长”，还得一起问：什么时候、在哪里、做什么用？

以上是来源支持的参考量值，不是各朝代所有地区的统一精确尺寸。秦为量器推算；两汉采用同一研究的主张；唐采用地方志综述；元为作者考证值。没有连续逐年观测，纵向只表示阅读顺序。图上厘米按比例绘制，屏幕长度不是实物长度。

来源：中国国家博物馆《青铜方斗》；白云翔《汉代尺度的考古发现及相关问题研究》；台州地区志；熊长云《元尺考》（第 74、76、80 页）。所选数值来自已整理资料，本例未新增文物实测或原件核验。

叙事、可视化选择与改编

叙事设计：新证据加入 → 比较差异。从一个参照出发，后来记录补充比较；同一时期出现并行记录，再追问“同时存在的差别有多大”。新增内容由问题推动，年份只提供一种顺序。

可视化选择：独立非负量值用零基线条长精读；新行加入时保留旧条，让参照可见。遮罩显露的是新记录，条长始终来自该条量值。并行记录放在一起，差值落在原端点间。

改编空间：可换题材、参照、加入理由、排列和素材。范围数据可用区间，连续观测可用轨迹；只需当前比较时可收起无关历史。各记录保持独立，只有可加总的量才接成累计。缩放时所有可比对象与刻度共用当帧尺度。

代码入口：recordExample 配记录、stops / pair；recordPose / recordGeometry 管排列、尺度与遮罩，blendRecords 管衔接。data-record-value / data-pair-gap 与图共用读数；换图形需同步改写几何与标签。
