星灯馆把最长时段推到 98 小时。不过，最长的这一家，能代表所有新馆吗？

叙事、可视化选择与改编

叙事：先留一个参照，再加入新证据。后来者先分列参照两侧，同年记录又拉开差距；最长时段继续增加后，追问它能否代表新馆，最后用最新一对与老参照回答“新是否等于更长”。比较终态直接收束主线。

设计：开放告示引入问题；短正文留在图形上方，滚轮、按钮或方向键共同触发正文交接与图形变化，动画自行完成，读者可停留。句子保持完整，数字随图内标注加强强调。同一组条形共用零点与尺度，旧行先让位，新行再显露，差值落在原端点之间。高亮随追问选择，关系清楚时可以不加。

改编：对象、加入理由、排序、素材和布局都可换。可只取新增、筛选或比较；图形也可按数据改用区间、点或轨迹。保留当前判断所需的参照与口径，独立记录不接成累计；改变尺度时，可比对象与刻度同步变化。

代码：mountRecords(root,{config}) 接入；records / stops / axis / layout 换数据、可见记录和空间。不传 layout 随容器排开；focus / pair 引用可见对象。按钮采用 记录与构成 的样式；本页用 connectReading 接入阅读轨道、箭头与按键；track.ids 取阅读状态，exit.sticky 按实际舞台高度补足末段停留。图文共用 data-record-value / data-pair-gap；recordPose / blendRecords 也可接入其他阅读方式。
