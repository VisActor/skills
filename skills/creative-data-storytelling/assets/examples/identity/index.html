素材跟随数据对象

三件虚构样品共用价格轴。图片帮助识别杯子，点的位置表达价格；比较两件样品时，图片、名称与价格点一起移动。

表达理由与改编

表达理由：素材识别对象：图片、名称与量值标记共用锚点，变化中仍可认出同一对象。本例点的位置表示价格，图片大小服务识别。

改编与接线：照片、图标或文字都可承担身份；选择跟随哪些对象由追问决定。mountIdentity(root, config) 接记录、selected 与视域，配置形状见 identityExample；图片 ID 对应记录。图像层与几何层共用无内边距的比例容器，锚点偏移在 identityPose 调整，普通配图可静态安排。
