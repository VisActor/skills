同一批记录，改变观察问题

项目数量多的类别，服务时长也一定多吗？让同一批模拟记录改变排列与面积，比较两种观察结果。书页轮廓只承担主题识别。

表达理由与改编

表达理由：主题形象、分布与数量转权重各有用途：轮廓引入主题，等大点看记录数，面积看贡献。保留记录身份以跟住对象，散开动作本身不表示数据变化。

数量怎样转成贡献：本例先按类别排等大项目，再保持中心，将面积改为服务时长，看到少数长时项目改变各组的轻重。按最大圆预留间距，减少无关移动，代价是等大点阶段更松；只需精读组间总量时可改成长度，也可将同批项目排成贡献带。

改编与接线：需要有稳定 ID 的逐条记录；汇总量另定义固定量单元。unitExample 配数据、类别、域与面积系数，slots 改轮廓，unitPose / blendUnits / renderUnits 管布局和衔接。可换形状、素材、分组及顺序，按问题取用状态，修改权重编码时同步几何和单位。
