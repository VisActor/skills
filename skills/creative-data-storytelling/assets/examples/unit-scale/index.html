分钟与秒

一分钟，
有 60 秒。

每格一秒，合起来仍是刚才那一分钟。

分钟与小时

60 个一分钟，
是一小时。

刚才细分一分钟，时长没变。现在接上一份份一分钟，等待才变长。

设计解释与改编入口

叙事设计：从基本关系引入：先认识一份，再看内部和倍数，最后借已建立的参照比较记录。等待只是题材；当前问题已无需解释单位时，可直接从比较开始。

可视化选择：拆分、重复与缩放各解释一种关系：等分保留总量；倍数增长先扩展视域，再保留原份、接入其余份，使读者分清“同一份在画面中变短”和“数量增加”。反向先收回新增份数，再靠近原份。进入比较时，时间带收拢为分钟参照，独立记录另行显露；两者始终共用当前尺度，记录不冒充参照拆出的部分。

改编空间：可换长度、质量、容量或其他有明确换算依据的量，重选素材、方向与布局；圆形、点阵等需另算几何。按追问借用其中一个操作或整段。两次等候不能代表群体；接入真实记录后，才可继续追问这种差异是否普遍。非等分组成用真实分项，不强套等份。

代码入口：unitScaleExample 配量值；只讲单位时省略 records 和 HTML 中的 compare 阅读段，将 data-reading-end 放到实际末段。保留比较时传两条记录。layout 可覆盖画布宽高、left/right、baseline/axisY、comparisonTop/comparisonRowGap；默认值见代码，字体与配色仍由 CSS 控制。此绘制支持 2–120 等分及重复份。滚动接入见 connectReading 用法。

unitScalePose 定终态，blendUnitScale 分开尺度与份数进度，unitScaleGeometry 与绘制共用当帧尺度；图文读数共用 unitScaleReading。超出水平等份与两项比较的构图时，改写这条链路。
