叙事、可视化选择与改编

叙事设计：构成比较。先认识几首歌，再提取同类、放回完整分母比较时期。其余记录中继续显出新类别，修正对“其他”的理解；最后在相同分类口径下回看过去与现在。

可视化选择：记录保留身份、时间位置与类别色；提取让类别可辨，重新汇合恢复分母。圆面积先表示前十周数，进入构成后改由色带纵向厚度表示各期份额，点只辅助身份交接。两种分类范围都比较同一对时期。

改编空间：可换消费明细、新闻主题、研究文献或使用记录，选择会改变判断的分类。类别已清楚时可省去记录引入；可用条形构成、单元或其他布局，按追问取用提取、汇合或扩展分类，不照搬八步。

数据与素材：按上榜日期分期，以前十总周数加权，不是逐年榜单席位复原；曲线连接时期汇总，不是年度观测。分类含编辑判断。数据文件直接导入，来源与 MIT 许可随附；未复制音频、品牌或原作页面代码。

代码入口：songs / categories / periods 定义记录、分类与分母；buildLayouts 管记录排列，areaBoundary 管构成边界；example.states 与 mount 内 blend / render 组织提取和汇合。改主题时一起更新代表记录、分类、时期及比较标注。
