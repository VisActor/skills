叙事、可视化选择与改编

叙事设计：多个条件与功能后果。比较两个口袋的尺寸，让同一件物品进入轮廓，再把代表样本放回两组，观察功能差异是否普遍。收尾比较各组比例；换物品只回答适配结果如何变化。

可视化选择：物品与容器共用厘米尺度，露出的部分直接解释使用后果。正文强调深度差或露出量，与当幕标注同色。代表样本先带着物品缩到各组位置，其他样本随后显出，返回时顺序相反。几何与身份保留；图文共用各组计数与分母。

改编空间：可换成电脑与包、车辆与车位、物品与柜格；也可只取试放或样本比较。重新设计轮廓、排列、方向与探索对象，按用途补足真实约束；不必沿用两个样本、两组或口袋阵列。

数据与素材：演示只判断同一个凸五边形内的二维竖直容纳，不模拟布料、厚度或旋转。手机 8×16 cm，钱包 9.5×8.5 cm；素材为自绘矢量。

代码入口：example.mount(svg, {rows}) 换样本，objects 换物品；itemTop / fits 共用轮廓，fitSummary 供正文和分组读数使用。render 的 collection 前段移动代表，后段显出其他样本；更换组数或扩大数量时另调排列。滚动接入见 connectReading 用法。
