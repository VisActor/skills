叙事、可视化选择与改编

叙事与设计：同批对象的两期变化。先建立类别位置，再让同一批人按第二次回答跨组重排；停在新分布，保留原人数与差额。读者既看见总体改变，也能点选一个对象回看对应。前文已有分组时可直接接入。

条件：需要稳定 ID、同定义的前后分类；只有两期总数不能推造个人流向。默认 120 条配对记录全部模拟，不解释现实收入与满意度的因果，也未观察到中间过程。有新增、退出或缺测时应另行处理总体。

视觉选择：类别位置与等大人形计数保持；颜色表示初次收入档位，跨期不变，也不表示变好或变差。终态描边对应换了回答的人数，点选可单独追踪；若只需比较总体，不必保留这层强调。只追问某来源去了哪里时，可改用 cohort-flow。

改编与代码：data.mjs 换分类、属性和配对记录；createCategoricalChange / layout / blend 保留身份并连接前后分布。可换单元形象、分类数、方向、布局与路径；第二属性无用时可单色。geometry 与 width/height 决定绘图区，更多类别需另排空间。mountCategorical 负责 SVG 与读数，句子按新数据重写。

预览沿用 固定正文接法与共享 connectReading / createCopyHandoff。预览装配可替换，构图与几何可接到自己的正文。
