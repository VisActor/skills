同一句话，谁在叮嘱谁？

“到了给我打个电话。”

一句平常的话，出现在三个不同的场景里。文字没有变，说话的人和当时的处境却变了。

第 2 场 / 第一次远行

出发前，
母亲多说了一句。

女儿第一次去外地生活。母亲把她送到车站，临别时叮嘱她，到了打个电话。

第 5 场 / 再次出发

后来，
又是这句叮嘱。

女儿已经熟悉独自生活。假期后再次离家，母亲还是说同一句话。重复让这份牵挂变得可辨。

第 8 场 / 送母亲远行

这一次，
换女儿来说。

母亲准备独自去旅行。女儿送她出发，也叮嘱她：到了打个电话。说话的人与听话的人互换了。

放回整段故事

同一句话，
换了叮嘱的人。

只数出现次数，会得到三次。把场次、人物与处境放在一起，才能看见这句叮嘱怎样从母亲传到女儿。

弧线连接的是经过标注的呼应；每个出现位置仍属于自己的场景。

剧情、对白与场次均为本示例自写虚构材料。场次间距只表示顺序，不表示经过了多少时间。表达启发来自 The Pudding：Common Threads 对重复旋律及其情境的组织；此处没有使用原作剧情、歌词、音频或代码。

叙事、可视化选择与改编

叙事设计：序列位置 → 前后呼应。虚构对白中，母亲先叮嘱女儿“到了给我打个电话”，后来女儿对母亲说出同一句话。若只问谁说过，按人物分组即可；这里按场次回看各次送行，才能读出角色与处境的改变。

可视化选择：标记留在原场次，片段就位后再绘弧线，让读者找到呼应的两端并回看语境。场次表达先后，弧线表达有依据的关系；它们不自动表示等时距、流动或因果。

改编空间：可换为原始报道与回应、作品意象或事件片段，重选序列和关系。需有可定位出处与核对依据，同词未必同义。两段已能讲清时可并置；多主题可分行或用矩阵，构图与运动随关系密度调整。

代码入口：recurrenceExample 配 scenes / occurrences / links / stops，links.basis 记录依据；recurrenceGeometry / blendRecurrence 管显露与连接。引用、卡片和正文一起改写；保留出处可接原文详情。
