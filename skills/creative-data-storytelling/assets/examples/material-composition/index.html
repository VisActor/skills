统计包含可食用与不可食用部分，不包含生产及供应链上游损失。占比采用报告公布的四舍五入值；它们比较的是三个环节在总量中的份额，不是各环节自身的浪费率。

叙事、可视化选择与改编

叙事设计：熟悉场景引入 → 组成与份额比较。先认出废弃物来自哪些生活场景，再看它们怎样构成总量，最后判断家庭是否超过半数。

可视化选择：图片保持类别身份，色带长度承担占比；同一组对象从场景进入首尾相接的组成带。半数线直接检验当前发现，图片的大小和食物数量不表示统计量。

改编空间：适用于同分母、互不重复且覆盖总体的分项。情境、图片、构图和参照可重选；前文已认识类别时可直接进入组成。也可用分段物件或固定量单元表达，保留正确份额；各类别自身的比率需分别比较。

代码入口：mountMaterialStory(root, { data }) 换分项、图片和 focusId；各行可给 color。只用 places / shares 可省略重点及相应正文绑定；majority 仍要求重点份额超过半数。shareScale / materialPose / blendMaterialPose 管几何与交接，data-focus-share / data-other-share 绑定重点及余量。
