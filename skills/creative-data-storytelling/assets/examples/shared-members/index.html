叙事、可视化选择与改编

叙事与设计：共同部分来自哪里。先建立报名来源，再原位辨认两项都参加的名额；提取后继续追问：报名最多的来源，共同参与人数也最多吗？颜色和报名总数留下参照，新增发现是两种排序不同。原位已回答当前问题时，也可在此结束。

数据条件：需要互斥来源分组及已知联合成员关系。本例是虚构活动的联合计数，每点展开一个名额，没有可查的个人身份。逐条记录可直接用真实 ID；仅有两项各自人数时，应看 overlap-bound，不能猜测哪些人同时参加。

视觉与取舍：等大点计数，圆簇只是紧凑排列，不是集合相交面积。原位高亮回答“哪些名额”，聚拢后保留颜色回答“来自哪里”。共同部分的来源数量不等于各来源的参与率，后者需分别保留分母。可改为网格、行列、素材或来源分面，路径也可换。

改编与代码：membershipExample / createMembership 配 origins、conditions 和互斥 patterns，派生交集、余量及报名和共同参与的最多来源（保留并列）；layout / blendMembership 保留全部名额，clusterSlots 可替换。当前布局支持两到三个来源，pitch / radius 调间距；大量对象需重新分区。mountMembership 绑定 SVG 与正文，提取后的追问随实际发现改写。

预览沿用 固定正文接法与共享 connectReading / createCopyHandoff。预览装配可替换，构图与几何可接到自己的正文。
