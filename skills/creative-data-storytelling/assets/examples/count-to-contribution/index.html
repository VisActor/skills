书名、题材与阅读次数均为模拟数据。每次阅读是一条阅读事件，不等于一个读者，也不能据此判断作品质量或受欢迎的原因。面积只计封面矩形，不计群落之间的空隙。

叙事、可视化选择与改编

叙事：数量多，贡献也多吗？等大封面先让数量可数，阅读量再改变原来的判断；接着追问优势是否集中于个别对象。另一结尾比较数量与阅读的份额，两种追问择一即可，不是固定的后续章节。

设计：封面既识别书籍，也在重排后保留个体。贡献画面按实际矩形面积编码，宽高按面积平方根变化，两类共用标定；按题材着色，提取头部后仍保留来源。面积群落让集中程度明显，附近读数负责精确核对。若只需比较接近的比例，可换成共同基线长度，不必保留封面。

改编：适合同一范围、带稳定身份和非负贡献量的小集合。可换项目、产品等对象，重选素材、构图与步骤；只需要数量与权重转换时，取前两态或基础 units。缩放表示度量方式改变，不表示对象随时间变大。零贡献在数量视图保留、贡献面积为零；不可把未知值记作零。

代码：mountContribution(root,{config,ending}) 接入；contributionExample 配两类对象与阅读量，createContribution 派生合计、头部和份额，data-value 绑定图文读数。packBooks / layout / blend 分别负责小集合矩形排布、状态与面积插值；layout 配画布、组中心与群落空间。更多对象、长标签或不规则素材需另排几何；不要把各组分别撑满到同样大小。

ending 可选 concentration 或 shares。后者上排是同批书目的数量参照副本，两行总面积相等、各为 100%，不是新增书目。换数据后按新结果改写正文，反转与“一本等于其余”都不是前提。正文、滚动与退出使用 connectReading、createCopyHandoff；本例代码。
