叙事、可视化选择与改编

叙事与设计：只有边际人数，至少重合多少。两条先共用总体与零点比较数量，再保持长度、将第二条移向总体另一端。即使尽量错开仍留下的重合，解释为什么交集有下限；这不是时间推进或人员流动。

数据条件：虚构意向调查，同一批 120 人中两项人数为 84 和 72；各项内部不重复。只用共同总体与边际计数，下界 max(0, A + B − N)，上界 min(A, B)。只有总数不能断言实际交集恰好是下界。若下界为零，只说明可能错开；已知成员对应则用 shared-members。

改编空间：可以用于功能使用、回答重合或活动参与；需要同一范围的总体，两项允许重叠。可换方向、图符、长度条或已有单元集合；保留总体边界、两项数量与“尽量分开”这一解释。主题与布局可改，不必先铺满粒子。

代码：overlapExample / createOverlap 集中输入与上下界，arrangement 给出假设排布；createOverlapScene 的 layout / blend / geometry 连续移动，mountOverlap 用同一模型绑定图文。可直接取上下界计算或错开过程，正文应随零下界、相等组或其他数据重新组织。

预览沿用 固定正文接法与共享 connectReading / createCopyHandoff。预览装配可替换，构图与几何可接到自己的正文。
