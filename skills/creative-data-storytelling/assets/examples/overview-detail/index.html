叙事、可视化选择与改编

叙事设计：全局 → 局部比较。从总体中挑出一对值得追问的记录，先让读者认出它们，再回答“相差多少”。选择理由来自正文与数据；可直接承接已有全景。

可视化选择：先原位突出，再让同一对条形及名称移入比较位置，交代局部来自哪里。条长精读用时，轴与端点读数按同一尺度缩放；差值标注在比较到位后出现，避免对象尚在移动、解释已指向终点。其他记录退出，把空间留给当前问题。

改编空间：对象需有稳定身份、可比口径和选取理由。原位已能读清时，高亮足够；需要定位时保留适量总体参照。点、线、区间或单元都可承担提取，重新安排尺度、素材与空间即可延续这段思路。

代码入口：mountDetailStory(root, { rows, selected, layout }) 换记录、选中项与空间；layout 可调标签区、行距、比较位置及画布尺寸，detailStoryPose / blendDetailStory 让轴、条形和标注同步。沿用这对记录继续解释或返回全景；正文与选择理由另行改写。滚动接入见 connectReading 用法。
