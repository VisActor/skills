# 时间趋势

用于有真实时间字段、需要判断变化的问题。先按[分析设计](insight.md)明确比较基准、变化量与后续定位，再选择时间粒度、图形和空间；主区参考[经营概览](../templates/template-business-overview.html)或[预期寿命](../templates/template-life-expectancy.html)。

## 时间与比较

- 区分事件日期、快照日期和随访时长；只有真实时间字段才用于日历趋势。比较时保证覆盖、单位、粒度与业务条件一致，首尾不完整周期需说明。
- 明确当前值代表区间汇总、末期状态还是选中时间点。只有可比基期存在时才计算变化，同步读数、基准、图形和结论。
- 时间排序与补齐遵循数据含义。只有业务确认“无记录即为零”时才补零，未知或未同步的数据保留缺失状态。

## 图形与阅读

折线或面积图可展示变化；需要解释波动时，结合适用的分组贡献、分布或结构比较，避免只报告最高点。参考路径见[按问题组织证据](insight.md#按问题组织证据)。

继承所选模板的轮廓、填充与交互。面积保留有效零基线和真实负值；平滑不能制造虚假峰谷，Tooltip 对应真实采样点。坐标与标签按比较任务保留，完整日期和值可交互查看，不重复绘制两套日期标注。视觉见[绘图表面](design.md#图表配色与页面同步)。

## 接入与交互

复用 `buildChartSpec()` / `draw()` 或 `buildSpec()` / `drawPlot()`，保持查询结果、字段 ID、系列含义和图表实例。新图形按 [VSeed](api/vseed/guide.md)配置，固定版本兼容见[模板接入](template-integration.md#固定版本与场景回归)。

临时时间查看从当前查询索引读取，按声明的作用域更新读数和范围说明；退出恢复汇总，不覆盖全局发现。主图与小图的联动、键盘操作及清理见[指标联动](metric-card.md#与图表联动)，确认时间选择与明细核对见[指标深入分析](metric-analysis/guide.md)。

布局变化后同步图表尺寸；空范围保留真实空状态。刷新、更新过渡与释放沿用模板和[共享刷新流程](visual-query/references/composition.md#刷新订阅与生命周期)，检查项见[验收标准](acceptance.md)。
