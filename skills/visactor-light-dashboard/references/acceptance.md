# 验收标准

按本次任务的影响范围检查；新页面覆盖完整分析与体验，局部修改核对受影响部分。自动检查用于验证具体约束，视觉与交互仍需实际对照。

## 分析与证据

- 使用者与主要问题清楚，图表、指标和发现支持同一判断；各模块或后续探索能提供新的比较、定位、解释或核对依据。
- 比较有可见基准且口径一致；最高、最低、变化或相关性有其业务含义，不直接当作异常、改善或原因。
- 结论能定位到真实查询结果；影响规模、比率、样本量和重要反例按当前问题纳入判断。稀疏或不稳定结果的限制可见。
- 观察事实、可能解释和待验证假设可区分。提供行动或情景估算时，其依据、假设与验证方式清楚；数据不足时说明需要补充什么证据。

## 数据与口径

核对默认范围与一个有效筛选范围的关键读数、图形和发现，按适用情况覆盖去重、比率分母、百分点、负值、缺失、空结果和不可比基期。明细粒度与指标关系明确，完整查询结果可访问，Top N 不截断总体计算。

保存恢复承诺涉及的条件、布局与资源应可重建；若包含公式重算，验证公式和依赖而非仅保存结论文本。具体规则见[分析设计](insight.md)与[指标深入分析](metric-analysis/guide.md)。

## 页面布局与视觉对照

模板与产物在相同视口、缩放和动效结束状态下检查首屏与完整页面。独立页面检查桌面及 390px 窄屏，嵌入页面以实际容器为准：

- 主次和阅读顺序清楚，数字、标题、图形与必要口径完整，长内容自然增长；不以缩字、裁切或大片无意义留白维持布局。
- 实际 computed style 的同角色排印一致。Canvas 融入阅读面，标签清楚，无意外白底、描边或重复标注；颜色、玻璃叠层和降级后的对比足够。
- 控件、浮层和独立触控命中区可用，页面无横向溢出；宽表在自身容器内滚动。

## 功能交互

- 筛选同步更新其声明范围内的指标、图形、明细与发现；“全部”只解除对应条件。临时 hover 按作用域更新并恢复，标题、单位和范围一致，不额外发起查询。
- 分析入口继承已确认条件，选择、清除、换维度和返回均可核对范围；图形与明细一致，继续探索增加证据，关闭恢复入口焦点与主页位置。
- 加载反馈仅跟随当前触发控件，保留已有内容和布局；快速连续选择只提交最新结果。失败、重试和空结果可辨认，关闭后无旧请求回写或遗留转圈。
- 图表与表格实例原位更新，读数从当前值接续，文本和内容不反复闪烁或重播入场；用户折叠状态与必要表格状态保留。
- 弹窗在内容就绪后揭示；覆盖动画中关闭、重开和延迟加载。菜单键盘选择、Escape 层级、外部关闭、触屏及可见焦点正常。
- 减少动态效果时可结束播放中的动画并直接呈现最终值；减少透明或不支持模糊时仍可读。退出释放订阅、查询、图表、表格、计时器与观察器。

完整交互规则见[筛选器](filter.md)与[指标深入分析](metric-analysis/guide.md)。交付简述实际验证范围和未验证项，运行日志与验收材料放在业务页面之外。
