# 布局与阅读路径

根据分析问题组织阅读顺序，再选择模块大小与响应式排列。模板与截图见[模板列表](templates.md)和[可视总览](../templates/index.html)，维护入口见[模板接入](template-integration.md)。具体尺寸和动效参数以所选 HTML 为准。

## 信息密度与模块取舍

首屏让使用者识别主要问题、结果和当前范围。每个模块应增加比较、定位、解释或核对依据；相关指标可合并到一个分析单元，重复的数字和图形可精简。模块数量与展开方式由任务决定。

需要比较绝对值、类别或分布时保留足够的图形空间与标签。低频说明按需展开，明细沿用模板默认展开及折叠状态；长分析可分段延续阅读。内容自然撑高，不用缩小文字、压扁图形或固定高度裁切来强塞一屏。

## 按分析任务选择布局

| 阅读任务                   | 组织方式                               | 实现参考                                               |
| -------------------------- | -------------------------------------- | ------------------------------------------------------ |
| 一个主要变化带动辅助判断   | 主要发现 → 主趋势及相关指标 → 证据。   | [预期寿命](../templates/template-life-expectancy.html) |
| 先判断整体状态，再定位差异 | 关键指标 → 主要比较或分布 → 明细。     | [心衰记录](../templates/template-heart-failure.html)   |
| 多个问题需要连续解释       | 按问题分段，每段包含结果、比较与依据。 | [餐食与运动](../templates/template-meal-workout.html)  |

这些是阅读路径参考，可以按业务组合；窄屏保持分析顺序，不按比例缩小桌面的并列布局。

## 排版与尺寸 token

继承所选模板的字号、间距和卡片几何，按内容与宿主整组调整：

| 对象         | 维护原则                                                                                |
| ------------ | --------------------------------------------------------------------------------------- |
| 外壳与网格   | `.shell` 控制可用宽度，`.dashboard` 承载 DSL 布局；区分外宽、内边距和实际内容宽度。     |
| 数字与单位   | 使用[同角色字号 token](metric-card.md#数值字号规范)，长数值调整单位和空间，不逐卡缩字。 |
| 标题与说明   | 维持清楚层级；必要口径可读，长文本自然换行。                                            |
| 图形与阅读面 | 图表有可测量尺寸，Canvas 与卡片底面衔接，见[绘图表面](design.md#图表配色与页面同步)。   |

## 用 Dashboard DSL 保存布局

可恢复的模块位置和资源引用由 Dashboard DSL 管理，通过 Builder 修改；UI 将当前断点布局映射到 CSS Grid。使用所选模板的 `setLayouts()` 与 `layoutDashboard()`，不在 CSS 中另维护一套模块坐标。API 见 [Dashboard Builder](api/vbi/guide.md)。

布局断点以容器实际可用宽度为依据。重排时同步 DOM 阅读顺序，保留焦点、widget ID、资源及分析条件；统一测量图表尺寸，仅在变化时 resize。状态与资源恢复见[组合指南](visual-query/references/composition.md)。

## 按模块关系联动与轻微倾斜

联动作用域按分析关系声明，调整卡片位置不改变作用域。指标显示与恢复见[图表联动](metric-card.md#与图表联动)。

小卡沿用模板 `bindCardTilt()`：固定外层 `.card-slot` 命中区，变换内层卡片，合成倾斜不超过 2°；主图与发现区保持平面。触屏、减少动态效果、离开和滚动等复位行为直接复用现有实现。

## 全页缓动入场

复用 `dashboard-motion-runtime` 的 `entranceTiming` 与 `revealComponents()`；时长、位移和缓动在源码中维护。静态加载态保留可测量布局，数据、读数、图表和明细就绪后统一揭示。筛选、hover 和响应式重排不重播入场；减少动态效果时直接显示最终状态。

加载、刷新与清理入口见[模板维护](template-integration.md#修改模板时同步维护)。

## 弹窗与内容同步入场

打开容器与内容就绪分开处理：加载期间保留可测量尺寸，关闭和失败恢复始终可用；内容就绪后再同步揭示。一次打开内的筛选与滚动不重播入场。关闭从当前姿态退场，旧查询失效后再释放 Canvas，并恢复入口焦点。

复用 `metric-analysis-runtime` 与 `metric-analysis-style`，参数以 HTML 为准。局部选择、返回与生命周期沿用[指标深入分析](metric-analysis/guide.md)；材质降级见[玻璃阅读面](design.md#玻璃阅读面)，验收见[验收标准](acceptance.md)。
