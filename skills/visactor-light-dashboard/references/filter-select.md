# Select 接入

用于平铺选项放不下或需要分组数值的单选菜单；选型与统一外观见[筛选器](filter.md)。复用宿主组件或模板分析弹窗的 `.ma-picker`、`renderGroupPicker()` 与选择处理，不另复制一套 CSS 和事件实现。

## 结构与状态

模板采用 `details + summary + button`，保留原生展开与按钮键盘语义。选项按钮用 `aria-pressed` 表达当前选择，真实值与显示标签分别映射；动态文本通过 `textContent` 写入。同页实例使用唯一关联 ID。

沿用当前结构的可访问语义；需要搜索、多选或大型列表时，使用具备相应键盘模型的组件，不只添加 `listbox` / `combobox` 角色名。

展示层负责展开、焦点和选择意图，数据条件交给宿主 Builder 与刷新流程。图表点选、清除和状态恢复都同步同一选择；选项来自完整有效范围，Top N 仅限制图形展示。

## 选择与关闭

- 点击、Enter 或 Space 确认选项；hover 和移动焦点不提交查询。单选确认后收起并归还触发器焦点。
- Escape 优先关闭当前菜单，不同时关闭分析弹窗。外部点击或焦点离开时收起，不抢回外部目标焦点；同一作用域一次打开一个菜单。
- 允许触发器展示当前值；若工具栏已有选择与清除标签，可保留简短的“选择维度”，同时更新无障碍描述与选中态。
- 失效选择、空列表、忙碌和失败反馈沿用[筛选状态](filter.md#select-实现与状态)。菜单选中后由可见触发器承接 loading。

## 边界与生命周期

浮层位于当前对话框的交互层内，不挤动图表和明细，宽高限制在可用视口；长列表内部滚动，必要时向上展开。改变窗口、滚动或重新打开后重新检查位置，触屏保持整行命中和可见焦点。

关闭菜单不清除已确认条件；关闭分析或销毁组件时释放对应监听与观察器。接入入口见[模板维护](template-integration.md#修改模板时同步维护)，验收见[功能交互](acceptance.md#功能交互)。
