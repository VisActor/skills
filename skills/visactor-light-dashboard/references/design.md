# 配色与材质

修改视觉时继承所选模板的 CSS token 与绘图配置，结合用户要求和宿主规范调整。具体数值以 HTML 为准，布局见[阅读路径](layout.md)，实现入口见[模板接入](template-integration.md)。

## 相近风格中的差异设计

布局由分析关系决定，主题与背景按内容、品牌及用户偏好选择。保持清楚的主辅层级和稳定阅读面；一组页面可有不同构图与色系，不把行业名称绑定到固定皮肤。现有页面的风格优先于示例色板。

## 玻璃阅读面

`dashboard-material` 维护页面、明细和弹窗的材质 token。继承其阅读面层次：指标卡清楚、底部明细更透明，弹窗隔开背后内容；嵌套图表与表格使用轻薄底面，不重复模糊。控件轨道与选中面见[筛选器](filter.md#视觉标准)。

装饰应弱于内容。避免多层高彩度渐变、强光晕和反复透明叠色；模糊不能替代稳定底色和足够对比。背景装饰不拦截指针，文字与 Canvas 不随背景一起模糊。不支持模糊或用户减少透明效果时使用 `--glass-fallback`。

## 统一颜色变量

CSS 是页面主题的输入；`--accent`、`--accent-ink`、`--chart-track` 与背景 token 分别供图形、文字、轨道和阅读面消费。图表与 VTable 读取同一输入，避免在业务配置和绘图代码中重复维护色号。

Canvas 颜色经适配器解析成渲染器支持的值，不能直接传入未解析的 `var()` 或 `color-mix()`。表格使用[统一 token 与适配器](visual-query/references/table-theme.md)，字体沿用 `--dashboard-font-family` / `--font-ui`。

## 图表配色与页面同步

在已有查询 seed 上补充视觉配置，再通过 VSeed 构建 Spec；保持字段 ID、数据含义和实例绑定。新图形复用同一绘图表面：

- Canvas 透明或与阅读面同色，字体与页面一致；检查最终 Spec 和画面，避免意外白底、标签描边或阴影。
- 轴、网格、图例和标签按阅读需要取舍。类别比较保留类别含义与零基线；需要比较绝对值或分布时保留相应刻度，不套用 mini 图的隐藏规则。
- 轮廓与填充分别控制强度，主题色保留对数据语义的表达。柱尾标签完整，必要时调整空间；落入柱体时保持对比，不添加装饰性描边。
- 检查玻璃与背景合成后的对比：普通文字至少 4.5:1，有效图形和细线至少 3:1；背景最深处及弹窗覆盖处也要可读。

API 见 [VSeed](api/vseed/guide.md)；固定版本兼容项见[模板回归](template-integration.md#固定版本与场景回归)。

## 按需提供主题切换

模板没有内置配色选择器。用户需要切换时，更新 CSS token 后重新读取 Canvas 颜色，复用缓存结果和渲染实例，保留当前数据范围与表格状态。可保存的主题配置通过所属 DSL / Builder 管理，具体背景和绘制留在 UI。验收见[页面布局与视觉对照](acceptance.md#页面布局与视觉对照)。
