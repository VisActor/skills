# 指标卡

指标卡把读数与支持判断的证据组成一个分析单元。先明确[分析问题](insight.md)，再决定是否需要小图、比较或进一步分析；主趋势见[趋势图](trend.md)。

## 指标与图形的语义

每张卡明确主指标、聚合口径、图形编码及交互范围。标题、数字和图形共同回答一个问题；均值与分布可以组合，但图形代表的类别、时间或区间需可识别。

按任务选择结果指标、解释指标与比较基准，区分业务结果和数据覆盖等代理指标。最高、最低或某字段的出现比例是否值得关注，要结合分母和业务含义，见[分析设计](insight.md)。

## 数值字号规范

继承模板的主指标、辅助指标、卡内衍生指标及单位 token，同一角色在同一断点统一字号、字重和行高。角色由分析优先级决定，不因卡片宽度、数字位数或筛选状态逐卡缩字。

数字使用等宽数字特性；单位与数字分级，长读数通过展示单位或空间调整保持完整。行业模板的 `metricUnit` 保留独立数值与单位节点，业务格式统一读取 `formats`；具体尺寸和节点实现见所选 HTML。

## 文本与迷你图配合

- mini 图适合辅助识别已有说明的走势或结构。需要比较类别、精确值或分布时保留相应标签和坐标，或扩大图形。
- 没有有意义的辅助图时保留清楚的读数与依据。多张卡之间应有分析关系，避免同一结果换图重复。
- hover 改变范围时同步范围提示；改变指标时同步标题、单位与读数，或仅在 Tooltip 展示该值。

## 主动分析入口

有后续问题的指标提供可辨认且键盘可达的入口，按[指标深入分析](metric-analysis/guide.md)设计默认问题、明细与返回。详情继承已确认条件，临时 hover 不隐式成为打开条件；只有口径说明时如实标注。

## 图表构建与更新

复用模板的 `buildChartSpec()` / `buildSpec()` 与 `draw()` / `drawPlot()`，在已有 seed 上配置图形，保持字段 ID 和系列含义稳定。视觉与版本处理见[绘图表面](design.md#图表配色与页面同步)及[模板接入](template-integration.md)。新增类型按 [VSeed API](api/vseed/guide.md)配置，不用文档中的另一套 Spec 覆盖成熟绘图流程。

## 指标文本更新动画

使用 `DashboardMotion` 提供的 `animateMetric()` / `animateReading()`。首次显示真实值，连续更新从当前读数接续；页面与弹窗复用同一调度和格式器，结果未变时不重复写 DOM。单位与入口节点保持稳定。

动画只影响呈现，计算、Tooltip、Insight 和导出使用真实查询结果。无定义值按口径显示；减少动态效果时结束过渡并落到最终值。关闭弹窗取消其读数，页面退出释放帧和缓存；维护入口见[模板运行时](template-integration.md#修改模板时同步维护)。

## 与图表联动

主图只更新声明的关联指标，小图只更新所属卡片，移出或取消查看后恢复相同范围的汇总、标题和说明。使用本次查询建立的缓存索引，同一维度去重更新，hover 不重新查询或覆盖全局发现。

经营概览使用 `bindMetricHover()`，专题与行业模板使用 `bindPlotInteraction()`。沿用各自的键盘、触屏等价入口和订阅清理；新结果应用前取消旧 hover 任务，避免旧值回写。跨视图同步按[组合与联动](visual-query/references/composition.md)，验收见[验收标准](acceptance.md)。
