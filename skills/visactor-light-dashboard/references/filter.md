# 筛选器

本篇负责控件选型、呈现与筛选作用域。查询条件与刷新规则见[组合与联动](visual-query/references/composition.md)，源码入口见[模板接入](template-integration.md)。

## 选型与用户动线

| 控件        | 适用情形                           | 动线                                                   |
| ----------- | ---------------------------------- | ------------------------------------------------------ |
| 胶囊平铺    | 少量、高频、短标签的互斥选项。     | 直接选择，当前范围清楚，通过“全部”解除本组条件。       |
| 定制 Select | 选项多、标签长或需要显示分组数值。 | 打开列表，选择整行，收起并显示选择；提供清除或“全部”。 |

按标签与可用空间选择，窄屏允许换行，不通过缩小文字和命中区硬挤。多选使用明确的多选语义；复杂搜索或大列表优先复用宿主的可访问组件。

## 视觉标准

继承 HTML 内 `dashboard-controls-style`，主页和分析弹窗复用[仓库履约观察](../templates/template-logistics-fulfillment.html)的胶囊、菜单及按钮样式；具体圆角、间距和过渡参数以源码为准。桌面筛选集中于标题右侧，当前选项、hover 和焦点可区分，窄屏与触屏保留完整标签及独立命中区。

仅让触发当前请求的控件在文字右侧显示 loading，平时不占位，出现与收起时平滑伸缩；连续选择跟随最新控件。菜单选择后将反馈留在可见触发器上，完成、失败和关闭均能清理。弹窗更新不重复显示“正在更新”文字。

## Select 实现与状态

结构、键盘与焦点规则见 [Select 接入](filter-select.md)。平铺与 Select 读取同一已确认条件；标签由真实值映射，选项数值来自完整查询范围，hover 不提交。动态选项失效时清理选择并同步查询，不能保留已不存在的值。

## 轻量筛选的作用范围

- 全局筛选同步相关汇总、图形、比较基准、明细和 Insight；本期与基期的业务条件一致，时间条件分别应用各自周期。
- 卡内筛选只修改其拥有的条件和查询；“全部”解除本组条件，保留其他条件及指标固有条件。
- 临时 hover 的作用域和恢复见[指标联动](metric-card.md#与图表联动)，分析选择与返回见[指标深入分析](metric-analysis/guide.md)。

可恢复条件通过 Builder 管理，UI 映射选择意图。`whereFilter` / `havingFilter`、条件 ID、事务和恢复遵循[筛选规则](visual-query/references/composition.md#筛选规则先于事件回调)。

## 联动更新与双重动画

复用页面的 `applyFilters()`、`requestRender()` 与刷新队列。加载保留原内容与尺寸，旧请求不能覆盖最新选择或提前清除 loading；失败保留原条件重试入口，不能把旧内容标成新结果。就绪后同步提交数字、图表、明细和发现，保留用户折叠状态。

图表复用实例并启用 update 过渡，读数使用[指标动画](metric-card.md#指标文本更新动画)，筛选不重播首次入场。加载时仍可继续选择，减少动态效果时直接落位。状态及生命周期按[共享刷新流程](visual-query/references/composition.md#刷新订阅与生命周期)，检查项集中在[验收标准](acceptance.md)。
