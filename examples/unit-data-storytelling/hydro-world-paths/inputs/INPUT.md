# Hydro 自由生存服的数据

Hydro 是玩家共用同一世界的《我的世界》生存服务器。这份资料选取游玩时长和已发现生物群系数均有正值记录的 **1,117 个账号**，在服务端一次快照中把进度档案与行为榜按账号对齐后汇总。快照时间为 2026 年 11 月 3 日 14:19（北京时间）。数据来自 [Hydro Vanilla SMP](https://hydrosmp.com/) 和[公开统计 API](https://api.hydrosmp.com/)。

**看做事的顺序**，先读 `milestones.csv` 和 `paths.csv`。

- `milestones.csv` 列出选取的 12 项进度。每项都有简短键名、原版进度 ID、中文释义和在这 1,117 个账号中有记录、有日期的人数。`family` 是本次整理的类别，`daily` 含种植、繁育、钓鱼，`trade` 是村民交易，`gear` 含获取材料、装备及加工，`explore` 是到访特定区域。各类覆盖的进度数量不同。
- `paths.csv` 每行是一种共同的记录顺序。用 `accounts` 当权重；这些行互不重叠，加起来恰好是 1,117。键名间的 `>` 表示游戏存档中解锁时间的先后，`+` 表示同一秒，保留并列。`-` 表示该字段没有记录。`undated` 用于保留有进度而无日期的条目，本次为空组标记 `-`。`first_family` 是最早一项所选进度的类别，`none` 表示这 12 项均无记录。实际选取的进度记录日期落在 2025-07-11 至 2026-11-03（UTC），每个账号的观测长度各异。
- “下一项”指所选进度中下一次有时间戳的解锁。这些记录允许玩家在两次解锁之间从事其他活动。同秒达成保持并列；到快照为止没有后续记录的账号单独保留。完成两项指定进度的人属于子样本，分母用满足条件的账号数。

**看同一批账号实际留下的东西**，用以下三张表。

| 文件 | 一行的含义 |
| --- | --- |
| `metrics.csv` | 一项行为在全部 1,117 个账号中的汇总。`description_source` 和 `unit` 来自服务器。包含服务器跟踪的全部 20 项 `craft_*`，以及建造放置、附魔、繁育、交易、旅行、环境种类和时长。`top3_sum_raw` 是这一指标最高三个账号的贡献量。 |
| `activities-by-start.csv` | 一个起始类别 × 一个累计游玩时长档 × 一项行为。对于同一行为，各组互斥并覆盖全部账号。因个别时长档人数过少，路径表中的 `none` 和 `trade` 在这张行为表合并为 `other / all`，保留总人数、贡献人数与总量，不细分时长，中位数留空。 |
| `activities-by-milestone.csv` | 对每一个指定进度，按截至快照有记录（1）或无记录（0）划分整批账号，再汇总每项行为。不同时期获得同一进度的人都会在有记录组。换一个进度，就会得到对同一批人的另一次划分。 |

`accounts` 是该组人数，`accounts_with_record` 是该行为有正值的账号数，`sum_raw` 是该组的原始总量，`median_all` 是该组所有账号的中位数。未在相应正值榜出现按 0 计，组中位数不能再平均成总体中位数。分组数据能回答“这批账号一共做了多少”及“多少账号做过”；跨行为相加会重复计人。只有路径表中明确记录的先后和交集可以用来追踪特定人群的进度。行为总量累计至快照，无法按某次解锁之前或之后分摊，也不能分摊给任意自选的更小路径。

时长按每小时 72,000 游戏 tick 换算，区间左闭右开。距离单位是厘米，100,000 cm 为 1 km。`biomes` 统计每个账号到访过的不同环境类型；跨账号的和会重复计算同一种环境。指标名是服务器的简写，解释请以原说明为准。例如食品制作 `craft_bread` 合计面包、蛋糕和饼干；`trade` 计村民交易；获得道具的进度只证明道具进入过账号的物品栏。材料记录能说明做过的事，主观动机和物品转手来源需另有证据。

**出处与范围**。数据取自 `/v1/advancements`、所选 12 项的 `/holders` 完整分页、`/v1/stats`、`/v1/totals` 和所选行为的完整榜单。同一导出时间为 `2026-11-03T06:19:10.079Z`。全服进度源扫描了 3,781 个账号，这里所有表仅统计上述共同范围的 1,117 个。导出保留计数、聚合路径及统计量，省略姓名、账号 ID 和个人时间戳。服务器规则可查[官方说明](https://hydrosmp.com/info/)；公开使用请署名并链接 Hydro Vanilla SMP，遵守其[署名及非商业使用等条款](https://api.hydrosmp.com/#terms)。
