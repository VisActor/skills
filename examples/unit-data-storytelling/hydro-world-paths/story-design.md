# 翅膀先到了
实现前设计稿 · 2026-11-03

写给没玩过《我的世界》的人。一个物品把两件本以为会分开的事连起来：取得稀有装备与亲自探索它的产地并不总按攻略顺序发生，冒险与地面生活也会落到同一批人身上。故事始终回到 825 个拿过鞘翅的账号。

开篇只给一个具体的场景。原创等距插画画出悬岛、末地城、停靠的船与一个滑翔的人，和题目「翅膀先到了。」组成跨页。告诉读者末地船能找到鞘翅，邀请他读真实存档。场景插画没有数量含义。

| 读者接着关心什么 | 文字与证据 | 构图、运动和停留 |
| --- | --- | --- |
| 谁拿到了翅膀 | 1,117 份符合条件的存档中，825 份有鞘翅进度。只证明物品进入过背包。 | 封面把空间交给一页全体名册。每小格表示一个账号的数量。825 与其余 292 在同一格距的名册里出现，留下可追踪的组。 |
| 这些人也去过产地吗 | 825 人中 660 人无到城进度，165 人同时有两项。 | 825 格在原地展开，右侧 165 格分出一列，被明确点名，剩余 292 退出。两组同样清晰。 |
| 连两样都做过的人，也是先到城吗 | 只看这 165 人。133 人先获翼后到城，32 人先到城后获翼。 | 从上幅的 165 格中分出两条相反的记录顺序。图标标明起点、终点，格数呈现两条路线的分量。时间间隔没有记录到画面里。 |
| 探险与播种会相遇吗 | 回到全部 825 人。244 人先播种，279 人先拿翅膀，302 人没有播种进度。前两组可相加，为 523 人。 | 刚才查看的账号保留，其他有翼账号重新加入，按两项进度顺序落进三块田。前两块在同一条括线上相合。跨状态的对应来自「到城顺序 × 播种顺序」的真实路径交叉计数。 |
| 背包里的装备真的用过吗，人在地面也做了什么 | 同一批 825 人中，804 人留下飞行距离，635 人放过楼梯。 | 路径小格收成总体标尺，换看同一批人的两项独立计数。先让两条从同一起点量出人数；两份累计行为表没有个人交集。 |
| 至少多少人两样都做过 | 接住上面的两条。在同一批 825 人里，即使飞过的人尽量与放楼梯的人错开，仍重合 614。 | 上尺不动，下尺移到最右端，21 人的空位和 614 人的必然重叠显出。可换工具、玻璃、食品等，让一个读法能回答读者自己的问题。末尾回到一幅地面的农田，留一句收束。 |

数据取自本次冻结包。路径按 accounts 加权，同秒不分先后。路径只表示选中进度之间的次序，不将其写成前后紧邻的全部游戏活动。累计行为没有相对解锁时间，不能追溯某双翅膀的来源；最后一幅是集合下界，绝不把示意排布当成真实匹配。口径收在页面的资料页，关键分母和必要限定在画面当场说明。

视觉采用深靛色天空、淡紫鞘翅、暖金末地城与新芽绿。左侧独立编辑文字，右侧宽幅舞台；固定舞台按滚动选择可停留的状态，连接由时钟走完。正文随构图交接。末尾保留「换一项」这一种探索，数字用同一标尺和精度。默认桌面，可用下一页按钮、方向键或自然滚动。
