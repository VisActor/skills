# NBA 输入

- `players.csv`：4,484 名研究范围内球员的统一来源档案身高，英寸；原始档案行号保留。
- `player-seasons.csv`：24,025 条球员—赛季记录，1960–61至2025–26，共66季。每人每季一行，positions 用 `|` 分隔，包含整季分钟、出场场次和原表行号。
- `honors.csv`：按赛季记录全明星入选及常规赛 MVP；荣誉可与当季是否出场分别存在。
- `sources.json`：固定 Kaggle 版本、压缩包与成员文件哈希，以及荣誉补充来源。
- `data-context.json`：分组、单位、缺失、位置和分钟口径。

年代按赛季开始年归组，每年代内部按人去重、对可用赛季的位置取并集；历史年代用满10季，2020年代有6季。身高为同一份生涯档案快照。球员全季分钟可以用于带该位置标签的人群分析，不能解读成其在每个位置分别打了这么多分钟。

minutes 已处理转队合计，包含总体行时使用总体，不重复相加分队。来源说明列出了对应原始表名，记录行号可用于追溯。原档案没有的身高保持空值。

本包从已固定的研究来源重建明细，未附均值、候选结论、旧场景配置、点阵标志坐标或网页。荣誉补充与来源核查状态沿用研究记录；本轮只验证文件与转换，不代表再次核读全部官方页面。
