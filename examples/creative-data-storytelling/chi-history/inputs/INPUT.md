# 寸、尺、丈的历史尺度资料

- `evidence.json` 保存来源、28 条尺度主张、进位依据、比较组与未决问题。
- `measurements.json` 是供展示使用的整理数据，包含同源记录及派生单位换算。
- `assets/` 提供四张透明背景的时代场景插画；生成提示词和艺术示意身份见 `assets/generation-prompts.json`。

每条记录表示某一来源支持的参考量值，不代表一个朝代所有地区与用途。`core` 为主选记录，`context` 为背景，`alternative` 为同一对象的另一研究主张，`hold` 为隔离记录。记录之间没有连续观测，不应把缺少资料的年份补成尺长曲线。

厘米是一尺长度的比较基准。寸、丈的派生保留原始进位依据与同尺制换算身份；唐代大小尺之间的折算与各自内部的进位需要分别理解。近现代市尺使用 `100/3` 厘米计算，显示时可以舍入。

部分资料是估值、转引或地方志综述，原件核验范围随证据保存。三元尺记录中的倍数与厘米数存在算术矛盾，保留原文并隔离，不驱动尺寸。四张插画不表示真实文物照片，也不用于测定单位长度。
