# 零售月度脉搏

展示交易金额、品类结构、销量与筛选联动。内嵌 Retail Sales Dataset 的 1,000 条合成交易记录；金额币种未说明，2024 年仅少量记录，不作年度同比。

- [打开单文件 HTML](result/index.html)
- [使用 visactor-light-dashboard](../../../skills/visactor-light-dashboard/SKILL.md)

下载 HTML 后用现代浏览器打开，需要联网加载图表或地图资源。也可在仓库根目录运行 `python3 -m http.server 8000` 后访问对应 HTML。
